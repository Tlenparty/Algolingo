**Проверить, является ли строка палиндромом.**

Палиндром — это строка, которая читается одинаково слева направо и справа налево (например, “radar”, “level”, “madam”).

```kotlin
fun isPalindrome(input: String): Boolean {
    val cleanedInput = input.replace("[^A-Za-z0-9]".toRegex(), "").lowercase() // Убираем все символы кроме букв и цифр, приводим к нижнему регистру
    return cleanedInput == cleanedInput.reversed() // Сравниваем строку с её обратной версией
}

fun main() {
    val testStrings = listOf(
        "radar",            // Палиндром
        "Level",            // Палиндром (с учётом регистра)
        "Madam",            // Палиндром
        "hello",            // Не палиндром
        "A man, a plan, a canal, Panama!", // Палиндром с пробелами и знаками препинания
        "No 'x' in Nixon"   // Палиндром с пробелами и знаками препинания
    )

    for (string in testStrings) {
        println("\"$string\" is a palindrome: ${isPalindrome(string)}")
    }
}
```

**Объяснение:**

1. **Очистка строки:**

• Используем регулярное выражение [^A-Za-z0-9], чтобы убрать все символы, которые не являются буквами или цифрами.

• Приводим строку к нижнему регистру с помощью lowercase(), чтобы не учитывать регистр символов.

2. **Проверка палиндрома:**

• Сравниваем очищенную строку с её обратной версией с помощью метода reversed().

3. **Пример вывода:**

```kotlin
"radar" is a palindrome: true
"Level" is a palindrome: true
"Madam" is a palindrome: true
"hello" is a palindrome: false
"A man, a plan, a canal, Panama!" is a palindrome: true
"No 'x' in Nixon" is a palindrome: true
```


Или можно решить эту задачу так 

```kotlin
fun isPalindrome(input: String): Boolean {

    val cleanedInput = input.replace("[^A-Za-z0-9]".toRegex(), "").lowercase() // Убираем все символы, кроме букв и цифр, и приводим к нижнему регистру

    // Перебираем символы с обоих концов
    var isPalindrome = true

    cleanedInput.forEachIndexed { index, char ->
        if (char != cleanedInput[cleanedInput.length - 1 - index]) {
            isPalindrome = false
            return@forEachIndexed // Если находим отличие, выходим из цикла
        }
    }

    return isPalindrome

}
```
