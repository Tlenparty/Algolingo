**1️⃣ public (по умолчанию)**

• **Видимость:** Доступен в любом месте программы (везде, где доступен класс или модуль).

• Это **модификатор по умолчанию** для всех членов, если не указан другой модификатор доступа.

 ```kotlin
 // public модификатор по умолчанию
class MyClass {
    val name = "Kotlin"
    
    fun printName() {
        println(name)
    }
}

fun main() {
    val obj = MyClass()
    obj.printName()  // Доступно из любого места программы
}
```

**2️⃣ internal**

• **Видимость:** Доступен только в пределах **одного модуля** (например, в пределах одного проекта или библиотеки).

• Модуль — это коллекция исходных файлов, скомпилированных в один артефакт (например, JAR, WAR, или обычное приложение).

  

**Пример:**

```kotlin
internal class MyClass {
    internal val name = "Kotlin"
    
    internal fun printName() {
        println(name)
    }
}

fun main() {
    val obj = MyClass()
    obj.printName()  // Доступно только в пределах того же модуля
}
```

**3️⃣ private**

• **Видимость:** Доступен только внутри **одного класса или файла**. В случае с функциями и переменными — только внутри того же класса/объекта, где они объявлены.

  

**Пример:**
```kotlin
class MyClass {
    private val secret = "This is private"
    
    private fun printSecret() {
        println(secret)
    }

    fun showSecret() {
        printSecret()  // Это допустимо, так как внутри того же класса
    }
}

fun main() {
    val obj = MyClass()
    obj.showSecret()  // Работает нормально, так как вызываем метод внутри того же класса
    // obj.secret // Ошибка! Переменная secret private
    // obj.printSecret() // Ошибка! Метод printSecret private
}

```

**4️⃣ protected**

• **Видимость:** Доступен в **классе** и в его **потомках** (наследниках).

• Такой модификатор можно использовать для методов и свойств, которые должны быть доступны в классе и его наследниках, но не для внешнего кода.

  

**Пример:**
```kotlin
open class Parent {
    protected val protectedValue = "Protected Value"
    
    protected fun printProtectedValue() {
        println(protectedValue)
    }
}

class Child : Parent() {
    fun showProtected() {
        println(protectedValue)  // Доступно в наследнике
        printProtectedValue()  // Доступно в наследнике
    }
}

fun main() {
    val parent = Parent()
    // parent.printProtectedValue() // Ошибка! Доступно только в наследниках
    // println(parent.protectedValue) // Ошибка! Доступно только в наследниках

    val child = Child()
    child.showProtected()  // Работает, потому что это наследник класса Parent
}
```

## Сводка

| Модификатор | Видимость члена класса                                  | Видимость на top-level (файл)        |
| ----------- | ------------------------------------------------------- | ------------------------------------ |
| `public`    | Везде (по умолчанию)                                    | Везде                                |
| `internal`  | Везде в пределах **модуля**                             | Везде в модуле                       |
| `protected` | В классе и его **наследниках**                          | ❌ Недоступно (нет наследников у файла)|
| `private`   | Только внутри **класса** (и его членов)                 | Только внутри **этого файла**        |

> [!important] Отличия от Java
> - **По умолчанию в Kotlin — `public`**, в Java — package-private (видимость в пределах пакета).
> - **В Kotlin НЕТ package-private.** Его ближайший аналог — `internal` (виден в модуле), но это не то же самое: модуль ≠ пакет.
> - **`protected` в Kotlin строже:** виден только в классе и наследниках, но **НЕ** в том же пакете (в Java `protected` = наследники + пакет).
> - `private` на top-level означает «видно только в этом файле» — удобно прятать вспомогательные функции.
> - **`internal` — основа модульности:** позволяет открыть API наружу (`public`), а внутренности модуля скрыть. Часто используется в многомодульных Android-проектах (api/impl).
