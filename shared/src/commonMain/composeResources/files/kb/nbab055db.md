# LinkedList

`LinkedList` в Java/Kotlin реализован как **двусвязный список** (doubly linked list): каждый элемент хранит ссылки на предыдущий и следующий узлы. Это даёт дешёвые вставку/удаление на концах, но доступ по индексу требует обхода списка.

> **На собес одной фразой:** двусвязный список — вставка/удаление на концах `O(1)`, доступ по индексу `O(n)`; выгоден, когда часто меняешь края и редко ходишь по индексу. Для произвольного доступа лучше `ArrayList`.

## Внутреннее устройство

### Узел (`Node`)
Внутренний статический класс. Каждый узел хранит значение и ссылки на соседей:

```java
private static class Node<E> {
    E item;         // значение
    Node<E> next;   // ссылка на следующий узел
    Node<E> prev;   // ссылка на предыдущий узел

    Node(Node<E> prev, E element, Node<E> next) {
        this.item = element;
        this.next = next;
        this.prev = prev;
    }
}
```

### Поля `LinkedList`
- `Node<E> first` — первый узел.
- `Node<E> last` — последний узел.
- `int size` — количество элементов.

При `get(index)` список обходится с того конца (начало или конец), к которому индекс ближе.

## Производительность операций

| Операция | Сложность | Почему |
|---|---|---|
| Добавление/удаление на концах | `O(1)` | меняется лишь несколько ссылок |
| Доступ по индексу (`get`) | `O(n)` | нужно пройти от края до нужного узла |
| Вставка/удаление в середине | `O(n)` | сначала надо **найти** нужный узел |

> На практике в Kotlin/Android для роли очереди или стека чаще берут **`ArrayDeque`** — он быстрее `LinkedList` за счёт локальности памяти. См. [[Коллекции, основные виды]].
