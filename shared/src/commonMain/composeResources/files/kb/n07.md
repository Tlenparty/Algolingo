Алгоритмическая сложность (Big-O) показывает, как **количество операций** изменяется в зависимости от **размера входных данных (**n**)**.

**Основные нотации сложности:**

| Нотация        | Название             | Пример                                                    |
| -------------- | -------------------- | --------------------------------------------------------- |
| O(1)           | Константная          | Доступ к элементу массива arr[i]                          |
| **O(log N)**   | **Логарифмическая**  | Бинарный поиск в отсортированном массиве                  |
| **O(N)**       | **Линейная**         | Проход по массиву for (i in 0 until n)                    |
| **O(N log N)** | **Квазилинейная**    | страя сортировка QuickSort, сортировка слиянием MergeSort |
| **O(N²)**      | **Квадратичная**     | Два вложенных цикла for (матрицы, пузырьковая сортировка) |
| **O(2^N)**     | **Экспоненциальная** | Задача о коммивояжёре (полный перебор)                    |
| **O(N!)**      | **Факториальная**    | Перебор всех перестановок                                 |
**🔹 O(log N) – Логарифмическая сложность**


**Обычно встречается в алгоритмах, где входные данные уменьшаются вдвое на каждом шаге**.
```kotlin
fun binarySearch(arr: IntArray, target: Int): Boolean {
    var left = 0
    var right = arr.size - 1

    while (left <= right) {
        val mid = left + (right - left) / 2
        if (arr[mid] == target) return true
        if (arr[mid] < target) left = mid + 1
        else right = mid - 1
    }
    return false
}
```

✅ **Применение:** Бинарный поиск, деревья поиска (BST).

**🔹 O(2^N) – Экспоненциальная сложность**


**Каждый шаг удваивает количество операций (рекурсивные переборы)**.

```kotlin
fun fibonacci(n: Int): Int {
    if (n <= 1) return n
    return fibonacci(n - 1) + fibonacci(n - 2) // O(2^N)
}
```

🔴 **Проблема:** При n = 50 вычисления займут **очень много времени!**
✅ **Применение:** Перебор подмножеств, задачи динамического программирования.
