# Flow

**Flow** — это асинхронный поток данных: позволяет генерировать и обрабатывать последовательные значения во времени. Значения отдаются через `emit`.

**Чем Flow отличается от suspend-функции?**

| Конструкция | Когда использовать                        |
| ----------- | ----------------------------------------- |
| `suspend fun` | Нужен **однократный** результат          |
| `Flow<T>`   | Нужно отдавать **несколько** значений во времени |

Дальше — самые популярные операторы объединения потоков.

## 1. combine — комбинирует последние значения

- Берёт **последние (актуальные)** значения двух или более `Flow` и объединяет.
- ==Работает асинхронно: не ждёт нового значения от обоих потоков — реагирует на изменение **любого**.==
- На вход: `Flow<T1>` и `Flow<T2>`. На выход: `Flow<R>`.

```kotlin
val flow1 = flow {
    emit(1)
    delay(300)
    emit(2)
}

val flow2 = flow {
    delay(100)
    emit("A")
    delay(300)
    emit("B")
}

fun main() = runBlocking {
    flow1.combine(flow2) { num, letter -> "$num-$letter" }
        .collect { println(it) }
}
```

```text
1-A   // последнее flow1 (1) + последнее flow2 (A)
2-A   // обновился flow1 → combine сработал снова
2-B   // обновился flow2 → combine сработал снова
```

## 2. zip — объединяет элементы по порядку

- Работает как молния ⚡: первый элемент первого потока + первый второго, затем второй + второй, и т. д.
- ==Если один поток закончился раньше — работа завершается.==
- На вход: `Flow<T1>` и `Flow<T2>`. На выход: `Flow<R>`.

```kotlin
val numbers = flow {
    emit(1)
    delay(100)
    emit(2)
}

val letters = flow {
    emit("A")
    delay(200)
    emit("B")
}

fun main() = runBlocking {
    numbers.zip(letters) { num, letter -> "$num-$letter" }
        .collect { println(it) }
}
```

```text
1-A   // первый + первый
2-B   // второй + второй
```

📌 **Отличие от combine:** `zip` ждёт пару из обоих потоков, а `combine` берёт последние доступные значения.

## 3. merge — сливает несколько Flow в один

- Объединяет потоки в один, **не ожидая** друг друга.
- Работает параллельно, отдавая значения в порядке поступления.
- На вход: два или больше `Flow<T>`. На выход: `Flow<T>`.

```kotlin
val flow1 = flow {
    emit(1)
    delay(100)
    emit(2)
}

val flow2 = flow {
    emit("A")
    delay(50)
    emit("B")
}

fun main() = runBlocking {
    merge(flow1, flow2).collect { println(it) }
}
```

```text
1   // первым сработал flow1
A   // затем flow2
B   // следующий flow2 (не ждёт flow1)
2   // второй emit flow1
```

## Другие полезные операторы

| Оператор        | Что делает                                                                |
| --------------- | ------------------------------------------------------------------------- |
| `map`           | Преобразует каждое значение (`Flow<Int>` → `Flow<String>`)                |
| `filter`        | Фильтрует значения (например, только чётные)                              |
| `take(n)`       | Берёт только первые `n` значений                                          |
| `flatMapConcat` | Для каждого элемента создаёт новый `Flow` и соединяет их **последовательно** |
| `flatMapMerge`  | Для каждого элемента создаёт новый `Flow` и соединяет их **параллельно**  |
| `flatMapLatest` | При новом элементе старый внутренний поток **отменяется**                 |

## Примеры с `Flow<Int>` и `Flow<String>`

### combine

- Выдаёт новый элемент при **любом** изменении в любом из потоков.
- Сначала ждёт **по одному значению** из каждого, затем эмитит комбинацию при каждом новом значении.

```kotlin
val intFlow = flowOf(1, 2, 3).onEach { delay(100) }
val stringFlow = flowOf("A", "B", "C").onEach { delay(200) }

intFlow.combine(stringFlow) { i, s -> "$i-$s" }
    .collect { println(it) }
```

```text
1-A
2-A
2-B
3-B
3-C
```

### zip

- Соединяет потоки **парами**.
- Выдаёт значение, только когда готовы **оба** потока.
- Если один завершился раньше — результат прекращается.

```kotlin
intFlow.zip(stringFlow) { i, s -> "$i-$s" }
    .collect { println(it) }
```

```text
1-A
2-B
3-C
```

**Что будет, если один поток пустой?**

```kotlin
val emptyFlow = emptyFlow<Int>()
val stringFlow = flowOf("A", "B", "C")

emptyFlow.zip(stringFlow) { i, s -> "$i-$s" }
    .collect { println(it) }
```

==Ничего не выведет== — `zip` нечего соединять в пары.

### merge

- Просто объединяет все значения из потоков **в порядке поступления** — без пар и комбинаций.

```kotlin
merge(intFlow, stringFlow).collect { println(it) }
```

```text
1
2
A
3
B
C
```

Порядок зависит от задержек и времени эмиссии.

### flattenMerge / flattenConcat

Используются с `flowOf(flow1, flow2, ...)` для объединения потока потоков.

```kotlin
// flattenMerge — асинхронно (значения вперемешку)
flowOf(intFlow, stringFlow).flattenMerge().collect { println(it) }

// flattenConcat — последовательно (сначала весь первый, потом второй)
flowOf(intFlow, stringFlow).flattenConcat().collect { println(it) }
```

`flattenConcat` даст строго `1, 2, 3, A, B, C`; `flattenMerge` — вперемешку по готовности.

## Когда какой оператор

1. **combine** — состояние экрана зависит от нескольких источников (нужно реагировать на любое изменение).
2. **zip** — данные логически связаны по парам (например, координаты x-y).
3. **merge** — нужно слить события в один поток (клики с разных кнопок).
4. **flatMapLatest** — поиск/автодополнение: на новый запрос отменяем предыдущий.
5. **flattenConcat / flatMapConcat** — важен порядок (сначала список, потом детали).
