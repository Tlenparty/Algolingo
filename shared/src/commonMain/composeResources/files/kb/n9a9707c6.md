```kotlin
/*
 * Дан список пользователей. Необходимо убрать всех пользователей, e-mail которых встречается
 * больше одного раза.
 *
 * Пример: userList -> [User(id=2, email=email2), User(id=4, email=email3)]
 */
 
fun main() {

    class User(
        val id: Int,
        val email: String,
    )
    

    val userList = listOf(
        User(
            id = 1,
            email = "email1"
        ),
        User(
            id = 2,
            email = "email2"
        ),
        User(
            id = 3,
            email = "email1"
        ),
        User(
            id = 4,
            email = "email3"
        )
    )

    fun List<User>.filterDuplicateEmails(): List<User> {
        // считаем, сколько раз встречается каждый email
        val countByEmail = groupingBy { it.email }.eachCount()
        // оставляем тех, чей email встретился ровно один раз
        return filter { countByEmail[it.email] == 1 }
    }
    println(userList.filterDuplicateEmails())
    // [User(id=2, email=email2), User(id=4, email=email3)]
}
```

## Разбор

Нужно убрать **всех** пользователей с дублирующимся email (а не «оставить по одному»). Поэтому:

1. Сначала считаем частоту каждого email — `groupingBy { it.email }.eachCount()` → `{email1=2, email2=1, email3=1}`.
2. Затем оставляем только тех, у кого счётчик равен 1.

`email1` встречается дважды (id 1 и 3) → оба удаляются. Остаются `email2` и `email3`.

> [!warning] Чем НЕ решается
> - **`distinctBy { it.email }`** — оставит **первого** с каждым email (id=1 останется). Это «убрать дубли», а не «убрать всех, у кого есть дубль». Условие задачи другое.
> - Решение в один проход по группировке — **O(n)**; наивная проверка «для каждого посчитать вхождения» дала бы **O(n²)**.

> [!tip]
> Ключевое — внимательно прочитать условие: «убрать **всех**, чей email встречается больше раза» ≠ «оставить уникальные по email». На этом ловят.
