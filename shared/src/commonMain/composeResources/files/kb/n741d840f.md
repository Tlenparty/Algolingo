# Coil (загрузка изображений)

**Coil** (Coroutine Image Loader) — современная библиотека загрузки изображений на Kotlin/корутинах. Заменяет **Glide**/**Picasso**. С версии **Coil 3** — мультиплатформенная (работает в [[KMP. Compose Multiplatform]]).

## Зачем отдельная библиотека

> [!important] Загрузка картинок — нетривиальная задача
> Наивный `BitmapFactory.decodeStream` на main → ANR + OOM. Правильная загрузка требует: фоновый поток, **downsampling** под размер View, **кэш в памяти и на диске**, отмену запроса при переиспользовании View/выходе с экрана, плейсхолдеры/ошибки. Всё это берёт на себя Coil.

## Использование

```kotlin
// View
imageView.load("https://…/photo.jpg") {
    crossfade(true)
    placeholder(R.drawable.ph)
    error(R.drawable.err)
}

// Compose
AsyncImage(
    model = "https://…/photo.jpg",
    contentDescription = null,
    modifier = Modifier.size(96.dp)
)
```

## Что важно знать

> [!info] Кэширование (двухуровневое)
> • **Memory cache** — `LruCache` декодированных bitmap (быстро, но дорого по RAM).
> • **Disk cache** — закодированные байты (переживает перезапуск).
> Ключ кэша учитывает размер/трансформации. Это связано с [[Performance. Память и утечки|управлением памятью]] и [[Структуры данных|LRU]].

> [!tip] Downsampling — главная защита от OOM
> Bitmap в памяти = ширина×высота×4 байта (ARGB_8888). Coil декодирует **под целевой размер** View/`Modifier.size`, а не в полное разрешение — поэтому фото 4000×3000 не съедает десятки МБ ради иконки 96dp. Это ключевая причина не грузить картинки «вручную».

> [!info] Отмена запросов
> При переиспользовании `ViewHolder` в RecyclerView (см. [[Recycler. ViewPool, PayLoads]]) или уходе composable из композиции Coil **отменяет** незавершённую загрузку (корутина привязана к жизненному циклу/`AsyncImage`). Это предотвращает «мигание» чужих картинок и лишний трафик.

> [!note] Coil vs Glide
> • **Coil** — Kotlin-first, корутины, меньше по размеру, KMP (Coil 3), нативная интеграция с Compose (`AsyncImage`).
> • **Glide** — старше, очень зрелый, чуть быстрее на некоторых кейсах, но Java/колбэки и только Android.
> На новых проектах (особенно Compose/KMP) дефолт — **Coil**.
