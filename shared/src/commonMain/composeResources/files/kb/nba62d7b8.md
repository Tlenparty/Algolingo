# HashMap

Коллекция пар «ключ → значение» на основе хеш-таблицы. Подробнее про механику — [[Как работает HashMap]].

> **На собес одной фразой:** доступ по ключу за `O(1)` в среднем; ключи уникальны, порядок не гарантирован; коллизии решаются цепочкой (список → красно-чёрное дерево).

## Особенности

1. **Пары ключ-значение** — каждый элемент это `key → value`.
2. **Быстрый доступ по ключу** — `O(1)` в среднем, что делает `HashMap` эффективным для поиска и доступа.
3. **Уникальные ключи** — при повторном `put` с тем же ключом значение **перезаписывается**.
4. **Нет гарантии порядка** — порядок элементов не определён и может меняться (в т.ч. при resize).

## Когда использовать

- Нужен **быстрый доступ к данным по уникальному ключу**.
- Данные естественно ложатся в структуру **«ключ → значение»** (ассоциативный массив/словарь).

## Как работает под капотом

`HashMap` хранит данные в массиве **бакетов** (корзин). При добавлении:
1. Вычисляется `hashCode()` ключа.
2. Из хеша определяется индекс бакета во внутреннем массиве.
3. Если в бакет попадает несколько ключей с одинаковым индексом (**коллизия**), они хранятся в связном списке, а при большом их числе — в красно-чёрном дереве (Java 8+).

Отличие от других коллекций — именно структура «хеш-таблица + пары»: она даёт быстрый доступ по ключу, но не сохраняет порядок и требует уникальности ключей.

## Вычисление индекса и коллизии

### Ключ → бакет
При добавлении вызывается `hashCode()` ключа → получается хеш-код (int). Индекс бакета определяется как остаток от деления хеша на размер массива (на практике — через побитовое `AND`, см. [[Как работает HashMap]]).

```kotlin
val map = HashMap<String, Int>()
map["apple"]  = 5
map["banana"] = 10
map["orange"] = 7
```

### Коллизии
Коллизия — когда два разных ключа дают один индекс бакета. Такие элементы кладутся в один бакет и связываются в цепочку (список или дерево). При поиске `HashMap` вычисляет индекс бакета, затем перебирает его содержимое через `equals()`, чтобы найти нужный ключ.

```kotlin
val map = HashMap<String, Int>()
map["apple"]   = 5
map["apricot"] = 7   // потенциальная коллизия с "apple"
map["banana"]  = 10
map["orange"]  = 7   // потенциальная коллизия с "apricot"

println(map["apple"])   // 5
println(map["apricot"]) // 7
println(map["orange"])  // 7
```

Даже при коллизии значения не теряются: разные ключи в одном бакете различаются через `equals()`. См. [[Как сравниваются ключи в HashMap при одинаковом hashCode]] и [[Как выглядит Bucket при ключах с одинаковым hashCode в HashMap]].
