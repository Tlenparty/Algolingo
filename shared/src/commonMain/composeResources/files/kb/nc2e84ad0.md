# 00 Программа трека Backend

Путь бэкенд-разработчика на Kotlin + Spring Boot: от «знаю Kotlin, но не писал сервер» до уверенного middle. Уроки трека лежат на вкладке **Backend**, теория — в заметках этого раздела. Где урок System Design уже объясняет «зачем», урок Backend показывает «как в коде».

Связано: [[01 Словарь Spring]] · [[00 Словарь терминов]] · [[05 Тренажёр решений]]

## Как устроен трек

- **Три типа уроков.** *Проверяемые* — чистый Kotlin (rate limiter, backoff, кеш), эталон и каждое неверное облачко доказаны компиляцией и тестами. *Ревьюенные* — код Spring, SQL и YAML собирается из облачков шагами, факты сверены с заметками. *Схемы* — шаги и блоки, как в System Design.
- **Номер урока** `bk<уровень>.<номер>`: `bk3.1` — первый урок третьего уровня.
- **Правило повторов** то же: вернись через 1, 3 и 7 дней.

## Лестница уровней
