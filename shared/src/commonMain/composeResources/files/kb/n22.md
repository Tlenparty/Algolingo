Задача на проверку, является ли одно слово анаграммой другого, заключается в том, чтобы проверить, могут ли два слова быть перестановкой друг друга. Чтобы решить эту задачу на Kotlin, можно воспользоваться подходом с подсчётом символов в обоих словах и сравнением этих подсчётов.

**Алгоритм:**

1. Если длины слов различаются, то они не могут быть анаграммами.
2. Преобразуем оба слова в нижний регистр (для учёта регистра) и отсортируем их.
3. Если отсортированные версии обоих слов совпадают, значит слова являются анаграммами.

**Реализация:**

```kotlin
fun areAnagrams(word1: String, word2: String): Boolean {
    // Если длины слов различаются, сразу возвращаем false
    if (word1.length != word2.length) return false

    // Создаем Map для подсчета частоты символов
    val charCount1 = mutableMapOf<Char, Int>()
    val charCount2 = mutableMapOf<Char, Int>()

    // Заполняем Map для первого слова
    word1.lowercase().forEach { charCount1[it] = charCount1.getOrDefault(it, 0) + 1 }

    // Заполняем Map для второго слова
    word2.lowercase().forEach { charCount2[it] = charCount2.getOrDefault(it, 0) + 1 }

    // Сравниваем оба Map
    return charCount1 == charCount2
}

fun main() {
    println(areAnagrams("listen", "silent"))    // true
    println(areAnagrams("hello", "world"))      // false
    println(areAnagrams("triangle", "integral")) // true
    println(areAnagrams("apple", "pale"))       // false
}
```

или

```kotlin
fun areAnagrams(word1: String, word2: String): Boolean {
    // Если длины слов различаются, сразу возвращаем false
    if (word1.length != word2.length) return false

    // Преобразуем слова в нижний регистр и сортируем их
    val sortedWord1 = word1.lowercase().toList().sorted()
    val sortedWord2 = word2.lowercase().toList().sorted()

    // Сравниваем отсортированные версии слов
    return sortedWord1 == sortedWord2
}

fun main() {
    println(areAnagrams("listen", "silent"))    // true
    println(areAnagrams("hello", "world"))      // false
    println(areAnagrams("triangle", "integral")) // true
    println(areAnagrams("apple", "pale"))       // false
}
```
