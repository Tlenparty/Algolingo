Проверить, является ли строка со скобками ``()[]{}`` правильной (открытые скобки закрываются в правильном порядке

**Решение:**

Используем **стек (**Stack**)**, который хранит открытые скобки.
```kotlin
• Если встречаем открывающую (, {, [ → добавляем в стек.
• Если встречаем закрывающую ), }, ] → проверяем, соответствует ли она верхнему элементу стека.
• Если стек в конце пуст — последовательность правильная.
```

```kotlin
fun isValidBrackets(str: String): Boolean {
    val stack = ArrayDeque<Char>()
    val pairs = mapOf(')' to '(', '}' to '{', ']' to '[')

    for (char in str) {
        if (char in pairs.values) {
            stack.addLast(char)  // Открывающая скобка → в стек
        } else if (char in pairs.keys) {
            if (stack.isEmpty() || stack.removeLast() != pairs[char]) {
                return false  // Либо стек пуст (лишняя закрывающая), либо не совпадает пара
            }
        }
    }
    return stack.isEmpty()  // Если стек пустой, последовательность корректна
}

fun main() {
    val test1 = "({[]})"  // ✅ Правильная
    val test2 = "([)]"    // ❌ Неправильная
    val test3 = "{[}"     // ❌ Неправильная

    println(isValidBrackets(test1)) // true
    println(isValidBrackets(test2)) // false
    println(isValidBrackets(test3)) // false
}
```

### Задача на Map

**Задача:**

Дана строка. Найдите **первый символ**, который **не повторяется**. Если таких символов нет, верните null.

**Решение:**

Используем Map<Char, Int>, где **ключ** — символ, **значение** — количество раз, сколько он встречается.

**Код на Kotlin:**

```kotlin
fun firstUniqueChar(s: String): Char? {
    val countMap = mutableMapOf<Char, Int>()

    // Заполняем map (считаем частоту символов)
    for (char in s) {
        countMap[char] = countMap.getOrDefault(char, 0) + 1
    }

    // Второй проход: ищем первый уникальный символ
    for (char in s) {
        if (countMap[char] == 1) return char
    }

    return null // Нет уникального символа
}

fun main() {
    println(firstUniqueChar("leetcode"))  // 'l'
    println(firstUniqueChar("aabbcc"))    // null
    println(firstUniqueChar("swiss"))     // 'w'
}

**Разбор решения:**

1. **Первый проход по строке** → заполняем Map (countMap), считая, сколько раз встречается каждый символ.

2. **Второй проход** → ищем первый символ с countMap[char] == 1.

3. Если все символы повторяются → возвращаем null.
```
