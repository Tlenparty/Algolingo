Jetpack Compose предлагает **мощную систему анимаций**, которая делится на несколько типов в зависимости от потребностей:
Гайд от гугла.
https://developer.android.com/develop/ui/compose/animation/quick-guide

- **Простые анимации** — `animate*AsState()`
- **Преобразования** — `updateTransition()`
- **Жестовые анимации** — `Animatable`
- **Анимация списков** — `LazyColumn` + `animateItem()`
- **Низкоуровневые анимации** — `rememberInfiniteTransition()`, `TargetBasedAnimation`

## 1️⃣ Простые анимации (`animate*AsState`)

Если нужно **изменять значение плавно**, например, цвет или размер, используем animate*AsState().

```kotlin

@Composable
fun SimpleColorAnimation() {
    var isExpanded by remember { mutableStateOf(false) }

    val backgroundColor by animateColorAsState(
        targetValue = if (isExpanded) Color.Red else Color.Blue,
        animationSpec = tween(durationMillis = 1000)
    )

    Box(
        modifier = Modifier
            .size(100.dp)
            .background(backgroundColor)
            .clickable { isExpanded = !isExpanded }
    )
}
```

✅ **Применение:**

• animateDpAsState() — для размеров
• animateFloatAsState() — для прозрачности
• animateColorAsState() — для цветов

**2️⃣ Анимация нескольких параметров (updateTransition())**

Если нужно **анимировать несколько параметров одновременно**, используем updateTransition().

```kotlin
@Composable
fun MultipleAnimations() {
    var isExpanded by remember { mutableStateOf(false) }
    val transition = updateTransition(isExpanded, label = "Box Transition")

    val size by transition.animateDp(label = "Size Animation") {
        if (it) 150.dp else 100.dp
    }
    val color by transition.animateColor(label = "Color Animation") {
        if (it) Color.Green else Color.Magenta
    }

    Box(
        modifier = Modifier
            .size(size)
            .background(color)
            .clickable { isExpanded = !isExpanded }
    )
}
```

✅ **Применение:**

• Когда нужно **анимировать несколько свойств** (размер, цвет, прозрачность) **синхронно**

**3️⃣ Анимация жестов (Animatable)**

Если нужно **управлять анимацией вручную**, например, при **перетаскивании**, используем Animatable.
```kotlin 
@Composable
fun DraggableBox() {
    val offsetX = remember { Animatable(0f) }

    Box(
        modifier = Modifier
            .size(100.dp)
            .background(Color.Cyan)
            .pointerInput(Unit) {
                detectTapGestures {
                    launch {
                        offsetX.animateTo(
                            targetValue = if (offsetX.value == 0f) 200f else 0f,
                            animationSpec = spring(stiffness = Spring.StiffnessMedium)
                        )
                    }
                }
            }
            .offset { IntOffset(offsetX.value.toInt(), 0) }
    )
}
```

✅ **Применение:**

• Для **жестовых анимаций** (перетаскивание, скролл).
• Для **ручного управления** (offsetX.snapTo(), offsetX.animateTo()).

**4️⃣ Анимация списков (LazyColumn)**

Если нужно **добавлять, удалять или менять элементы списка плавно**, используем animateItemPlacement().

```kotlin
@Composable
fun AnimatedList() {
    var items by remember { mutableStateOf((1..5).toList()) }

    Column {
        Button(onClick = { items = items.shuffled() }) {
            Text("Shuffle")
        }
        LazyColumn {
            items(items, key = { it }) { item ->
                Text(
                    text = "Item $item",
                    modifier = Modifier
                        .fillMaxWidth()
                        .animateItemPlacement()
                        .padding(8.dp)
                        .background(Color.LightGray)
                        .padding(16.dp)
                )
            }
        }
    }
}
```

✅ **Применение:**

• При **перемещении** элементов.
• При **добавлении/удалении** элементов в списке.

**5️⃣ Бесконечные анимации (rememberInfiniteTransition())**

Если нужно **запустить анимацию без остановки** (например, пульсацию), используем rememberInfiniteTransition().

```kotlin
@Composable
fun PulsingCircle() {
    val infiniteTransition = rememberInfiniteTransition()
    val scale by infiniteTransition.animateFloat(
        initialValue = 1f,
        targetValue = 1.5f,
        animationSpec = infiniteRepeatable(
            animation = tween(1000),
            repeatMode = RepeatMode.Reverse
        )
    )

    Box(
        modifier = Modifier
            .size(100.dp * scale)
            .background(Color.Blue, shape = CircleShape)
    )
}
```

✅ **Применение:**

• Анимация **пульсации, мигания**.
• Анимация **фоновых элементов**.

**6️⃣ Низкоуровневые анимации (TargetBasedAnimation)**

Если нужна **анимация без** LaunchedEffect, например, внутри Canvas.

```kotlin
@Composable
fun TargetAnimation() {
    val density = LocalDensity.current
    val anim = remember {
        TargetBasedAnimation(
            animationSpec = tween(2000),
            typeConverter = Float.VectorConverter,
            initialValue = 0f,
            targetValue = 300f
        )
    }

    var playTime by remember { mutableStateOf(0L) }

    LaunchedEffect(Unit) {
        val startTime = withFrameMillis { it }
        while (true) {
            playTime = withFrameMillis { it } - startTime
        }
    }

    val animatedValue = anim.getValueFromNanos(playTime * 1_000_000)

    Box(
        modifier = Modifier
            .size(animatedValue.dp)
            .background(Color.Red)
    )
}
```

✅ **Применение:**

• Анимация **без корутин и recomposition** (например, для Canvas).

> [!note] `animateItemPlacement()` устарел
> В свежих версиях Compose вместо `Modifier.animateItemPlacement()` используется `Modifier.animateItem()` — он умеет анимировать не только перемещение, но и появление/исчезновение элементов (`fadeInSpec`/`fadeOutSpec`). Не забывайте про **стабильный `key`** в `items(..., key = { it.id })` — без него анимация перестановки не сработает.

> [!tip] Что ещё спросят про анимации
> - **`AnimatedVisibility`** — плавные появление/исчезновение (`fadeIn`/`slideIn`).
> - **`Crossfade`** — плавный переход между двумя состояниями/экранами.
> - **`AnimatedContent`** — переход с разной анимацией в зависимости от направления изменения.
> - **Производительность:** анимации значений, влияющих только на отрисовку (`alpha`, `translation`, `scale`), лучше делать через `Modifier.graphicsLayer { }` — тогда меняется только фаза Draw, без Composition/Layout (см. [[Compose. Оптимизация]]).
