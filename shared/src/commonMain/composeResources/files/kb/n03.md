# 🏋️ Тренажёр задач — распознавание паттерна

> **Как тренироваться:** прочитай условие → **вслух назови метод и сложность** → только потом раскрой спойлер.
> Цель не написать код, а за 10–15 секунд сказать: «это два указателя, O(n)».
> Спойлеры свёрнуты (callout с `-`) — кликни, чтобы проверить себя.

Связано: [[00 Компас алгоритмов]] · [[01 Ключи и сигналы]] · [[02 Шаблон решения]]

Прогрессия: 🟢 супер-просто → 🟢🟢 просто → 🟡 ниже среднего → 🟡🟡 средне.

---

## 🟢 Уровень 1 — супер-простые (один очевидный приём)

### 1.1 Сумма массива
Дан массив чисел. Верни их сумму.
> [!question]- Ответ
> **Метод:** один проход (линейный обход). **O(n)**, память O(1).
> Сигнал: «пройти и накопить» — базовый цикл, никакой структуры данных не нужно.

### 1.2 Максимум в массиве
Найди наибольший элемент.
> [!question]- Ответ
> **Метод:** один проход с переменной-максимумом. **O(n)**, O(1).
> Сигнал: «найти max/min» без сортировки → линейный проход.

### 1.3 Разворот строки
Переверни строку «abc» → «cba».
> [!question]- Ответ
> **Метод:** два указателя навстречу (или встроенный reverse). **O(n)**, O(1).
> Сигнал: «развернуть / симметрия» → указатели по краям, меняем местами.

### 1.4 Есть ли дубликат
Верни true, если в массиве есть повторяющийся элемент.
> [!question]- Ответ
> **Метод:** **Hash Set** — добавляем, при коллизии true. **O(n)**, O(n).
> Сигнал: «есть ли дубликат / уникальность» → Set. (Альтернатива: сортировка + сосед, O(n log n).)

### 1.5 Палиндром-строка
Проверь, читается ли строка одинаково с обеих сторон.
> [!question]- Ответ
> **Метод:** два указателя навстречу. **O(n)**, O(1).
> Сигнал: «палиндром / симметрия». См. [[Если слово палиндром]].

## 🟢🟢 Уровень 2 — простые (надо выбрать структуру)

### 2.1 Two Sum (массив НЕ отсортирован)
Верни индексы двух чисел с суммой `target`.
> [!question]- Ответ
> **Метод:** **Hash Map** `значение → индекс`, ищем дополнение `target - x`. **O(n)**, O(n).
> Сигнал: «пара с суммой» + НЕ отсортировано → Map (а не вложенный цикл O(n²)).

### 2.2 Two Sum (массив отсортирован)
То же, но массив отсортирован.
> [!question]- Ответ
> **Метод:** **два указателя** навстречу. **O(n)**, O(1).
> Сигнал: «отсортировано» + «пара» → меняем Map на указатели, экономим память. См. [[Задача на 2 указателя]].

### 2.3 Корректность скобок
Строка из `()[]{}` — правильная ли вложенность?
> [!question]- Ответ
> **Метод:** **Стек**. Открытую кладём, закрытую сверяем с вершиной. **O(n)**, O(n).
> Сигнал: «скобки / вложенность / парность» → стек. См. [[Задача на stack и map]].

### 2.4 Первый неповторяющийся символ
Верни первый символ строки, который встречается один раз.
> [!question]- Ответ
> **Метод:** **Hash Map** частот, затем второй проход. **O(n)**, O(1) (алфавит ограничен).
> Сигнал: «частота / первый уникальный» → счётчик в Map.

### 2.5 Анаграмма
Являются ли две строки анаграммами друг друга?
> [!question]- Ответ
> **Метод:** **Map частот** (или сортировка обеих). **O(n)**, O(1).
> Сигнал: «одинаковый набор символов» → сравнить частоты. См. [[Проверка является ли слово анаграммой]].

### 2.6 Поиск в отсортированном массиве
Найди индекс элемента за O(log n).
> [!question]- Ответ
> **Метод:** **Бинарный поиск**. **O(log n)**, O(1).
> Сигнал: «отсортировано» + «log n / найти позицию». См. [[Бинарный поиск]].

### 2.7 Лестница (climb stairs)
Сколько способов подняться на n ступеней, шагая на 1 или 2?
> [!question]- Ответ
> **Метод:** **DP** `dp[i] = dp[i-1] + dp[i-2]` (числа Фибоначчи). **O(n)**, O(1).
> Сигнал: «сколько способов» + подзадачи перекрываются → DP. См. [[Динамическое программирование]].

## 🟡 Уровень 3 — ниже среднего (паттерн неочевиден сразу)

### 3.1 Самая длинная подстрока без повторов
Найди длину наибольшей подстроки без повторяющихся символов.
> [!question]- Ответ
> **Метод:** **Скользящее окно** + Map последних позиций. **O(n)**, O(n).
> Сигнал: «непрерывная подстрока» + «без повторов / максимальная длина» → окно.

### 3.2 Подмассив с суммой K
Сколько непрерывных подмассивов имеют сумму ровно K?
> [!question]- Ответ
> **Метод:** **Префиксные суммы + Hash Map** (считаем `prefix - K`). **O(n)**, O(n).
> Сигнал: «количество подмассивов с суммой» → префиксные суммы в Map. (Наивно — O(n²).)

### 3.3 Перемещение нулей
Сдвинь все нули в конец, сохранив порядок остальных, на месте.
> [!question]- Ответ
> **Метод:** **два указателя** в одном направлении (медленный/быстрый). **O(n)**, O(1).
> Сигнал: «на месте / сохранить порядок / перегруппировать» → fast/slow pointers.

### 3.4 Слияние интервалов
Дан список интервалов — слей пересекающиеся.
> [!question]- Ответ
> **Метод:** **сортировка по началу + жадный проход**. **O(n log n)**.
> Сигнал: «интервалы / пересечения / расписание» → сортируем и сливаем.

### 3.5 Количество островов
Матрица 0/1 — посчитай связные группы единиц.
> [!question]- Ответ
> **Метод:** **DFS или BFS** по матрице, помечая посещённые. **O(rows·cols)**.
> Сигнал: «группы / острова / связность на сетке» → обход (DFS/BFS) или Union-Find. См. [[Поиск в глубину (DFS)]].

### 3.6 K самых частых элементов
Верни K самых часто встречающихся чисел.
> [!question]- Ответ
> **Метод:** **Map частот + Heap размера K** (или bucket sort). **O(n log k)**.
> Сигнал: «top K / самые частые» → Map для частот, Heap для отбора K.

### 3.7 Уровни бинарного дерева
Выведи значения дерева по уровням (level order).
> [!question]- Ответ
> **Метод:** **BFS** с обработкой целого слоя за итерацию. **O(n)**.
> Сигнал: «по уровням / по слоям» → BFS с `repeat(queue.size)`. См. [[Задача на поиск в ширину]].

## 🟡🟡 Уровень 4 — средние (комбинация приёмов / неявный паттерн)

### 4.1 Максимальная сумма подмассива (Кадане)
Найди максимальную сумму непрерывного подмассива.
> [!question]- Ответ
> **Метод:** **DP / алгоритм Кадане**: `cur = max(x, cur + x)`, `best = max(best, cur)`. **O(n)**, O(1).
> Сигнал: «максимальная сумма непрерывного» → Кадане (частный случай DP).

### 4.2 Размен монетами (минимум монет)
Минимальное число монет для суммы `amount` (номиналы заданы).
> [!question]- Ответ
> **Метод:** **DP** `dp[s] = min(dp[s - coin] + 1)`. **O(amount·coins)**.
> Сигнал: «минимум/оптимум» + «набрать сумму» + жадность не работает → DP. (Жадность ошибётся, например, на [1,3,4], amount=6.)

### 4.3 Все подмножества (subsets)
Верни все подмножества множества.
> [!question]- Ответ
> **Метод:** **backtracking (DFS)** или битовые маски. **O(2ⁿ · n)**.
> Сигнал: «ВСЕ варианты / подмножества / комбинации» → перебор с откатом.

### 4.4 Товар в окне максимум (sliding window maximum)
Для каждого окна длины K найди максимум.
> [!question]- Ответ
> **Метод:** **дек (монотонная очередь)**. **O(n)**.
> Сигнал: «окно фиксированной длины» + «максимум в окне» → монотонный дек (наивно O(n·k)).

### 4.5 Минимальное число пересадок
Граф станций (рёбра равны) — минимум пересадок от A до B.
> [!question]- Ответ
> **Метод:** **BFS** (веса равны → первый приход = кратчайший). **O(V+E)**.
> Сигнал: «минимум шагов/пересадок» + невзвешенный граф → BFS. См. [[Задача от Яндекс со станциями]].

### 4.6 Топологическая сортировка (порядок задач)
Есть зависимости «задача A до B» — можно ли выполнить все и в каком порядке?
> [!question]- Ответ
> **Метод:** **топологическая сортировка** (Kahn / BFS по входным степеням, либо DFS). **O(V+E)**.
> Сигнал: «зависимости / порядок / нет ли циклов» → топосорт на DAG.

### 4.7 Самая длинная возрастающая подпоследовательность (LIS)
Длина наибольшей строго возрастающей подпоследовательности.
> [!question]- Ответ
> **Метод:** **DP O(n²)** `dp[i] = max(dp[j]) + 1`, либо **бинпоиск O(n log n)**.
> Сигнал: «подпоследовательность» (не подряд!) + «оптимум» → DP; ускорение бинпоиском.

## 🎯 Как закрепить

1. Прогоняй файл сверху вниз, **называя метод вслух** до спойлера. Цель — рефлекс.
2. Отмечай ❌ те, где ошибся с паттерном — это твои слабые сигналы, повтори их в [[01 Ключи и сигналы]].
3. Когда уверенно угадываешь метод за 10 сек — переходи к написанию кода по [[02 Шаблон решения]].

> Связки-рефлексы, которые надо довести до автоматизма:
> - отсортировано + пара → **два указателя**
> - не отсортировано + пара/частота → **Hash Map**
> - непрерывный подотрезок → **окно**
> - вложенность/скобки → **стек**
> - кратчайшее по шагам → **BFS**
> - все варианты → **backtracking**
> - количество способов/оптимум → **DP**
> - top K → **heap**
