Как объединить 2 списка 

```kotlin
val a = arrayOf(1, 2, 3)
val b = arrayOf(10, 20, 30)

val result = listOf(*a, *b)
println(result) // [1, 2, 3, 10, 20, 30]
```

В **Kotlin** оператор * (spread operator) используется для **распаковки массива** при передаче его в функцию, ожидающую vararg (переменное количество аргументов), или при объединении коллекций.

 **vararg в Kotlin – передача переменного числа аргументов**
 
```kotlin

fun printNumbers(vararg numbers: Int) {
    for (num in numbers) {
        println(num)
    }
}

fun main() {
    printNumbers(1, 2, 3, 4, 5)
    // Вывод:
    // 1
    // 2
    // 3
    // 4
    // 5
}
```

Здесь `printNumbers` принимает **переменное число аргументов** `vararg numbers: Int`, которые внутри функции воспринимаются как массив (`IntArray` для примитивов, `Array<T>` для объектов).

## Spread (`*`) для передачи массива в vararg

Если есть готовый массив, его нельзя передать в vararg напрямую — нужен spread-оператор `*`:

```kotlin
val nums = intArrayOf(1, 2, 3)
printNumbers(*nums)            // распаковываем массив
printNumbers(0, *nums, 4)      // можно комбинировать с обычными аргументами
```

> [!tip] Нюансы
> - **`*` создаёт копию** массива (поверхностную) перед передачей — для больших массивов это лишняя аллокация.
> - В функции может быть **только один** `vararg`-параметр; обычно его ставят последним (иначе аргументы после него передают только по имени).
> - `vararg` под капотом — это массив, поэтому `printNumbers(vararg numbers: Int)` в байткоде принимает `int[]`.
