# Как работает CountDownLatch

`CountDownLatch` — это механизм из `java.util.concurrent`, который позволяет **одному или нескольким потокам ждать завершения других потоков**. Работает как счётчик: его можно уменьшать (`countDown()`), а другие потоки могут ждать, пока он не станет нулём (`await()`).

## Как работает

1. **Инициализируется числом `N`** — количеством событий (потоков), которых нужно дождаться.
2. Потоки выполняют свою работу и вызывают `countDown()`, уменьшая счётчик.
3. Главный (или другие) поток вызывает `await()` и **останавливается**, пока счётчик не станет 0.
4. Когда счётчик достигает 0, все ожидающие на `await()` потоки **разблокируются** и продолжают выполнение.

## Пример: ждём завершения 3 потоков

```kotlin
import java.util.concurrent.CountDownLatch

fun main() {
    val latch = CountDownLatch(3) // ожидаем завершения 3 потоков

    for (i in 1..3) {
        Thread {
            println("Поток $i выполняет работу...")
            Thread.sleep((1000L..3000L).random()) // имитация работы
            println("Поток $i завершил работу")
            latch.countDown() // уменьшаем счётчик
        }.start()
    }

    println("Ожидаем завершения потоков...")
    latch.await() // ждём, пока latch не станет 0
    println("Все потоки завершены, продолжаем выполнение!")
}
```

**Возможный вывод в консоль:**

```text
Ожидаем завершения потоков...
Поток 1 выполняет работу...
Поток 2 выполняет работу...
Поток 3 выполняет работу...
Поток 3 завершил работу
Поток 1 завершил работу
Поток 2 завершил работу
Все потоки завершены, продолжаем выполнение!
```

> [!tip] Частые вопросы на собесе
> - **`CountDownLatch` одноразовый** — счётчик нельзя «перезарядить». Если нужен повторно используемый барьер, берите [[ReentrantLock, Semaphore и CyclicBarrier|CyclicBarrier]].
> - **`await()` блокирует поток.** В корутинах вместо этого ждут результат через `Job.join()` / `awaitAll()` или через `coroutineScope` — не блокируя поток.
> - Есть перегрузка `await(timeout, unit)` — вернёт `false`, если дождаться не удалось за отведённое время.
