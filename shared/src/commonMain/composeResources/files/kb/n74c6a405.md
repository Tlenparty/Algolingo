В **Kotlin** функциональный тип — ==это **тип, представляющий функцию** как объект.== Он позволяет передавать функции как аргументы, возвращать их из других функций и работать с ними как с обычными значениями.

Функциональные типы записываются как:
```kotlin
(A, B) -> C
```

Где:

• A, B — типы входных аргументов функции.
• C — тип возвращаемого значения.

Примеры:

• (Int, Int) -> Int — функция принимает два Int и возвращает Int.
• (String) -> Boolean — функция принимает String и возвращает Boolean.
• () -> Unit — функция без параметров, ничего не возвращает.

**🔥 Как работают функциональные типы?**

**✅ 1. Присваивание функции переменной**

Функция может быть присвоена переменной, если она соответствует ==функциональному типу==.

```kotlin
val sum: (Int, Int) -> Int = { a, b -> a + b }

fun main() {
    println(sum(5, 3)) // 8
}

```

```java
package kotlin.jvm.functions;

public interface Function2<T1, T2, R> {
    R invoke(T1 t1, T2 t2);

}
```

**✅ 2. Передача функции в аргументы**

Функции могут передаваться как параметры другим функциям.

```kotlin
fun operateOnNumbers(a: Int, b: Int, operation: (Int, Int) -> Int): Int {
    return operation(a, b)
}

fun main() {
    val result = operateOnNumbers(4, 5) { x, y -> x * y }
    println(result) // 20
}
```

💡 Здесь operateOnNumbers принимает три аргумента: a, b и operation, который является **функциональным параметром**.

**✅ 3. Возвращение функции из другой функции**

Функция может **возвращать другую функцию**.

```kotlin
fun getOperation(type: String): (Int, Int) -> Int {
    return when (type) {
        "sum" -> { a, b -> a + b }
        "multiply" -> { a, b -> a * b }
        else -> { _, _ -> 0 }
    }
}

fun main() {
    val operation = getOperation("sum")
    println(operation(2, 3)) // 5
}
```

💡 Здесь getOperation возвращает функцию, которая соответствует функциональному типу (Int, Int) -> Int.

**✅ 4. Анонимные функции**

Вместо **лямбд** можно использовать **анонимные функции**:

```kotlin
val subtract = fun(a: Int, b: Int): Int {
    return a - b
}

fun main() {
    println(subtract(10, 4)) // 6
}
```

### Пример с собеса Совкомбанка

```kotlin
class SpecialFunction : () -> Unit {  
    override fun invoke() {  
        println("Invoked from an instance")  
    }  
  
}  
  
fun main() {  
    try {  
        SpecialFunction()()  
    } catch (ex: Exception) {  
        println("Error")  
    }  
}
```

В Kotlin класс может наследоваться от **функционального типа** (например, () -> Unit). Это значит, что экземпляр класса можно использовать **как функцию**.
```kotlin
class SpecialFunction : () -> Unit {
    override fun invoke() {
        println("Invoked from an instance")
    }
}

fun main() {

    val myFunction = SpecialFunction()
    myFunction() // Вызов как функции
    myFunction.invoke() // Вызов вручную через invoke()

    // Вывод:
    // Invoked from an instance

}
```

💡 **Объяснение:**

1. class SpecialFunction : () -> Unit
	• Класс наследуется от функционального типа () -> Unit, что означает, что он может работать **как функция без параметров, возвращающая** Unit.

2. override fun invoke()
	• В Kotlin любая функция, определенная с именем invoke, позволяет объекту класса быть вызванным **как функция**.

3. myFunction()
	• Экземпляр SpecialFunction вызывается **как функция**, потому что в нем переопределен метод invoke().

**✅ Пример с параметрами**
```kotlin
class MultiplyBy(val factor: Int) : (Int) -> Int {
    override fun invoke(x: Int): Int {
        return x * factor
    }
}

fun main() {
    val multiplyBy2 = MultiplyBy(2)
    
    println(multiplyBy2(5)) // 10
    println(multiplyBy2.invoke(7)) // 14
}
```

💡 **Что здесь происходит?**

• MultiplyBy(2) создаёт объект, который умножает переданное число на 2.
• multiplyBy2(5) автоматически вызывает invoke(5), возвращая 10.

**✅ Когда это полезно?**

1. **Если нужно создать объекты, ведущие себя как функции**.
2. **Когда требуется передавать экземпляры классов в качестве функций**.
3. **Когда нужно инкапсулировать логику в классе и при этом работать с ним, как с функцией**.

> [!tip] Что под капотом и что спросят
> - Функциональный тип `(A, B) -> C` компилируется в интерфейс `FunctionN` (`Function2<A, B, C>` с методом `invoke`). Лямбда — это объект, реализующий `invoke`.
> - **Оператор `invoke`** делает любой объект «вызываемым»: `obj()` ≡ `obj.invoke()`. Поэтому класс может наследоваться от `() -> Unit` и вызываться как функция.
> - **Receiver-типы**: `A.(B) -> C` — функция с приёмником (как в `apply`/`buildString`), внутри лямбды `this` = `A`. Основа DSL.
> - **`suspend`-функциональные типы**: `suspend (A) -> B` — тип для suspend-лямбд (используется в корутинах).
