В Kotlin **reference function** (ссылка на функцию) – это способ передавать функции в качестве аргументов или присваивать их переменным, используя ссылку на существующую функцию вместо её вызова. Это позволяет работать с функциями как с первоклассными объектами.


**Синтаксис ссылки на функцию**

Для получения ссылки на функцию используется оператор ::.


**Примеры:**

1. **Ссылка на обычную функцию**
```kotlin
fun sayHello() {
    println("Hello, Kotlin!")
}

val helloRef = ::sayHello // Ссылка на функцию
helloRef() // Вызов через ссылку
```

2. **Ссылка на функцию с параметрами**

```kotlin
fun greet(name: String) {
    println("Hello, $name!")
}

val greetRef: (String) -> Unit = ::greet
greetRef("Alice")
```

3. **Ссылка на метод объекта**

```kotlin
class Person(val name: String) {
    fun introduce() {
        println("Hi, I'm $name")
    }
}

val person = Person("Bob")
val introduceRef = person::introduce
introduceRef() // Hi, I'm Bob
```
  

4. **Ссылка на конструктор**
```kotlin
class User(val name: String)

val userRef: (String) -> User = ::User
val user = userRef("Charlie")
println(user.name) // Charlie
```

5. **Ссылка на свойство** (property reference)
```kotlin
val nameRef = User::name      // KProperty: (User) -> String
println(nameRef.get(user))    // Charlie
// удобно в map: users.map(User::name)
```

> [!tip] Bound vs unbound references
> - **Unbound** (`User::introduce`) — первым параметром принимает приёмник: тип `(User) -> Unit`. Удобно в `list.map(User::name)`.
> - **Bound** (`person::introduce`) — приёмник уже «привязан»: тип `() -> Unit`.
> - Частое применение — передать существующую функцию вместо лямбды: `button.setOnClickListener(::onClick)` вместо `{ onClick() }`. Читаемее и не плодит лишний объект лямбды.
> - `::class` — это уже **ссылка на класс** (`KClass`), не на функцию.
