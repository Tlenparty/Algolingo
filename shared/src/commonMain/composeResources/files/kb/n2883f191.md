**✅ Основные методы класса Object:**

1. equals(Object obj)

• **Описание**: Метод используется для сравнения текущего объекта с другим объектом на **логическое равенство**.

• **Пример**:

```java
String str1 = new String("Hello");
String str2 = new String("Hello");
boolean areEqual = str1.equals(str2); // Возвращает true
```

2. hashCode()

• **Описание**: Метод возвращает **хеш-код объекта**, который используется в различных коллекциях, таких как HashMap или HashSet. Хеш-код должен быть согласован с методом equals(), т.е. если два объекта равны по equals(), то они должны иметь одинаковый хеш-код.

• **Пример**:

```java
String str = new String("Hello");
int hash = str.hashCode(); // Возвращает хеш-код строки
```

3. toString()

• **Описание**: Метод возвращает строковое представление объекта. Обычно используется для вывода объекта в виде строки.

• **Пример**:

```java
Object obj = new Object();
System.out.println(obj.toString()); // Выведет строковое представление объекта
```

4. getClass()

• **Описание**: Возвращает объект типа Class, который представляет тип текущего объекта.

• **Пример**:

```java
Object obj = new String("Hello");
Class<?> clazz = obj.getClass(); // Возвращает класс объекта
System.out.println(clazz.getName()); // Выведет полное имя класса
```

5. clone()

• **Описание**: Метод создает **копию** текущего объекта. Для использования этого метода класс должен реализовывать интерфейс Cloneable. Если объект не поддерживает клонирование, будет выброшено исключение CloneNotSupportedException.

• **Пример**:

```java
class MyClass implements Cloneable {
    int value;

    MyClass(int value) {
        this.value = value;
    }

    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone(); // Клонирование объекта
    }
}

MyClass obj1 = new MyClass(10);
MyClass obj2 = (MyClass) obj1.clone(); // Создание копии объекта
```

6. notify()

• **Описание**: Метод уведомляет один из потоков, ожидающих на объекте, что он может продолжить выполнение. Поток, вызвавший notify(), должен иметь **монитор** этого объекта.

```java
synchronized (obj) {
    obj.notify(); // Пробуждает один поток, ожидающий на объекте obj
}
```

7. notifyAll()

• **Описание**: Метод уведомляет все потоки, которые ожидают на объекте, что они могут продолжить выполнение.

• **Пример**:
```java
synchronized (obj) {
    obj.notifyAll(); // Пробуждает все потоки, ожидающие на объекте obj
}
```

8. wait()

• **Описание**: Метод заставляет текущий поток ожидать (блокируется) до тех пор, пока другой поток не вызовет notify() или notifyAll() на том же объекте.

• **Пример**:

```java
synchronized (obj) {
    obj.wait(); // Текущий поток будет ожидать
}
```

> [!important] Чем `Any` в Kotlin отличается от `Object` в Java
> Корень иерархии в Kotlin — `Any`, и он объявляет **только три метода**: `equals()`, `hashCode()`, `toString()`. Остальных методов `java.lang.Object` в `Any` **нет**:
> - `wait()` / `notify()` / `notifyAll()` — убраны намеренно: низкоуровневая синхронизация на мониторе считается устаревшей, в Kotlin используют корутины/`Mutex`/конкурентные структуры.
> - `getClass()` → в Kotlin `obj::class` (`KClass`) или `obj.javaClass`.
> - `clone()` → нет; копирование делают через `copy()` у `data class`.
> При компиляции под JVM `Any` всё равно ложится на `java.lang.Object`, поэтому из Kotlin можно дотянуться до `(obj as Object).wait()`, но это антипаттерн.
