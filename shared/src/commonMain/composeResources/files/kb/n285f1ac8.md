Задачка от вк на лайфкодинг:

  

// Задача:

// Дана скобочная последовательность из 3х видов скобок - ``'(', '{' и '['. ``
// Нужно написать программу, которая
// при возможности достраивает эту последовательность до 
// правильной добавлением символов в конец последовательности,
// или определяет, что это невозможно.


// Входные данные:

// На вход функции будет подана строка, содержащая последовательность

  // Выходные данные:

// Верните строку, содержащую символы, добавление которых 
// в конец последовательности достроит ее до 
// правильной, или null если такой строки не существует.

  
// Пример:

// Вход:

//``{([])[{()``

// Выход:

// ``}]}``

  

// Вход:

// ``(()){]}``

// Выход:

// null

## Решение

Идея: проходим по строке со **стеком** открывающих скобок. На закрывающую скобку проверяем вершину стека — если не совпала, последовательность **невалидна** → `null`. В конце для оставшихся открытых скобок (снизу вверх по стеку) дописываем их закрывающие пары в обратном порядке.

```kotlin
fun completeBrackets(input: String): String? {
    val pairs = mapOf('(' to ')', '{' to '}', '[' to ']')
    val opens = pairs.keys
    val stack = ArrayDeque<Char>()

    for (ch in input) {
        when (ch) {
            in opens -> stack.addLast(ch)
            else -> {
                // закрывающая: должна закрывать последнюю открытую
                val last = stack.removeLastOrNull() ?: return null
                if (pairs[last] != ch) return null
            }
        }
    }

    // дописываем закрывающие для оставшихся открытых (с вершины стека)
    return buildString {
        while (stack.isNotEmpty()) {
            append(pairs[stack.removeLast()])
        }
    }
}

fun main() {
    println(completeBrackets("{([])[{()"))  // }]}
    println(completeBrackets("(()){]}"))    // null
}
```

> [!tip] Разбор
> - **`{([])[{()`** → в стеке остаются `{ [ {` → закрываем с вершины: `}` `]` `}` → **`}]}`**.
> - **`(()){]}`** → на `]` вершина стека `{`, пара не совпала → **`null`**.
> - Сложность — **O(n)** по времени и памяти (стек). Это классическая «valid parentheses» с достройкой хвоста.
