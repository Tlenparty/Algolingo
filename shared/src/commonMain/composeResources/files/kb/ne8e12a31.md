**Дан граф в виде списка смежности. Необходимо найти все вершины, достижимые из заданной стартовой вершины.

**Пример:**
**Входные данные:****

```kotlin
//Граф представлен в виде словаря Map<Int, List<Int>>, где ключ — вершина, а значение — список её соседей.

Граф (список смежности):
1: 2, 3
2: 4
3: 5
4: 
5: 

Достижимые вершины: 1, 2, 3, 4, 5
```

Решение 

```kotlin
fun bfs(graph: Map<Int, List<Int>>, start: Int): List<Int> {
    val visited = mutableSetOf<Int>() // Множество посещённых вершин
    val queue = ArrayDeque<Int>()    // Очередь для BFS

    // Добавляем стартовую вершину в очередь
    queue.add(start)
    visited.add(start)

    while (queue.isNotEmpty()) {
        val current = queue.removeFirst() // Извлекаем текущую вершину

        // Добавляем всех соседей, которые ещё не были посещены
        for (neighbor in graph[current] ?: emptyList()) {
            if (neighbor !in visited) {
                visited.add(neighbor)
                queue.add(neighbor)
            }
        }
    }

    // Возвращаем список достижимых вершин
    return visited.toList()
}

fun main() {
    // Пример графа в виде списка смежности
    val graph = mapOf(
        1 to listOf(2, 3),
        2 to listOf(4),
        3 to listOf(5),
        4 to emptyList(),
        5 to emptyList()
    )
    
	1-2
	| |
	3 4
	|
	5
	
    val startVertex = 1
    val reachableVertices = bfs(graph, startVertex)

    println("Достижимые вершины: ${reachableVertices.joinToString(", ")}")
}
```

****Объяснение кода:**

1. **Список смежности:**

• Граф представлен в виде словаря ``Map<Int, List<Int>>``, где ключ — вершина, а значение — список её соседей.

2. **Очередь (queue):**

• Используется для хранения вершин, которые нужно обработать.

3. **Множество посещённых вершин:**

• Хранит вершины, которые уже обработаны, чтобы избежать зацикливания.

4. **Алгоритм:**

• Добавляем стартовую вершину в очередь.

• Пока очередь не пуста:

• Извлекаем вершину из очереди.

• Добавляем в очередь всех её соседей, которые ещё не посещены.

• Повторяем, пока не обработаем все вершины.

5. **Результат:**

• Возвращается список всех достижимых вершин.
