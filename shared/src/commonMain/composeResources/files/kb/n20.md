Дана последовательность чисел Int.MIN_VALUE до Int.MAX_VALUE, нужно проверить есть ли для каждого числа противоположная пара, для 1 — -1, для -2 — 2, и так далее, если у тебя -1 встречается 2 раза, то и 1 должна встречаться 2 раза

**Алгоритм:**

1. Проходим по всем числам и записываем их количество в Map.
2. Проверяем, что у каждого x есть -x с тем же количеством.
3. Проверяем, что 0 встречается чётное число раз.

```kotlin
fun hasOppositePairs(numbers: List<Int>): Boolean {
    val countMap = mutableMapOf<Int, Int>()  // Словарь для подсчёта количества чисел

    // 1️⃣ Считаем, сколько раз встречается каждое число
    for (num in numbers) {
        countMap[num] = countMap.getOrDefault(num, 0) + 1
    }

    // 2️⃣ Проверяем условия
    for ((num, count) in countMap) {
        if (num == 0) {
            // ❗ 3️⃣ Число 0 должно встречаться чётное число раз
            if (count % 2 != 0) return false
        } else {
            // ❗ 4️⃣ У каждого числа x должно быть ровно столько же -x
            if (countMap[num] != countMap.getOrDefault(-num, 0)) return false
        }
    }
    
    return true  // ✅ Всё верно
}
```

💡 **Что здесь происходит?**

• **Берём число** num
• **Смотрим, сколько раз оно уже есть в** countMap (getOrDefault(num, 0))
• **Увеличиваем счётчик этого числа на 1**

Пример
val numbers = listOf(1, -1, 2, -2, 2, 0, 0, -2)
countMap будет:
```kotlin
{
    1 -> 1,
    -1 -> 1,
    2 -> 2,
    -2 -> 2,
    0 -> 2
}
```

 **Шаг 2: Проверяем условия**

Теперь нам нужно пройти по countMap и проверить:

1. Если num == 0, то оно должно встречаться **чётное число раз**.
2. Для каждого x должно быть столько же -x.


**🔹 Проверка нуля**
```kotlin
if (num == 0) {
    if (count % 2 != 0) return false
}
```

**🔹 Проверка противоположных пар**
```kotlin
if (countMap[num] != countMap.getOrDefault(-num, 0)) return false
```

• **Проверяем, есть ли у** num **такое же количество** -num**.**
• Если у 2 встречается 2 раза, но -2 встречается 1 раз → ❌ ошибка.

**📊 Анализ сложности**

| Шаг                                | Операция |
| ---------------------------------- | -------- |
| Подсчёт элементов (countMap)       | O(n)     |
| Проверка условий (for по countMap) | O(n)     |
| **Общая сложность**                | O(n)     |

### Даны два слова. Нужно определить, **состоят ли они из одинакового набора букв с учётом их количества**.


✅ **Примеры:**

| **Слово 1** | **Слово 2** | **Ответ** | **Объяснение**                           |
| ----------- | ----------- | --------- | ---------------------------------------- |
| йцукен      | некуцй      | ✅ true    | Одинаковые буквы в одинаковом количестве |
| ффффа       | фффа        | ❌ false   | В первом слове 4 ф, во втором — 3        |
| hello       | ohlle       | ✅ true    | Одинаковый состав                        |
| test        | ttew        | ❌ false   | В первом слове нет w                     |

**🚀 Алгоритм решения**

1. **Посчитать частоту каждой буквы** в обоих словах.
2. **Сравнить полученные частотные словари (Map)**.
3. Если частотные словари равны, значит, слова состоят из одних и тех же букв в одинаковом количестве → true.
4. Если различаются — false.

Решение :

```kotlin
fun haveSameLetters(word1: String, word2: String): Boolean {
    return word1.groupingBy { it }.eachCount() == word2.groupingBy { it }.eachCount()
}
```

Решение с помощью hash map 

```kotlin
fun haveSameLetters(word1: String, word2: String): Boolean {
    if (word1.length != word2.length) return false  // Быстрая проверка по длине

    fun buildFrequencyMap(word: String): HashMap<Char, Int> {
        val map = HashMap<Char, Int>()
        for (char in word) {
            map[char] = map.getOrDefault(char, 0) + 1
        }
        return map
    }

    return buildFrequencyMap(word1) == buildFrequencyMap(word2)
}
```

**Как работает этот код?**

• Проходим по **каждой букве** слова.
• **Записываем в** HashMap, сколько раз встречается каждая буква.
• **Если буква уже есть**, увеличиваем счётчик +1.

✍ **Пример работы** buildFrequencyMap("hello")**:**
```kotlin
{
    h -> 1,
    e -> 1,
    l -> 2,
    o -> 1
}
```

👉 **Мы решили задачу за** O(n)**, что очень эффективно!** 🚀
