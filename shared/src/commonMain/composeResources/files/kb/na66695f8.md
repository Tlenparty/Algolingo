Функции let, apply, with, run, и also — это так называемые **scope-функции** в Kotlin, которые позволяют работать с объектами в контексте их существования, выполняя какие-то действия внутри блока кода. Эти функции позволяют сократить код и улучшить его читаемость, а также изменяют контекст вызова.

### **1. let**

• **Описание**: Функция let выполняет действия с объектом, а затем возвращает результат последнего выражения в блоке. Обычно используется для работы с объектами и для выполнения операций в случае, если объект не null (особенно в комбинации с ?.).

• **Возвращаемое значение**: Результат последнего выражения в блоке.
• **Контекст**: Внутри блока объект доступен через it.

**Пример**:

```kotlin

val name: String? = "John"
val length = name?.let {
    println(it)  // it - это имя "John"
    it.length   // возвращаем длину строки
}
println(length)  // 4
```

### **2. apply**

• **Описание**: Функция apply используется для конфигурации объекта. Она выполняет действия с объектом, но возвращает сам объект. Обычно используется для инициализации объекта.
• ==**Возвращаемое значение**: Сам объект.==
• apply чаще используется для инициализации или конфигурации объекта, когда вы хотите настроить объект, например, установить значения его свойств.
• **Контекст**: Внутри блока объект доступен через this.
• В apply объект доступен через this, который является ссылкой на объект внутри блока. Это позволяет использовать объект непосредственно в блоке, и **возвращает сам объект**.

**Пример**:

```kotlin
val person = Person().apply {
    name = "John"
    age = 30
}
println(person.name)  // John
println(person.age)   // 30
```

### **3. with**

• **Описание**: Функция with используется для работы с объектом в контексте выполнения нескольких операций. Она не изменяет сам объект, но позволяет многократно ссылаться на него внутри блока.
• **Возвращаемое значение**: Результат последнего выражения в блоке.
• **Контекст**: Внутри блока объект доступен через this.

**Пример**

```kotlin
val person = Person("John", 30)
val result = with(person) {
    println(name)   // John
    println(age)    // 30
    name.length     // возвращаем длину имени
}
println(result)  // 4

```

### **4. run**

• **Описание**: Функция run выполняет блок кода с объектом и возвращает ==результат последнего выражения в блоке==. Также может использоваться для выполнения операций с nullable-объектами (вместо let).
• **Возвращаемое значение**: Результат последнего выражения в блоке.
• **Контекст**: Внутри блока объект доступен через this.

```kotlin
val person = Person("John", 30)
val result = person.run {
    println(name)   // John
    println(age)    // 30
    name.length     // возвращаем длину имени
}
println(result)  // 4
```

### **5. also**

• **Описание**: Функция also позволяет выполнять действия с объектом (например, логирование или проверку), но при этом возвращает сам объект, чтобы цепочка вызовов продолжалась.
• **Возвращаемое значение**: Сам объект.
• **Контекст**: Внутри блока объект доступен через it.
• В also объект доступен через it, который является неименованной ссылкой на объект, переданный в блок. Он используется в качестве аргумента для выполнения операций с этим объектом, но **возвращает сам объект**.
• also используется для выполнения побочных эффектов (например, логирования, отладки или изменения состояния объекта) с объектом, не изменяя его.

**Пример**:

```kotlin
val person = Person("John", 30)
person.also {
    println(it.name)  // John
    println(it.age)   // 30
}.apply {
    age = 31          // изменили возраст
}
println(person.age)  // 31
```

## Сводная таблица

| Функция  | Контекст (`this`/`it`) | Возвращает         | Типичное применение                              |
| -------- | ---------------------- | ------------------ | ------------------------------------------------ |
| `let`    | `it`                   | результат блока    | работа с nullable (`?.let`), трансформация       |
| `run`    | `this`                 | результат блока    | блок вычислений с доступом к членам объекта      |
| `with`   | `this` (аргумент)      | результат блока    | несколько операций над объектом (не extension)   |
| `apply`  | `this`                 | **сам объект**     | конфигурация/инициализация объекта               |
| `also`   | `it`                   | **сам объект**     | побочные эффекты (логирование) в цепочке          |

Мнемоника: **возвращают объект** → `apply`/`also`; **возвращают результат блока** → `let`/`run`/`with`. **`it`** → `let`/`also`; **`this`** → `run`/`with`/`apply`.

### **Когда использовать каждую функцию:**

• let: Когда нужно выполнить операцию с объектом и получить результат. Часто используется с nullable-типами.
• let обычно используется для работы с объектами внутри цепочек вызовов, или когда нужно работать с объектом, если он не равен null (вместе с оператором безопасного вызова ?.).

• apply: Когда нужно настроить объект, например, при создании и инициализации.
• apply — для **инициализации и изменения состояния** объекта, когда вы хотите настроить объект внутри блока и вернуть его изменённым.

• with: Когда нужно выполнить несколько операций с объектом и вернуть результат. Используется с конкретным объектом.

• run: Когда нужно выполнить блок кода с объектом и вернуть результат, особенно при использовании с nullable-типами
• run обычно используется для выполнения блока кода, который выполняет несколько операций и возвращает результат, часто с доступом к свойствам объекта через this.

• also: Когда нужно выполнить побочный эффект с объектом, например, для логирования, и вернуть сам объект
• also — для **побочных эффектов**, когда вам не нужно изменять объект, но вы хотите выполнить с ним какие-то действия (например, логирование).

### Вопрос про apply из Совкомбанка

Что будет выведено ? 

```kotlin
fun main() {
    val map = mapOf("Zero" to 0)        // неизменяемый Map
        .plus("First" to 1)             // создаётся новый Map
        .apply {
            this.plus("Second" to 2)    // результат отбрасывается — ничего не меняет
        }
    println(map.values)                 // [0, 1]
}
```

**Ответ: `[0, 1]`.** `apply {}` возвращает **тот же объект**, к которому применён (здесь — Map после `.plus("First" to 1)`). А `this.plus("Second" to 2)` создаёт **новую** Map, но её результат нигде не сохраняется → она тут же отправляется в GC. На исходный `map` это не влияет.

> [!tip] Ловушка задачи
> Подвох в том, что `plus` у Map **не мутирует**, а возвращает новую коллекцию. Внутри `apply` нужно использовать возвращаемое значение (например, через `run`/присваивание), а не вызывать «в пустоту». Это же отличает `apply` (возвращает receiver) от `run`/`let` (возвращают результат блока).
