**🚧 Основные ограничения для разработчиков:**

• **Разрешения на уведомления (POST_NOTIFICATIONS)**: С Android 13.
• **Ограничения на доступ к фоновым сервисам** (Android 11+).
• **Scoped Storage**: С Android 11 доступ к файлам ограничен.
• **Разделение Bluetooth-разрешений** (Android 12+).
• **Strict Mode для PendingIntent** (Android 12+): Обязательное указание Mutable или Immutable.

**🆚 API Level 36 (Android 16):**

📅 **Дата выхода:** 2025 год

🔑 **Основные изменения:**

• **Edge-to-edge принудительно**: для `targetSdk 36` приложение по умолчанию рисуется под системными барами — нужно корректно обрабатывать insets.
• **Предсказуемая обратная навигация (Predictive Back)**: дальнейшее развитие.
• Новые ограничения на фоновую работу и приватность.

**🆚 API Level 35 (Android 15):**

📅 **Дата выхода:** 2024 год

🔑 **Основные изменения:**

• **Foreground Service types**: обязательное указание типа foreground-сервиса.
• **Better Large Screen Support**: развитие поддержки складных устройств и планшетов.
• **Improved Privacy**: усиление ограничений на доступ к данным.

**🆚 API Level 34 (Android 14):**

📅 **Дата выхода:** Октябрь 2023

🔑 **Основные изменения:**

• **Background Task Scheduler**: Оптимизация фоновых задач через JobScheduler.
• **Custom Lock Screen Widgets**: Поддержка пользовательских виджетов на экране блокировки.
• **Improved Privacy Indicators**: Показ индикаторов использования камеры/микрофона в статус-баре.
• **Safer Implicit Intents**: Запрещены неявные PendingIntent, чтобы избежать утечек данных.
• **Health Connect API**: Унификация доступа к данным о здоровье и фитнесе.

**🆚 API Level 33 (Android 13):**

📅 **Дата выхода:** Август 2022

🔑 **Основные изменения:**

• **Runtime Permissions for Notifications**: Теперь пользователи должны разрешать уведомления (POST_NOTIFICATIONS).
• **Photo Picker API**: Новый безопасный выбор фотографий вместо прямого доступа к файлам.
• **Themed App Icons**: Поддержка динамических иконок в Material You.
• **Per-App Language Preferences**: Настройки языка для каждого приложения (AppLanguageManager).
• **Bluetooth LE Audio & MIDI 2.0**: улучшенная поддержка аудио по Bluetooth.

> [!tip] Что реально важно знать про API levels на собесе
> - **`minSdk`** — минимальная версия, на которой запустится приложение; **`targetSdk`** — версия, под чьё поведение «заточено» приложение (определяет, какие behavior changes к нему применяются); **`compileSdk`** — против какого SDK компилируем.
> - Повышение `targetSdk` — это про **behavior changes**: новые рантайм-разрешения (нотификации с 13), Scoped Storage (11), mutable/immutable `PendingIntent` (12), foreground service types (14–15), edge-to-edge (16).
> - Google Play **обязывает** поднимать `targetSdk` (обычно «текущая −1») для публикации обновлений.
