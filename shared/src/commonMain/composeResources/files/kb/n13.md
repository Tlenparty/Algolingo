**Пузырьковая сортировка** — это простой алгоритм сортировки, который сравнивает соседние элементы в массиве и меняет их местами, если они находятся в неправильном порядке. Этот процесс повторяется до тех пор, пока массив не будет отсортирован.

**Как работает пузырьковая сортировка:**

1. Алгоритм проходит по массиву несколько раз.
2. На каждой итерации сравниваются пары соседних элементов.
3. Если текущий элемент больше следующего, они меняются местами.
4. После каждой итерации самый большой элемент “всплывает” (как пузырёк) к своему правильному месту.

```kotlin
fun bubbleSort(array: IntArray) {
    val n = array.size

    // Внешний цикл: количество проходов
    for (i in 0 until n - 1) {
        // Внутренний цикл: сравнение соседних элементов
        for (j in 0 until n - i - 1) {
            if (array[j] > array[j + 1]) {
                // Меняем элементы местами, если они в неправильном порядке
                val temp = array[j]
                array[j] = array[j + 1]
                array[j + 1] = temp
            }
        }
    }
}

fun main() {
    val array = intArrayOf(5, 3, 8, 4, 2)
    println("Исходный массив: ${array.joinToString(", ")}")
    bubbleSort(array)
    println("Отсортированный массив: ${array.joinToString(", ")}")
}
```
