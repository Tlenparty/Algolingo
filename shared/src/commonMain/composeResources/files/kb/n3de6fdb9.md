# Structured Concurrency

**Structured Concurrency** (структурированная конкурентность) — это концепция, которая определяет, как управлять конкурентными (асинхронными) задачами, делая их выполнение структурированным, безопасным и предсказуемым. В Kotlin, Java и других языках она решает проблему хаотичного управления потоками и задачами, создавая чёткий порядок их жизненного цикла.

## Основные принципы

1. **Дерево задач.** Каждая асинхронная задача создаётся в контексте (scope) родительской задачи. Родитель отвечает за завершение всех своих дочерних задач перед тем, как завершиться сам.

2. **Локальная область задач.** Асинхронные задачи привязаны к конкретному блоку или функции. Когда блок завершается, все связанные задачи автоматически завершаются.

3. **Автоматическое управление временем жизни.** Не нужно вручную отслеживать, завершены ли задачи. Это снижает вероятность утечек ресурсов и ошибок синхронизации.

4. **Иерархическая отмена.** Если родительская задача отменена, все её дочерние задачи также отменяются.

## Как это выглядит в корутинах

`coroutineScope` не вернёт управление, пока не завершатся **все** запущенные внутри него корутины:

```kotlin
suspend fun loadDashboard(): Dashboard = coroutineScope {
    val profile = async { loadProfile() }   // дочерняя корутина
    val feed = async { loadFeed() }          // дочерняя корутина
    Dashboard(profile.await(), feed.await())
} // функция завершится только когда обе async-задачи отработают
```

Если `loadFeed()` бросит исключение — `loadProfile()` будет автоматически отменён, и `coroutineScope` пробросит ошибку наверх. Не останется «висящих» корутин.

> [!tip] Совет на собес
> - **`coroutineScope`** — если падает любая дочерняя корутина, отменяются все остальные (ошибки распространяются вверх).
> - **`supervisorScope`** — падение одной дочерней корутины **не** отменяет соседей (полезно для независимых задач, например параллельной загрузки нескольких виджетов экрана).
> - Антипаттерн, ломающий structured concurrency, — `GlobalScope.launch`: такая корутина живёт вне дерева задач, её никто не отменит → утечки.
