# Побитовые операции

Побитовые операции работают с **отдельными битами чисел**. Применяются в:

- **оптимизированных алгоритмах** (сжатие, быстрые вычисления);
- **манипуляции флагами** (права доступа, наборы опций в одном Int);
- **шифровании и хешировании**;
- **графике и обработке изображений** (распаковка ARGB-каналов цвета).

## Операторы в Kotlin

В Kotlin побитовые операции — это **инфиксные функции** (не символы `&`/`|`, как в Java), доступные для `Int` и `Long`:

| Kotlin   | Java | Описание                                  |
| -------- | ---- | ----------------------------------------- |
| `and`    | `&`  | побитовое И                               |
| `or`     | `\|` | побитовое ИЛИ                             |
| `xor`    | `^`  | исключающее ИЛИ                           |
| `inv()`  | `~`  | инверсия битов                            |
| `shl(n)` | `<<` | сдвиг влево на `n` бит                    |
| `shr(n)` | `>>` | сдвиг вправо (с сохранением знака)        |
| `ushr(n)`| `>>>`| беззнаковый сдвиг вправо (дополняет нулём)|

```kotlin
val a = 0b1100 // 12
val b = 0b1010 // 10

println(a and b) // 8  (0b1000)
println(a or b)  // 14 (0b1110)
println(a xor b) // 6  (0b0110)
println(a.inv()) // -13
println(1 shl 4) // 16 (сдвиг влево = умножение на 2^4)
println(16 shr 2)// 4  (сдвиг вправо = деление на 2^2)
```

## Пример: флаги в одном Int

Классический приём — хранить набор булевых опций в битах одного числа:

```kotlin
const val READ = 1 shl 0   // 0b001
const val WRITE = 1 shl 1  // 0b010
const val EXEC = 1 shl 2   // 0b100

var permissions = READ or WRITE      // выдать чтение и запись

val canWrite = permissions and WRITE != 0  // проверить флаг → true
permissions = permissions and EXEC.inv()   // снять флаг EXEC
```

> [!tip] Где встречается в Android
> - `View.SYSTEM_UI_FLAG_*`, `Intent`-флаги (`FLAG_ACTIVITY_NEW_TASK or FLAG_ACTIVITY_CLEAR_TASK`) — это битовые маски, объединяемые через `or`.
> - Цвет `Int` ARGB распаковывается сдвигами: `val red = (color shr 16) and 0xFF`.
> - `x and 1 == 0` — быстрая проверка на чётность; `x shl 1` / `x shr 1` — умножение/деление на 2.
