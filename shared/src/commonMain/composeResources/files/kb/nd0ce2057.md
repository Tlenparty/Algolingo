# Поиск в глубину (DFS)

**DFS (Depth-First Search)** — обход графа/дерева «вглубь»: идём по ветке до конца, потом возвращаемся (backtrack) и пробуем следующую. Парный к [[Задача на поиск в ширину|BFS]] алгоритм.

## Две реализации

```kotlin
// Рекурсивно (через стек вызовов)
fun dfs(node: Int, graph: Map<Int, List<Int>>, visited: MutableSet<Int>) {
    if (node in visited) return
    visited.add(node)
    // ... обработка node
    for (next in graph[node].orEmpty()) dfs(next, graph, visited)
}

// Итеративно (явный стек) — без риска StackOverflow
fun dfsIterative(start: Int, graph: Map<Int, List<Int>>) {
    val visited = mutableSetOf<Int>()
    val stack = ArrayDeque<Int>()
    stack.addLast(start)
    while (stack.isNotEmpty()) {
        val node = stack.removeLast()        // LIFO — отличие от BFS
        if (node in visited) continue
        visited.add(node)
        for (next in graph[node].orEmpty()) stack.addLast(next)
    }
}
```

> [!important] DFS vs BFS — главное различие
> • **DFS — стек (LIFO)**, идёт вглубь. **BFS — очередь (FIFO)**, идёт по уровням.
> • **BFS** находит **кратчайший путь** в невзвешенном графе (по числу рёбер); **DFS — нет**.
> • DFS экономнее по памяти на «глубоких узких» графах (O(глубины)), BFS — на «широких» хуже (O(ширины)).
> • DFS естественно ложится на рекурсию; BFS — на явную очередь.

> [!warning] `visited` обязателен на графах с циклами
> Без множества посещённых DFS зациклится на графе с циклами (и повторно обойдёт узлы в DAG). На **дереве** (циклов нет) `visited` не нужен. Частая ошибка — забыть отметить узел или отметить его слишком поздно.

## Где применяется (узнать задачу)

> [!tip] Сигналы «это DFS/backtracking»
> • **Обход дерева** — pre/in/post-order (это и есть DFS).
> • **Связные компоненты**, «количество островов» (number of islands), заливка (flood fill).
> • **Поиск цикла**, топологическая сортировка (DFS + стек завершения).
> • **Backtracking** — перебор с откатом: перестановки, комбинации, судоку, расстановка — DFS по дереву решений с возвратом.
> • Путь существует ли между A и B (но не кратчайший — для кратчайшего BFS).

> [!note] Сложность и подвох с рекурсией
> • Время **O(V + E)** (вершины + рёбра), память O(V) на `visited` + O(глубины) на стек.
> • **Рекурсивный DFS на глубоком графе → `StackOverflowError`** (на Android стек потока ограничен). На больших данных — итеративная версия с явным `ArrayDeque`. Это связано с [[Heap & Stack]] (стек вызовов конечен).
