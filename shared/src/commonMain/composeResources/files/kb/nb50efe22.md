# Типы семантики в JVM

JVM описывается через несколько видов семантики — формальных правил того, как ведёт себя виртуальная машина.

## 1. Операционная семантика (Operational Semantics)

- Описывает, как именно JVM выполняет байт-код шаг за шагом.
- Включает интерпретацию инструкций, выполнение методов, управление стеком, обработку исключений и вызовы нативных методов.

## 2. Семантика синхронизации (Synchronization Semantics)

- Описывает, как обеспечивается корректность многопоточного исполнения.
- Основана на модели памяти Java (**Java Memory Model, JMM**), которая регулирует порядок операций чтения/записи в многопоточном окружении.
- Гарантирует, что конструкции `synchronized`, `volatile` и другие средства синхронизации приводят к корректной видимости данных между потоками.

## 3. Семантика исключений (Exception Semantics)

- Определяет, как JVM обрабатывает исключения, возникшие во время выполнения программы.
- Включает:
    - поиск подходящего обработчика (`catch`-блока);
    - развёртывание стека вызовов (stack unwinding).

## 4. Семантика типов (Type Semantics)

- Описывает, как JVM проверяет типы во время компиляции и выполнения (включая динамическую проверку типов).
- Основана на строгой системе типов: например, нельзя присвоить значение типа `String` переменной типа `int`.

## 5. Семантика безопасности (Safety Semantics)

- Определяет, как JVM гарантирует безопасность выполнения кода:
    - проверка корректности байт-кода через **Bytecode Verifier**;
    - защита памяти (предотвращение выхода за пределы массива);
    - контроль доступа к методам и полям через модификаторы (`private`, `protected`, `public`).

## 6. Семантика памяти (Memory Semantics)

- Управляет взаимодействием между потоками через память.
- Регулирует видимость изменений, порядок выполнения операций и работу с кэшами процессора.

> [!note] Что важно для собеседования
> На практике почти всегда спрашивают именно про **семантику синхронизации / памяти** — то есть про [[Happens before|happens-before]] и JMM. Остальные виды семантики полезны для общей эрудиции, но реже всплывают на интервью.
