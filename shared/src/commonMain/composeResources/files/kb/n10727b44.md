**1️⃣ Обязательный вызов primary constructor**

Если в классе **есть первичный конструктор**, то **каждый вторичный конструктор обязан его вызвать** (напрямую или косвенно).

```kotlin
class Person(val name: String) {
    // ❌ Ошибка! Вторичный конструктор не вызывает primary constructor
    constructor() 
}
```

**✅ Исправленный вариант**
```kotlin
class Person(val name: String) {
    constructor() : this("Default Name") // ✅ Вызываем primary constructor
}
```

**2️⃣ val/var нельзя объявлять во secondary constructor**

В отличие от первичного конструктора, **во вторичном нельзя объявлять** val **или** var **свойства**.

```kotlin
class Person {
    constructor(val name: String) // ❌ Ошибка! Нельзя объявлять `val/var`
}
```

**✅ Исправленный вариант**

```kotlin
class Person {
    val name: String

    constructor(name: String) {
        this.name = name // ✅ Сохраняем в `this`
    }
}
```

**3️⃣ secondary constructor нельзя использовать в data class**

В data class **все параметры должны быть в** primary constructor, иначе компилятор выдаст ошибку.

```kotlin
data class User(val name: String) {
    constructor() : this("Default") // ❌ Ошибка! Нельзя использовать вторичный конструктор
}
```

**4️⃣ secondary constructor не поддерживает default значения**

В отличие от **первичного конструктора**, во **вторичном нельзя указывать** default **параметры**.

```kotlin
  class Person {
    constructor(name: String = "Default") // ❌ Ошибка! `default` параметры запрещены
}
```

**5️⃣ super должен быть вызван явно, если есть родительский класс**

Если класс наследует другой класс, **вторичный конструктор обязан вызвать** super.

```kotlin
open class Animal(val name: String)

class Dog : Animal {
    constructor() // ❌ Ошибка! Не вызван `super`
}
```

```kotlin
open class Animal(val name: String)

class Dog : Animal {
    constructor() : super("Default Dog") // ✅ Вызываем `super`
}
```

**6️⃣ this или super должны быть первыми в secondary constructor**

Если secondary constructor вызывает другой конструктор, то this(...) **или** super(...) **должны быть первой строкой**.

```kotlin
class Person(val name: String) {
    constructor() {
        println("Init block") // ❌ Ошибка! `this()` должен быть первым
        this("Default")
    }
}
```

```kotlin
class Person(val name: String) {
    constructor() : this("Default") { 
        println("Init block") // ✅ Теперь `this("Default")` вызывается первым
    }
}
```

**7️⃣ init блок выполняется перед secondary constructor**

Когда объект создаётся, **сначала выполняется** init {} **блок, а затем** secondary constructor.

```kotlin
class Example(val name: String) {
    init {
        println("Init block: $name")
    }

    constructor() : this("Default") {
        println("Secondary constructor")
    }
}

fun main() {
    Example()
}
```

Выведет:

```text
Init block: Default
Secondary constructor
```

> [!important] Порядок инициализации
> `init {}`-блоки и инициализаторы свойств выполняются **в составе первичного конструктора**. Вторичный конструктор сначала (через `this(...)`) делегирует первичному → отрабатывают `init`-блоки → и только потом выполняется **тело** вторичного конструктора. Поэтому `init` всегда раньше тела secondary.

> [!tip] Когда вообще нужен вторичный конструктор
> В Kotlin он нужен **редко** — обычно его заменяют **параметрами по умолчанию** в первичном конструкторе:
> ```kotlin
> class Person(val name: String = "Default")  // вместо secondary constructor
> ```
> Вторичные конструкторы оправданы при интеропе с Java или когда нужно несколько разных способов создания с логикой. Для сложного создания лучше [[Паттерны|фабричный метод]] в `companion object`.
