# HashSet

Множество уникальных элементов на основе хеш-таблицы. Внутри — [[HashMap]].

> **На собес одной фразой:** `HashSet` реализован поверх `HashMap`: элемент кладётся как **ключ**, значение — константа-заглушка `PRESENT`. Уникальность и `O(1)`-доступ наследуются от `HashMap`.

## Особенности

1. **Уникальность** — дубликаты игнорируются (`add` вернёт `false`).
2. **Неупорядоченность** — порядок элементов не гарантирован.
3. **Быстрые `add` / `contains` / `remove`** — `O(1)` в среднем (зависит от качества `hashCode`).

## Когда использовать

- **Удаление дубликатов** из коллекции.
- **Быстрая проверка наличия** элемента (`contains`).
- Нужна **гарантия уникальности** элементов.

## Как работает под капотом

`HashSet` хранит элементы как **ключи** внутреннего `HashMap`, а значением ставит общую константу-заглушку `PRESENT`. Поскольку ключи в `HashMap` уникальны — уникальны и элементы множества.

```java
// Упрощённо из JDK
public class HashSet<E> {
    private transient HashMap<E, Object> map;
    private static final Object PRESENT = new Object(); // заглушка-значение

    public boolean add(E e)           { return map.put(e, PRESENT) == null; }
    public boolean contains(Object o) { return map.containsKey(o); }
    public boolean remove(Object o)   { return map.remove(o) == PRESENT; }
}
```

## Сходство и отличия

- **vs `ArrayList`** — тоже коллекция, но `HashSet` гарантирует уникальность и **не хранит порядок** вставки.
- **vs `HashMap`** — использует `HashMap` внутри, но у элементов нет связанного значения (только ключи).

## Пример

```kotlin
val set = HashSet<String>()

set.add("Привет")
set.add("Мир")
set.add("Привет")               // дубликат — проигнорирован

val hasHello = set.contains("Привет") // true
set.remove("Привет")
val size = set.size             // 1
```

> ⚠️ Уникальность работает только при корректных `equals`/`hashCode`. Для обычного класса без их переопределения два «одинаковых» объекта считаются разными — используйте `data class`.
