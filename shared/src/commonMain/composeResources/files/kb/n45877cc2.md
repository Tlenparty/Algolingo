**ML Kit Barcode Scanning** — это мощный инструмент от Google, который позволяет сканировать штрихкоды и QR-коды прямо в мобильном приложении. Он работает **локально**, не требует подключения к интернету и поддерживает **различные типы кодов** (QR, UPC, EAN, PDF417 и т. д.).

### **🔍 Как работает ML Kit Barcode Scanning?**

**1. Захват изображения**

• Используется **камера устройства** (через CameraX или Camera2 API).
• Можно сканировать **в реальном времени** или **анализировать уже сделанные фото**.


**2. Обнаружение и декодирование штрихкодов**

• ML Kit использует **оптимизированные модели машинного обучения** для поиска штрихкодов в кадре.
• Если найден код → **он автоматически декодируется**.


**3. Получение результата**

• SDK возвращает **тип кода** (например, QR или EAN-13).
• Расшифрованные **данные** (например, ссылка, Wi-Fi настройки, текст).


### **📌 Как интегрировать ML Kit Barcode Scanning в Android?**


**1️⃣ Добавляем зависимость в build.gradle.kts**
```kotlin
dependencies {
    implementation("com.google.mlkit:barcode-scanning:17.2.0") // Последняя версия
}
```

**2️⃣ Настраиваем BarcodeScanner**
```kotlin
import com.google.mlkit.vision.barcode.Barcode
import com.google.mlkit.vision.barcode.BarcodeScanning
import com.google.mlkit.vision.common.InputImage
import android.graphics.Bitmap
import android.net.Uri
import android.content.Context

fun scanBarcodeFromBitmap(bitmap: Bitmap, context: Context) {
    val image = InputImage.fromBitmap(bitmap, 0) // Преобразуем изображение в формат ML Kit
    val scanner = BarcodeScanning.getClient() // Получаем инстанс сканера

    scanner.process(image)
        .addOnSuccessListener { barcodes ->
            for (barcode in barcodes) {
                val value = barcode.rawValue // Декодированное значение
                println("📌 Сканировано: $value")
            }
        }
        .addOnFailureListener { e ->
            println("🚨 Ошибка сканирования: ${e.message}")
        }
}
```

✅ **Этот код можно использовать для анализа изображений из галереи или камеры.**

### **3️⃣ Реальное время: Используем CameraX**

Если нужен **реальный поток с камеры**, лучше использовать **CameraX**.

📌 **Добавляем зависимость для CameraX:**
📌 **Настраиваем CameraX для передачи данных в ML Kit:**

```kotlin
val imageAnalysis = ImageAnalysis.Builder()
    .setBackpressureStrategy(ImageAnalysis.STRATEGY_KEEP_ONLY_LATEST)
    .build()

imageAnalysis.setAnalyzer(Executors.newSingleThreadExecutor()) { imageProxy ->
    val rotationDegrees = imageProxy.imageInfo.rotationDegrees
    val image = InputImage.fromMediaImage(imageProxy.image!!, rotationDegrees)

    val scanner = BarcodeScanning.getClient()
    scanner.process(image)
        .addOnSuccessListener { barcodes ->
            for (barcode in barcodes) {
                println("✅ Найден код: ${barcode.rawValue}")
            }
        }
        .addOnFailureListener { e ->
            println("🚨 Ошибка: ${e.message}")
        }
        .addOnCompleteListener {
            imageProxy.close() // Важно закрывать imageProxy, иначе поток зависнет
        }
}
```

📌 **Если нужно распознавать только QR-коды для оптимизации, можно передать BarcodeScannerOptions:**
```kotlin
val options = BarcodeScannerOptions.Builder()
    .setBarcodeFormats(Barcode.FORMAT_QR_CODE)
    .build()

val scanner = BarcodeScanning.getClient(options)
```

> [!tip] Нюансы ML Kit Barcode
> - **`imageProxy.close()` обязателен** в CameraX-анализаторе (в `addOnCompleteListener`) — иначе конвейер кадров «зависнет» (новые кадры не придут).
> - Ограничивай форматы через `BarcodeScannerOptions` (`FORMAT_QR_CODE`) — быстрее и точнее, чем сканировать все типы.
> - **Готовый сканер без своего UI:** `com.google.android.gms:play-services-code-scanner` (`GmsBarcodeScanning`) — Google даёт полноэкранный сканер «из коробки», не нужно возиться с CameraX.
> - Работает **офлайн** (модели на устройстве), не требует интернета.
