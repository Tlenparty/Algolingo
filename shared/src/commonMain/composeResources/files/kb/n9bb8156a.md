**✅ 1. Преобразования (Transformation)**

Эти анимации изменяют визуальные характеристики View.

**1.1 Трансформация объектов (изменение масштаба, поворота, смещения)**

• **Scale Animation (Масштабирование)**: изменяет размер View.
• Пример: Увеличение или уменьшение размера элемента.
```xml
<scale
    android:duration="500"
    android:fromXScale="1.0"
    android:fromYScale="1.0"
    android:toXScale="2.0"
    android:toYScale="2.0" />
```
  

• **Rotate Animation (Поворот)**: поворачивает View на определенный угол.

```xml
<rotate
    android:duration="500"
    android:fromDegrees="0"
    android:toDegrees="360" />
```

• **Translate Animation (Перемещение)**: изменяет положение View в пространстве.

```xml
<translate
    android:duration="500"
    android:fromXDelta="0"
    android:toXDelta="200" />
```

• **Alpha Animation (Прозрачность)**: изменяет прозрачность View.

```xml
<alpha
    android:duration="500"
    android:fromAlpha="1.0"
    android:toAlpha="0.0" />
```

**1.2 Комбинированные анимации**

Вы можете комбинировать несколько анимаций в одну с помощью AnimationSet.

```xml
<set
    android:duration="1000">
    <scale
        android:fromXScale="1.0"
        android:toXScale="2.0"/>
    <translate
        android:fromXDelta="0"
        android:toXDelta="200"/>
</set>
```


**✅ 2. Секвенциальные анимации (Animator)**

Это более сложные анимации, которые применяются через **Property Animations (Animator)** API, а не через старое ViewAnimation API.

**2.1 ObjectAnimator: анимирует изменения свойств объектов**

```kotlin
ObjectAnimator.ofFloat(view, "alpha", 1.0f, 0.0f).apply {
    duration = 500
    start()
}
```

**2.2 ValueAnimator: анимация изменения значений (например, чисел, координат и т. д.)**

```kotlin
ValueAnimator.ofInt(0, 100).apply {
    duration = 500
    addUpdateListener { animation ->
        val value = animation.animatedValue as Int
        // Обновляем свойство
    }
    start()
}
```

**2.3 AnimatorSet: позволяет комбинировать несколько анимаций в последовательность или параллельное выполнение**

```kotlin
AnimatorSet().apply {
    playTogether(animator1, animator2) // параллельно (playSequentially — последовательно)
    start()
}
```

**✅ 3. Анимации переходов (Transitions)**

Анимации переходов используются для анимации изменений между состояниями View или фрагментов.

**3.1 Scene Transition (Переход между состояниями сцены):**

• Эти анимации позволяют анимировать переход между различными View или макетами.

```kotlin
Scene scene1 = Scene.getSceneForLayout(container, R.layout.scene1, context);
Scene scene2 = Scene.getSceneForLayout(container, R.layout.scene2, context);
Transition transition = new Slide();
TransitionManager.go(scene2, transition);
```

**3.2 Explode, Fade, Slide (Переходы в FragmentTransaction)**

• **Fade**: плавное исчезновение и появление элементов.
• **Slide**: сдвиг элементов на экране.
• **Explode**: анимация, когда элементы появляются или исчезают, как будто взрываются.

```kotlin
FragmentTransaction transaction = fragmentManager.beginTransaction();
transaction.setTransition(FragmentTransaction.TRANSIT_FRAGMENT_FADE);
transaction.replace(R.id.container, fragment);
transaction.addToBackStack(null);
transaction.commit();
```


**✅ 4. Свойства анимации для UI элементов**

Эти анимации воздействуют на **элементы интерфейса** в процессе их показа/скрытия или изменения.

**4.1 ViewPropertyAnimator:**

Удобный способ анимировать свойства View через chainable методы.

```kotlin
view.animate()
    .translationX(200f)
    .alpha(0.5f)
    .setDuration(500)
    .start()
```

**4.2 Circular Reveal Animation (анимированный круговой переход)**

```kotlin
ViewAnimationUtils.createCircularReveal(view, centerX, centerY, startRadius, endRadius)
    .setDuration(500)
    .start();
```

**✅ 5. MotionLayout (для более сложных анимаций)**

MotionLayout используется для создания сложных анимаций и переходов между различными состояниями макета с использованием **ConstraintLayout**.

• Это мощный инструмент для создания анимаций переходов, подобных тому, как работает анимация в iOS. Использует XML и код для определения анимаций.


**✅ 6. Списки (RecyclerView)**

**6.1 ItemAnimator** — анимация добавления, удаления и изменения элементов в `RecyclerView` (по умолчанию `DefaultItemAnimator`). Чтобы анимации перестановки работали корректно, нужен `DiffUtil`/`ListAdapter` со стабильными ключами (см. [[RecyclerView, Diff Utils, List Adapter]]).

> [!important] Три семейства анимаций — не путать
> 1. **View Animation (старое, `android.view.animation`)** — `scale`/`rotate`/`translate`/`alpha` в XML. **Анимирует только отрисовку**, не реальные свойства View: после анимации View «прыгает» назад, а тач-зоны остаются на старом месте. Устарело.
> 2. **Property Animation (`android.animation`, с API 11)** — `ObjectAnimator`/`ValueAnimator`/`ViewPropertyAnimator`. **Меняет реальные свойства** объекта (включая тач-зоны). Современный стандарт для View.
> 3. **Transitions / MotionLayout** — для переходов между состояниями/экранами.
>
> На собесе ключевое: **View Animation vs Property Animation** — первое рисует «обманку», второе реально двигает объект.

> [!tip]
> - **`ViewPropertyAnimator`** (`view.animate()...`) — самый удобный для простых анимаций одной View; внутри использует Property Animation и идёт через [[Render Thread]].
> - В **Compose** анимации устроены иначе — `animate*AsState`, `updateTransition`, `AnimatedVisibility` (см. [[Compose. Анимации]]).
