## 1. Hash Map — частоты
🔑 **Маркеры:** «сколько раз», «частота», «первый уникальный», «two sum без сортировки», «сгруппировать».
```kotlin
val cnt = HashMap<T, Int>()
for (x in items) cnt[x] = cnt.getOrDefault(x, 0) + 1
// доступ к частоте за O(1)
```
⚠️ Грабли: `getOrDefault`, не забудь второй проход, если ищешь «первый». 🗣 «Меняю O(n²) на O(n) через Map».

---

## 2. Hash Set — наличие
🔑 **Маркеры:** «есть ли дубликат», «уникальность», «встречался ли», «пересечение множеств».
```kotlin
val seen = HashSet<T>()
for (x in items) if (!seen.add(x)) return true // add вернул false → уже было
```
⚠️ `add` возвращает false при дубле — удобно. 🗣 «Наличие/уникальность → Set за O(n)».

---

## 3. Два указателя навстречу
🔑 **Маркеры:** «отсортированный массив» + «пара/тройка/сумма», «палиндром», «container/вода».
```kotlin
var l = 0; var r = n - 1
while (l < r) {
    when {
        ok(l, r)     -> { /* ответ, либо l++; r-- */ }
        нужноБольше  -> l++
        else         -> r--
    }
}
```
⚠️ Условие `l < r` (не `<=`), иначе возьмёшь элемент дважды. 🗣 «Отсортировано + пара → края навстречу, O(1) памяти».

---

## 4. Два указателя в одну сторону (fast/slow)
🔑 **Маркеры:** «на месте», «сохранить порядок», «удалить дубликаты/нули», «цикл в связном списке».
```kotlin
var slow = 0
for (fast in 0 until n) {
    if (нужноОставить(fast)) {
        nums[slow] = nums[fast] // перезаписываем «хорошими»
        slow++
    }
}
return slow // длина/граница результата
```
⚠️ slow — куда пишем, fast — что читаем. 🗣 «Перегруппировать на месте → медленный пишет, быстрый читает».

## 5. Скользящее окно (переменное)
🔑 **Маркеры:** «непрерывный подмассив/подстрока», «без повторов», «максимальная/минимальная длина при условии», «сумма ≥ K».
```kotlin
var left = 0; var best = 0
for (right in 0 until n) {
    добавить(arr[right])
    while (окноНарушено()) { убрать(arr[left]); left++ }
    best = maxOf(best, right - left + 1)
}
```
⚠️ Сначала расширяем (right), потом чиним (while). 🗣 «Непрерывный кусок с условием → окно, один проход».

---

## 6. Скользящее окно (фиксированное K)
🔑 **Маркеры:** «окно длины K», «среднее/сумма каждого K», «максимум в каждом окне».
```kotlin
var sum = 0
for (i in 0 until n) {
    sum += arr[i]
    if (i >= k) sum -= arr[i - k]  // выкидываем вышедший
    if (i >= k - 1) обработать(sum) // окно набралось
}
```
⚠️ Окно «готово» начиная с `i == k-1`. 🗣 «Фиксированное окно → прибавил новый, вычел старый».

## 7. Бинарный поиск (по индексу)
🔑 **Маркеры:** «отсортировано» + «найти позицию / за log n».
```kotlin
var lo = 0; var hi = n - 1
while (lo <= hi) {
    val mid = lo + (hi - lo) / 2
    when {
        arr[mid] == target -> return mid
        arr[mid] < target  -> lo = mid + 1
        else               -> hi = mid - 1
    }
}
return -1
```
⚠️ `mid = lo + (hi-lo)/2` от переполнения; `lo <= hi`. 🗣 «Отсортировано → отбрасываю половину».

---

## 8. Бинарный поиск по ответу
🔑 **Маркеры:** «минимальное/максимальное X, при котором выполнимо», «можно ли за время/скорость», монотонность «да→нет».
```kotlin
var lo = minAns; var hi = maxAns
while (lo < hi) {
    val mid = lo + (hi - lo) / 2
    if (feasible(mid)) hi = mid      // mid годится → ищем левее
    else               lo = mid + 1  // не годится → правее
}
return lo // минимальный подходящий
```
⚠️ Нужна монотонная проверка `feasible`. 🗣 «Ищу не элемент, а минимальный подходящий ОТВЕТ — бинпоиск по диапазону значений».

## 9. Стек — парность/скобки
🔑 **Маркеры:** «скобки», «корректная последовательность», «вложенность», «отмена».
```kotlin
val st = ArrayDeque<Char>()
val pair = mapOf(')' to '(', ']' to '[', '}' to '{')
for (c in s) {
    if (c in pair.values) st.addLast(c)
    else if (st.isEmpty() || st.removeLast() != pair[c]) return false
}
return st.isEmpty()
```
⚠️ В конце стек должен быть пустым. 🗣 «Вложенность/парность → стек».

---

## 10. Монотонный стек — ближайший больший/меньший
🔑 **Маркеры:** «ближайший больший справа», «следующий тёплый день», «температуры», «гистограмма».
```kotlin
val st = ArrayDeque<Int>() // храним ИНДЕКСЫ
val res = IntArray(n) { -1 }
for (i in 0 until n) {
    while (st.isNotEmpty() && arr[st.last()] < arr[i]) {
        res[st.removeLast()] = i // нашли ближайший больший для прошлых
    }
    st.addLast(i)
}
return res
```
⚠️ Храним индексы, а не значения; знак сравнения задаёт «больший/меньший». 🗣 «Ближайший больший/меньший → монотонный стек, O(n)».

## 11. BFS — кратчайшее по шагам
🔑 **Маркеры:** «минимум шагов/пересадок», «по уровням/слоям», невзвешенный граф/матрица.
```kotlin
val q = ArrayDeque<Node>()
val visited = HashSet<Node>()
q.add(start); visited.add(start)
var steps = 0
while (q.isNotEmpty()) {
    repeat(q.size) {                       // ← обрабатываем ЦЕЛЫЙ слой
        val cur = q.removeFirst()
        if (cur == goal) return steps
        for (next in neighbors(cur)) if (visited.add(next)) q.add(next)
    }
    steps++
}
```
⚠️ Помечай visited **при добавлении** в очередь, не при извлечении (иначе дубли). 🗣 «Кратчайшее по шагам, веса равны → BFS по слоям».

## 12. DFS — обход в глубину
🔑 **Маркеры:** «обойти дерево/граф», «существует ли путь», «посчитать компоненту/остров».
```kotlin
val visited = HashSet<Node>()
fun dfs(node: Node) {
    if (node in visited) return
    visited.add(node)
    for (next in neighbors(node)) dfs(next)
}
```
⚠️ Не забудь visited (циклы в графе → бесконечность). Для матрицы — проверка границ. 🗣 «Обойти/посчитать связное → DFS с visited».

## 13. Backtracking — все варианты
🔑 **Маркеры:** «ВСЕ комбинации / перестановки / подмножества», «все пути», «сгенерировать».
```kotlin
val res = mutableListOf<List<T>>()
val path = mutableListOf<T>()
fun backtrack(start: Int) {
    res.add(path.toList())          // или: if (готово) { res.add(...); return }
    for (i in start until n) {
        path.add(choices[i])        // 1. выбор
        backtrack(i + 1)            // 2. рекурсия
        path.removeAt(path.size - 1) // 3. ОТКАТ ← ключевая строка
    }
}
backtrack(0)
```
⚠️ Сохраняй копию (`path.toList()`); три шага «выбор → рекурсия → откат». 🗣 «Нужны ВСЕ варианты → backtracking с откатом».

## 14. DP снизу-вверх (таблица)
🔑 **Маркеры:** «сколько способов», «минимум/максимум стоимости», «можно ли набрать», подзадачи перекрываются.
```kotlin
val dp = IntArray(n + 1)
dp[0] = базовыйСлучай
for (i in 1..n) {
    dp[i] = функцияОт(dp[i - 1], dp[i - 2] /* ... */)
}
return dp[n]
```
⚠️ Сначала определи: что такое `dp[i]`, база, переход. 🗣 «Оптимум/счёт через подзадачи → таблица dp».

---

## 15. DP сверху-вниз (мемоизация)
🔑 **Маркеры:** те же, что у DP, но удобнее рекурсией (дерево решений, сложное состояние).
```kotlin
val memo = HashMap<State, Int>()
fun solve(s: State): Int {
    if (базовый(s)) return base
    memo[s]?.let { return it }
    val ans = варианты(s).minOf { solve(переход(s, it)) + cost(it) }
    memo[s] = ans
    return ans
}
```
⚠️ Ключ memo = всё состояние; без него — экспонента. 🗣 «Рекурсия с повторами → добавляю memo, получаю DP».

## 16. Префиксные суммы
🔑 **Маркеры:** «сумма на отрезке [i..j]» (много запросов), «подмассивов с суммой K».
```kotlin
val pref = IntArray(n + 1)
for (i in 0 until n) pref[i + 1] = pref[i] + arr[i]
// сумма [i..j] = pref[j + 1] - pref[i]   → O(1) на запрос
```
Связка с Map для «суммы == K»:
```kotlin
val seen = HashMap<Int, Int>().apply { put(0, 1) }
var sum = 0; var ans = 0
for (x in arr) {
    sum += x
    ans += seen.getOrDefault(sum - k, 0) // сколько префиксов давали sum-k
    seen[sum] = seen.getOrDefault(sum, 0) + 1
}
```
🗣 «Суммы на отрезках → префиксы; счёт подмассивов с суммой → префиксы + Map».

## 17. Heap — top K
🔑 **Маркеры:** «top K», «K-й наибольший/наименьший», «слить K списков», «медиана потока».
```kotlin
// K наибольших → держим MIN-heap размера K
val heap = PriorityQueue<Int>() // min-heap по умолчанию
for (x in nums) {
    heap.add(x)
    if (heap.size > k) heap.poll() // выкидываем наименьший
}
return heap.peek() // K-й наибольший
```
⚠️ Для K наибольших — **min-heap** (контр-интуитивно!); для K наименьших — max-heap (`reverseOrder()`). 🗣 «top K → куча размера K, O(n log k)».

## 18. Union-Find (DSU) — компоненты
🔑 **Маркеры:** «связность», «группы/друзья», «сколько компонент», «динамически объединять».
```kotlin
val parent = IntArray(n) { it }
fun find(x: Int): Int {
    if (parent[x] != x) parent[x] = find(parent[x]) // сжатие пути
    return parent[x]
}
fun union(a: Int, b: Int) { parent[find(a)] = find(b) }
// число компонент = кол-во i, где find(i) == i
```
⚠️ Сжатие пути обязательно для скорости (почти O(1)). 🗣 «Объединять и спрашивать связность → DSU».

## 19. Топологическая сортировка (Kahn)
🔑 **Маркеры:** «зависимости / порядок выполнения», «можно ли упорядочить», «есть ли цикл в зависимостях».
```kotlin
val indeg = IntArray(n)
for ((u, v) in edges) indeg[v]++ // ребро u → v
val q = ArrayDeque<Int>()
for (i in 0 until n) if (indeg[i] == 0) q.add(i)
val order = mutableListOf<Int>()
while (q.isNotEmpty()) {
    val u = q.removeFirst(); order.add(u)
    for (v in adj[u]) if (--indeg[v] == 0) q.add(v)
}
return if (order.size == n) order else null // size < n → есть цикл
```
⚠️ `order.size < n` означает цикл (упорядочить нельзя). 🗣 «Порядок при зависимостях → топосорт; не все вошли → цикл».

## 20. Кадане — макс сумма подмассива
🔑 **Маркеры:** «максимальная сумма непрерывного подмассива», «лучшая серия».
```kotlin
var cur = nums[0]; var best = nums[0]
for (i in 1 until n) {
    cur = maxOf(nums[i], cur + nums[i]) // продолжить серию или начать заново
    best = maxOf(best, cur)
}
return best
```
⚠️ Инициализируй первым элементом (а не 0) — массив может быть весь отрицательный. 🗣 «Макс сумма непрерывного → Кадане, O(n)».
