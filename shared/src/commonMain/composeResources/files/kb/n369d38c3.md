
В Kotlin Any, Nothing и Unit — это особые типы, которые имеют специфическое значение и используются для различных целей в языке. Давайте рассмотрим их подробно:

==The root of the Kotlin class hierarchy. Every Kotlin class has Any as a superclass==.
```kotlin
public open class Any {
```

==Nothing has no instances.== You can use Nothing to represent "a value that never exists": for example, if a function has the return type of Nothing, it means that it never returns (always throws an exception).

```kotlin
public class Nothing private constructor()
```

### Unit 

> - синглтон, существует только 1 экземпляр класса

The type with only one value: the Unit object. This type corresponds to the void type in Java.

```kotlin
public object Unit { 
    override fun toString() = "kotlin.Unit"
}
```
### Any

Any — это **базовый тип** для всех типов данных в Kotlin, за ==исключением Nothing и Null ==(который может быть подтипом Any?). В отличие от Java, где существует только один универсальный родительский тип (Object), в Kotlin есть два типа для работы с объектами: Any и Any?.

**Особенности типа Any:**

1. **Базовый тип для всех типов:**

• Все типы в Kotlin, включая примитивы (которые автоматически преобразуются в объекты), наследуются от Any.
• Например, типы Int, String, List — все являются подтипами Any в Kotlin.

2. **Не может быть** null**:**

• ==Any сам по себе не может быть null==. Для этого существует тип Any?, который позволяет работать как с объектами, так и с null.

3. **Методы для всех объектов:**
1. clone() (Метод в Java, но не в Kotlin):
• В отличие от Java, в Kotlin метод clone() не является частью класса Any. Это связано с тем, что Kotlin не поддерживает создание “клонов” объектов по умолчанию и предпочитает использовать другие способы копирования объектов (например, через метод copy() в **data class**).
2. toString(): String:
• Этот метод возвращает строковое представление объекта. По умолчанию, он возвращает строку, которая включает имя класса и адрес объекта в памяти. Однако этот метод часто переопределяется в классах, чтобы вернуть более читаемое или полезное представление объекта.
3. hashCode(): Int:
• Метод, который возвращает хэш-код объекта. Это значение используется, например, при добавлении объектов в коллекции, такие как HashSet или HashMap. По умолчанию хэш-код генерируется на основе адреса объекта в памяти, но может быть переопределен для классов, которые сравнивают объекты по значению.
4. equals(other: Any?): Boolean:
• Метод для сравнения текущего объекта с другим объектом. По умолчанию, он проверяет ссылки (сравнивает адреса в памяти), но может быть переопределен в классе для сравнения значений.

Например, все объекты Kotlin (кроме примитивов) имеют эти методы.
```kotlin

fun printDetails(value: Any) {
    println(value.toString())  // Все объекты в Kotlin могут быть приведены к строковому представлению
    println(value.hashCode())  // Все объекты имеют хэш-код
}

fun main() {
    val number = 42
    val text = "Hello, Kotlin!"

    printDetails(number)  // Выведет: 42 и хэш-код числа
    printDetails(text)    // Выведет: Hello, Kotlin! и хэш-код строки
}
```

• В примере выше, функция printDetails может принимать аргумент любого типа (так как его тип — Any), и мы можем использовать стандартные методы, такие как toString() и hashCode(), для этих значений.

### **Типы и Any?**

• Any? — это тип, который включает в себя все типы Any, а также позволяет значениям быть равными null. Это эквивалентно типу, который представляет “любое значение или null”. То есть Any? может быть как объектом любого типа, так и null.

```kotlin

fun printIfNotNull(value: Any?) {
    if (value != null) {
        println(value.toString())  // Если value не null, выводим его строковое представление
    } else {
        println("Value is null")
    }
}

fun main() {
    printIfNotNull(42)        // Выведет: 42
    printIfNotNull("Hello")   // Выведет: Hello
    printIfNotNull(null)      // Выведет: Value is null
}
```

• Здесь Any? позволяет работать как с объектами, так и с null.

**Ключевые отличия от Java:**

• В **Java** все классы, включая базовые типы данных (такие как int, boolean и т.д.), наследуются от класса Object. В Kotlin же примитивы автоматически оборачиваются в соответствующие объекты (например, Int становится объектом Integer).

• В Kotlin существует два типа для объектов:
• Any — для объектов, не равных null.
• Any? — для объектов, которые могут быть равны null.

**Резюме:**

• Any — это базовый тип для всех типов в Kotlin (кроме Nothing и Null).
• Он предоставляет методы, доступные для всех объектов, такие как toString(), hashCode(), и equals().
• Any? — это расширение Any, которое также поддерживает значение null.

## Nothing

Nothing в Kotlin — это особый тип, который обозначает **“ничего”**. Он используется в специфичных случаях, когда функция или ==выражение не может завершиться нормально== и, следовательно, никогда не возвращает значение. Тип Nothing служит для указания, что результат выполнения операции ==либо приводит к исключению==, ==либо она продолжает выполняться бесконечно==.

**Особенности типа Nothing:**

1. **Не имеет значений:**

• Тип Nothing не может иметь значений, потому что он предназначен для случаев, когда выполнение функции или выражения не завершится нормальным образом (например, выбрасывается исключение или программа заходит в бесконечный цикл).

2. **Использование в типах возвращаемых значений:**

• Функции, которые выбрасывают исключение или никогда не завершаются (например, бесконечные циклы), имеют тип Nothing.

3. **Иногда используется для аннотации функций, которые не должны возвращать управление:**

• Nothing полезен для аннотирования функций, которые не могут завершиться обычным способом (например, функции с throw, которые выбрасывают исключения, или функции с бесконечными циклами).

## Практическое применение Nothing

`Nothing` — **подтип любого типа**, поэтому компилятор позволяет «подставить» его куда угодно. Это даёт удобные паттерны:

```kotlin
// 1. Функция, которая всегда бросает — её можно вернуть из любой ветки
fun fail(msg: String): Nothing = throw IllegalStateException(msg)

val name = user.name ?: fail("name is null") // тип name — String, не String?

// 2. Elvis + throw / return / TODO
val token = getToken() ?: return
val config = loadConfig() ?: TODO("реализовать дефолт") // TODO() возвращает Nothing

// 3. Nothing? — тип, у которого единственное значение null
val nothing: Nothing? = null
```

Именно потому, что `Nothing` — подтип всего, выражения `throw`, `return`, `TODO()` можно использовать в правой части elvis и в любых ветках `when`/`if`.

> [!tip] Unit vs Nothing vs void — на собесе
> - **`Unit`** — функция **завершается и ничего полезного не возвращает** (есть ровно одно значение `Unit`). Аналог `void` в Java, но это полноценный тип/объект.
> - **`Nothing`** — функция **никогда не завершается нормально** (всегда throw или бесконечный цикл). Значений у типа нет вообще.
> - **`void` (Java)** — ключевое слово, не тип; нельзя использовать как параметр дженерика, а `Unit`/`Nothing` — можно.
> - Иерархия: `Nothing` — на самом «дне» (подтип всех), `Any?` — на вершине (надтип всех).
