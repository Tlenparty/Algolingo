# l2.14
note: 2.14 Two Sum II (массив отсортирован)
title: Two Sum II
trains: два указателя навстречу по отсортированному массиву
examples:
- assertContentEquals(intArrayOf(1, 2), twoSumSorted(intArrayOf(2, 7, 11, 15), 9))
- assertContentEquals(intArrayOf(1, 3), twoSumSorted(intArrayOf(2, 3, 4), 6))
- assertContentEquals(intArrayOf(1, 2), twoSumSorted(intArrayOf(-1, 0), -1))
checks:
```kotlin
// оракул: перебор пар; все неубывающие массивы длины 2..5 из чисел -2..2 и цели, у которых пара ровно одна
for (n in 2..5) case {
    for (m in 0 until pw(5, n)) {
        val a = IntArray(n) { (m / pw(5, it)) % 5 - 2 }
        if ((1 until n).any { a[it] < a[it - 1] }) continue
        for (t in -4..4) {
            val pairs = (0 until n).flatMap { i -> (i + 1 until n).filter { j -> a[i] + a[j] == t }.map { j -> intArrayOf(i + 1, j + 1) } }
            if (pairs.size != 1) continue
            assertContentEquals(pairs[0], twoSumSorted(a, t), a.joinToString() + " / " + t)
        }
    }
}
case { assertContentEquals(intArrayOf(2, 4), twoSumSorted(intArrayOf(2, 7, 11, 15), 22)) }

case { assertContentEquals(intArrayOf(3, 4), twoSumSorted(intArrayOf(1, 2, 5, 9), 14)) }
case { assertContentEquals(intArrayOf(2, 3), twoSumSorted(intArrayOf(1, 2, 3, 9), 5)) }
```

## theory Когда навстречу по сумме
signals:
- Массив уже отсортирован
- Пара с заданной суммой
- Память O(1): Map нельзя
body: Сумма крайних мала — левое число не подходит даже к самому большому справа: `left++`. Велика — правое не подходит даже к самому маленькому слева: `right--`. Каждый шаг выкидывает одно число, поэтому O(n).

## theory Каркас
skeleton:
```kotlin
var left = 0
var right = numbers.size - 1
while (left < right) {
    val sum = numbers[left] + numbers[right]
    // нашли -> номера с единицы
    // мало -> left++, много -> right--
}
```
body: Ответ просит номера с единицы, а индексы в Kotlin с нуля: `left + 1`, `right + 1`.

## theory Грабли
pitfalls:
- `intArrayOf(left, right)`: номера с нуля, `[2, 7, 11, 15]`, `9` → `[0, 1]` вместо `[1, 2]`
- Перепутать сдвиги: на малой сумме `right--` уводит от ответа
- `right = numbers.size`: первый же `numbers[right]` вне массива
- Без сортировки приём не работает: выкинутое число могло пригодиться

## e1
```kotlin
// Случай 1: [2, 7, 11, 15], target = 9 → [1, 2]
// Случай 2: [2, 3, 4], target = 6 → [1, 3]
// Случай 3: [-1, 0], target = -1 → [1, 2]
fun twoSumSorted(numbers: IntArray, target: Int): IntArray {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = numbers.size - 1
    // идём навстречу
    while (left < right) {
        val sum = numbers[left] + numbers[right]
        // нашли пару: номера с единицы
        if (sum == target) return intArrayOf(left + 1, right + 1)
        // мало — левый вправо, много — правый влево
        if (sum ⟦<⟧ target) left++ else right--
    }
    // по условию пара всегда есть
    return intArrayOf()
}
```
- `>` [wrong]: сдвиги перепутаны: `[2, 7, 11, 15]`, `9` → сумма `17` велика, а `left++` делает её ещё больше: `[]` вместо `[1, 2]`
- `==` [wrong]: условие всегда ложно, двигается только `right`: `[2, 7, 11, 15]`, `22` → `[]` вместо `[2, 4]`
? Сумма меньше нужной — левое число слишком маленькое: двигаем `left`.

## e2
```kotlin
// Случай 1: [2, 7, 11, 15], target = 9 → [1, 2]
// Случай 2: [2, 3, 4], target = 6 → [1, 3]
// Случай 3: [-1, 0], target = -1 → [1, 2]
fun twoSumSorted(numbers: IntArray, target: Int): IntArray {

    var left = 0
    // правый указатель — с конца
    var right = numbers.size - 1
    // идём навстречу
    while (left < right) {
        val sum = numbers[left] + numbers[right]
        // нашли пару: номера с единицы
        if (sum == target) return intArrayOf(⟦left + 1⟧, ⟦right + 1⟧)
        // мало — левый вправо, много — правый влево
        if (sum < target) left++ else right--

    // по условию пара всегда есть
    return intArrayOf()

```
- `left`
- `right`
- @1 `left` [wrong]: номер с нуля, а нужен с единицы: `[2, 7, 11, 15]`, `9` → `[0, 2]` вместо `[1, 2]`
- @1 `right` [wrong]: это правый индекс, а не левый номер: `[2, 3, 4]`, `6` → `[2, 3]` вместо `[1, 3]`
- @1 `right + 1` [wrong]: оба номера правые: `[2, 7, 11, 15]`, `9` → `[2, 2]` вместо `[1, 2]`
- @2 `left` [wrong]: это левый индекс, а не правый номер: `[2, 7, 11, 15]`, `9` → `[1, 0]` вместо `[1, 2]`
- @2 `right` [wrong]: номер с нуля, а нужен с единицы: `[2, 7, 11, 15]`, `9` → `[1, 1]` вместо `[1, 2]`
- @2 `left + 1` [wrong]: оба номера левые: `[2, 7, 11, 15]`, `9` → `[1, 1]` вместо `[1, 2]`
? Индексы в Kotlin с нуля, а ответ просит номера с единицы.

## e3
```kotlin
// Случай 1: [2, 7, 11, 15], target = 9 → [1, 2]
// Случай 2: [2, 3, 4], target = 6 → [1, 3]
// Случай 3: [-1, 0], target = -1 → [1, 2]
fun twoSumSorted(numbers: IntArray, target: Int): IntArray {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = ⟦numbers.size - 1⟧
    // идём навстречу
    while (⟦left < right⟧) {
        val sum = numbers[left] + numbers[right]
        // нашли пару: номера с единицы
        if (sum == target) return intArrayOf(left + 1, right + 1)
        // мало — левый вправо, много — правый влево
        if (sum < target) ⟦left++⟧ else right--
    }
    // по условию пара всегда есть
    return intArrayOf()
}
```
- `numbers.size`
- `right--`
- @1 `numbers.size` [crash]: первый же `numbers[right]` вне массива: `[2, 7, 11, 15]` → `numbers[4]`
- @1 `left < right` [compile]: `right` используется в собственном объявлении: `var right = left < right` не скомпилируется
- @1 `left++` [wrong]: `right` станет `0`, а `left` — `1`: цикл не начнётся, `[2, 7, 11, 15]`, `9` → `[]` вместо `[1, 2]`
- @1 `right--` [compile]: `right` используется в собственном объявлении: `var right = right--` не скомпилируется
- @2 `numbers.size - 1` [compile]: `while` ждёт `Boolean`, а это `Int`: `while (numbers.size - 1)` не скомпилируется
- @2 `numbers.size` [compile]: `while` ждёт `Boolean`, а это `Int`: `while (numbers.size)` не скомпилируется
- @2 `left++` [compile]: `while` ждёт `Boolean`, а `left++` — `Int`: не скомпилируется
- @2 `right--` [compile]: `while` ждёт `Boolean`, а `right--` — `Int`: не скомпилируется
- @3 `numbers.size - 1` [hang]: на малой сумме никто не двигается: `[2, 7, 11, 15]`, `22` → вечный цикл
- @3 `numbers.size` [hang]: на малой сумме никто не двигается: `[2, 7, 11, 15]`, `22` → вечный цикл
- @3 `left < right` [hang]: на малой сумме никто не двигается: `[2, 7, 11, 15]`, `22` → вечный цикл
- @3 `right--` [wrong]: двигается только `right`, левое число не меняется: `[2, 7, 11, 15]`, `22` → `[]` вместо `[2, 4]`
? `right` — индекс последнего числа: `numbers.size - 1`.
? Указатели идут навстречу, пока не встретятся.
? Сумма мала — левое число слишком маленькое: `left++`.
