# l0.3
note: 0.3 Палиндром ли строка
title: Палиндром
pitfalls:
- `left <= right` работает, но на нечётной длине средний символ сравнивается сам с собой: лишний шаг
- `right = s.length` вместо `s.length - 1`: первый же `s[right]` вне строки
- `left != right`: на чётной длине указатели проскочат друг друга и выйдут за границы
- Перепутать ответы: на несовпадении — `false`, после цикла — `true`
examples:
- assertTrue(isPalindrome("aba"))
- assertTrue(isPalindrome("abba"))
- assertFalse(isPalindrome("ab"))
- assertTrue(isPalindrome(""))
- assertTrue(isPalindrome("a"))
checks:
```kotlin
// оракул: s == s.reversed(); все строки длины 0..5 из {a, b, c}
for (n in 0..5) case {
    for (m in 0 until pw(3, n)) {
        val s = CharArray(n) { 'a' + (m / pw(3, it)) % 3 }.concatToString()
        assertEquals(s == s.reversed(), isPalindrome(s))
    }
}
case { assertTrue(isPalindrome("aa")) }
case { assertFalse(isPalindrome("abcb")) } // расходится первая пара
case { assertFalse(isPalindrome("abca")) } // расходится внутренняя пара
```

## theory Тот же скелет
signals:
- «Палиндром / симметрия»
- «Читается одинаково с обеих сторон»
body: Скелет разворота из 0.2, только вместо обмена сравниваем пару: `s[left] != s[right]` — сразу `return false`. Время O(n), память O(1).

## theory Каркас
skeleton:
```kotlin
// левый указатель — с начала
var left = 0
// правый указатель — с конца
var right = n - 1
// идём навстречу
while (left < right) {
    // пара разная -> ответ
    // оба указателя — к центру
    left++; right--
}
// дошли до середины -> ответ
```
body: Как и в 0.2, `left <= right` засчитывается с пометкой: средний символ лишний раз сравнится сам с собой.

## theory Грабли
pitfalls:
- `right = s.length`: первый же `s[right]` вне строки
- `left != right` на чётной длине: указатели проскочат друг друга, `"abba"` → `s[4]`
- Перепутать ответы: на несовпадении `false`, после цикла `true`

## e1
```kotlin
fun isPalindrome(s: String): Boolean {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = s.length - 1
    // идём навстречу
    while (⟦left < right | ~left <= right⟧) {
        // края разные — нет
        if (s[left] != s[right]) return false
        // оба указателя — к центру
        left++; right--
    }
    // все пары совпали
    return true
}
```
- ~`left <= right`: работает, но на нечётной длине средний символ сравнится сам с собой: `"aba"` делает лишний шаг на `b`
- `left > right` [wrong]: цикл не выполнится ни разу: `"ab"` вернёт `true`
- `left != right` [crash]: на чётной длине указатели проскочат друг друга: `"abba"` → выход за границы на `s[4]`
? Указатели с краёв идут навстречу, пока `left < right`.

## e2
```kotlin
fun isPalindrome(s: String): Boolean {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = s.length - 1
    // идём навстречу
    while (left < right) {
        // края разные — нет
        if (s[left] ⟦!=⟧ s[right]) return ⟦false⟧
        // оба указателя — к центру
        left++; right--
    }
    // все пары совпали
    return true
}
```
- `==` [wrong]: условие перевёрнуто: `"ab"` вернёт `true`, а `"aba"` — `false`
- `true` [wrong]: на несовпадении скажет «да»: `"ab"` вернёт `true`
- @1 `true` [compile]: `s[left] true s[right]` не скомпилируется: здесь нужен оператор сравнения
- @2 `==` [compile]: `return ==` не скомпилируется: здесь нужен ответ `Boolean`
? Нашли несовпадающую пару — дальше смотреть незачем: сразу `return false`.

## e3
```kotlin
fun isPalindrome(s: String): Boolean {

    // правый указатель — с конца

        // края разные — нет

    }

}
```
- `s.length` [crash]: первый же `s[right]` вне строки: `"aba"` → `s[3]`
- `false`
- `==` [wrong]: условие перевёрнуто: `"aba"` вернёт `false`
- @2 `s.length` [compile]: `while` ждёт `Boolean`, а `s.length` — `Int`: не скомпилируется
- @3 `s.length` [compile]: `s[left] s.length s[right]` не скомпилируется: здесь нужен оператор сравнения
- @4 `s.length` [compile]: функция возвращает `Boolean`, а `s.length` — `Int`: не скомпилируется
- @1 `false` [compile]: `right` должен быть индексом `Int`, а не `Boolean`: `left < right` не скомпилируется
- @2 `false` [wrong]: `while (false)` не выполнится ни разу: `"ab"` вернёт `true`
- @3 `false` [compile]: `s[left] false s[right]` не скомпилируется: здесь нужен оператор сравнения
- @4 `false` [wrong]: на палиндроме ответ всё равно «нет»: `"aba"` вернёт `false`
- @1 `==` [compile]: `var right = ==` не скомпилируется: здесь нужен индекс последнего символа
- @2 `==` [compile]: `while (==)` не скомпилируется: здесь нужно условие `left < right`
- @4 `==` [compile]: `return ==` не скомпилируется: здесь нужен ответ `Boolean`
- @2 `true` [crash]: `while (true)` не остановится в середине: `"aba"` → выход за границы на `s[3]`
- @4 `left < right` [wrong]: после цикла `left < right` всегда ложно: `"aba"` вернёт `false`
? `right` — индекс последнего символа: `s.length - 1`.
? Нашли несовпадающую пару — сразу `return false`.
? Цикл дошёл до середины без расхождений — строка палиндром: `return true`.
