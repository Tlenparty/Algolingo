# l2.15
note: 2.15 Валидный палиндром
title: Валидный палиндром
trains: два указателя навстречу с пропуском лишних символов
examples:
- assertTrue(isValidPalindrome("A man, a plan, a canal: Panama"))
- assertFalse(isValidPalindrome("race a car"))
- assertTrue(isValidPalindrome(" "))
- assertFalse(isValidPalindrome("0P"))
checks:
```kotlin
// оракул: оставить буквы и цифры, в нижний регистр, сравнить с разворотом; все строки длины 0..5 из {a, A, b, 0, пробел, запятая}
val abc = "aAb0 ,"
for (n in 0..5) case {
    for (m in 0 until pw(6, n)) {
        val s = CharArray(n) { abc[(m / pw(6, it)) % 6] }.concatToString()
        val t = s.filter { it.isLetterOrDigit() }.lowercase()
        assertEquals(t == t.reversed(), isValidPalindrome(s), s)
    }
}
case { assertTrue(isValidPalindrome("")) }
case { assertTrue(isValidPalindrome(".,")) }
case { assertTrue(isValidPalindrome("Шалаш!")) }
// контрпримеры из причин
case { assertFalse(isValidPalindrome(".ab")) }
case { assertFalse(isValidPalindrome("ab.")) }
case { assertTrue(isValidPalindrome(".a")) }
case { assertFalse(isValidPalindrome("ab")) }
case { assertTrue(isValidPalindrome("Aa")) }
```

## theory Когда пропускать по пути
signals:
- Палиндром, но «только буквы и цифры»
- «Регистр не важен»
- Память O(1): копию строки не строим
body: Скелет 0.3. Перед сравнением каждый указатель сам пропускает лишний символ: шаг и `continue`, на следующем круге проверка заново. Сравниваем `lowercaseChar()` обеих сторон. Время O(n), память O(1).

## theory Каркас
skeleton:
```kotlin
while (left < right) {
    // слева лишний -> left++, continue
    // справа лишний -> right--, continue
    // сравнить без регистра
    left++; right--
}
```
body: `continue` нужен, чтобы после шага снова проверить `left < right` и новый символ.

## theory Грабли
pitfalls:
- `isLetter()` вместо `isLetterOrDigit()`: цифры выпадут, `"0P"` → `true`
- Без `lowercaseChar()`: `"Aa"` → `false`
- Пропуск справа двигает не тот указатель: `"ab."` → `true`
- На несовпадении `false`, после цикла `true`

## e1
```kotlin
// Случай 1: "A man, a plan, a canal: Panama" → true
// Случай 2: "race a car" → false
// Случай 3: " " → true
fun isValidPalindrome(s: String): Boolean {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = s.length - 1
    // идём навстречу
    while (left < right) {
        // слева не буква и не цифра — пропускаем
        if (!s[left].isLetterOrDigit()) { ⟦left++⟧; continue }
        // справа так же
        if (!s[right].isLetterOrDigit()) { right--; continue }
        // сравниваем без учёта регистра
        if (s[left].lowercaseChar() != s[right].lowercaseChar()) return false
        // оба указателя — к центру
        left++; right--
    }
    // все пары совпали
    return true
}
```
- `right--` [wrong]: лишний символ слева так и остаётся, а правый указатель съедает буквы: `".ab"` вернёт `true`
- `left--` [crash]: левый указатель уходит за начало: `".a"` → `s[-1]`
? Лишний символ слева — сдвигаем левый указатель внутрь.

## e2
```kotlin
// Случай 1: "A man, a plan, a canal: Panama" → true
// Случай 2: "race a car" → false
// Случай 3: " " → true
fun isValidPalindrome(s: String): Boolean {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = s.length - 1
    // идём навстречу
    while (left < right) {
        // слева не буква и не цифра — пропускаем
        if (!s[left].isLetterOrDigit()) { left++; continue }
        // справа так же
        if (!s[right].isLetterOrDigit()) { right--; continue }
        // сравниваем без учёта регистра
        if (s[left].lowercaseChar() ⟦!=⟧ s[right].lowercaseChar()) return ⟦false⟧
        // оба указателя — к центру
        left++; right--
    }
    // все пары совпали
    return true
}
```
- `==` [wrong]: условие перевёрнуто: `"ab"` вернёт `true`, а `"Aa"` — `false`
- `true` [wrong]: на несовпадении скажет «да»: `"ab"` вернёт `true`
- @1 `false` [compile]: `s[left].lowercaseChar() false s[right]...` не скомпилируется: здесь нужен оператор сравнения
- @1 `true` [compile]: `s[left].lowercaseChar() true s[right]...` не скомпилируется: здесь нужен оператор сравнения
- @2 `!=` [compile]: `return !=` не скомпилируется: здесь нужен ответ `Boolean`
- @2 `==` [compile]: `return ==` не скомпилируется: здесь нужен ответ `Boolean`
? Нашли несовпадающую пару — сразу `return false`.
