# l1.5
note: 1.5 Победители соревнования 🔥Avito
title: Победители соревнования
examples:
- assertEquals(ChampionResult(listOf(1), 200), findChampions(listOf(listOf(StepEntry(1, 100), StepEntry(2, 50)), listOf(StepEntry(1, 100), StepEntry(2, 50)))))
- assertEquals(ChampionResult(listOf(1), 200), findChampions(listOf(listOf(StepEntry(1, 100), StepEntry(2, 500)), listOf(StepEntry(1, 100)))))
- findChampions(listOf(listOf(StepEntry(1, 100), StepEntry(2, 100)), listOf(StepEntry(2, 50), StepEntry(1, 50)))).let { assertEquals(listOf(1, 2), it.userIds.sorted()); assertEquals(150, it.steps) }
- assertEquals(ChampionResult(emptyList(), 0), findChampions(emptyList()))

## theory Когда две Map
signals:
- По каждому юзеру нужны и сумма, и счётчик
- «Во все дни», «без пропусков» — счётчик дней равен числу дней
- «Максимум среди тех, кто…» — сначала фильтр, потом максимум
body: Две `HashMap` за один двойной проход: `totalSteps` копит шаги, `daysActive` — дни участия. O(N) по числу записей, O(U) по числу юзеров.

## theory Каркас
skeleton:
```kotlin
for (day in statistics) for (e in day) {
    totalSteps[e.userId] = totalSteps.getOrDefault(e.userId, 0) + e.steps
    daysActive[e.userId] = daysActive.getOrDefault(e.userId, 0) + 1
}
val full = daysActive.filterValues { it == totalDays }.keys
val maxSteps = full.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
val champions = full.filter { totalSteps[it] == maxSteps }
```
body: Фильтр → максимум → сбор всех с этим максимумом. Сначала отфильтруй тех, кто был все дни, и только среди них ищи максимум.

## theory Грабли
pitfalls:
- Победителей может быть несколько (равный максимум) → возвращаем список, а не одного
- Максимум по всем юзерам, а не только по участникам всех дней: юзер с пропуском задаст недостижимый максимум, и победителей не останется
- Без участников `maxOfOrNull` вернёт `null` — нужен `?: 0`

## e1
```kotlin
data class StepEntry(val userId: Int, val steps: Int)
data class ChampionResult(val userIds: List<Int>, val steps: Int)

fun findChampions(statistics: List<List<StepEntry>>): ChampionResult {
    val totalDays = statistics.size
    val totalSteps = HashMap<Int, Int>()
    val daysActive = HashMap<Int, Int>()

    for (day in statistics) for (e in day) {
        totalSteps[e.userId] = totalSteps.getOrDefault(e.userId, 0) + e.steps
        daysActive[e.userId] = daysActive.getOrDefault(e.userId, 0) + 1
    }

    val full = daysActive.filterValues { it == totalDays }.keys
    val maxSteps = ⟦full⟧.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
    val champions = full.filter { totalSteps[it] == maxSteps }
    return ChampionResult(champions, maxSteps)
}
```
- `totalSteps.keys`: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
- `daysActive.keys`: те же ключи, что у `totalSteps` — максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
? «Без пропусков» = число дней участия равно `statistics.size`. Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).

## e2
```kotlin
data class StepEntry(val userId: Int, val steps: Int)
data class ChampionResult(val userIds: List<Int>, val steps: Int)

fun findChampions(statistics: List<List<StepEntry>>): ChampionResult {
    val totalDays = statistics.size
    val totalSteps = HashMap<Int, Int>()
    val daysActive = HashMap<Int, Int>()

    for (day in statistics) for (e in day) {
        totalSteps[e.userId] = totalSteps.getOrDefault(e.userId, 0) + e.steps
        daysActive[e.userId] = daysActive.getOrDefault(e.userId, 0) + 1
    }

    val full = daysActive.filterValues { it == totalDays }.keys
    val maxSteps = ⟦full⟧.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
    val champions = full.filter { totalSteps[it] == maxSteps }
    return ChampionResult(⟦champions⟧, maxSteps)
}
```
- `totalSteps.keys`: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
- `listOf(champions.first())`: при равном максимуме теряется второй победитель: день `[(1, 100), (2, 100)]` → в `userIds` один юзер вместо `1` и `2`
- `listOf(maxSteps)`: в список победителей попадают шаги, а не `userId`: день `[(1, 100)]` → `ChampionResult([100], 100)` вместо `([1], 100)`
- @1 `champions`: `champions` объявлен строкой ниже: `champions.maxOfOrNull { … }` не скомпилируется
- @1 `listOf(champions.first())`: `champions` объявлен строкой ниже: `listOf(champions.first()).maxOfOrNull { … }` не скомпилируется
- @1 `listOf(maxSteps)`: `maxSteps` ссылается на саму себя: `val maxSteps = listOf(maxSteps)…` не скомпилируется
- @2 `full`: `keys` — это `Set`, а `ChampionResult` ждёт `List<Int>`: `ChampionResult(full, maxSteps)` не скомпилируется
- @2 `totalSteps.keys`: `keys` — это `Set`, а `ChampionResult` ждёт `List<Int>`: `ChampionResult(totalSteps.keys, maxSteps)` не скомпилируется
? «Без пропусков» = число дней участия равно `statistics.size`. Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).

## e3
```kotlin
data class StepEntry(val userId: Int, val steps: Int)
data class ChampionResult(val userIds: List<Int>, val steps: Int)

fun findChampions(statistics: List<List<StepEntry>>): ChampionResult {
    val totalDays = statistics.size
    val totalSteps = HashMap<Int, Int>()
    val daysActive = HashMap<Int, Int>()

    for (day in statistics) for (e in day) {
        totalSteps[e.userId] = totalSteps.getOrDefault(e.userId, 0) + ⟦e.steps⟧
        daysActive[e.userId] = daysActive.getOrDefault(e.userId, 0) + ⟦1⟧
    }

    val full = daysActive.filterValues { it == ⟦totalDays⟧ }.keys
    val maxSteps = ⟦full⟧.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
    val champions = full.filter { totalSteps[it] == maxSteps }
    return ChampionResult(champions, maxSteps)
}
```
- `totalSteps.keys`: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
- `daysActive.size`: это число юзеров, а не дней: день `[(1, 100), (2, 50)]` → дней `1`, юзеров `2`, ответ `([], 0)` вместо `([1], 100)`
- `e.userId`: к шагам прибавляется номер юзера: день `[(1, 100), (2, 50)]` → `ChampionResult([2], 2)` вместо `([1], 100)`
- @1 `1`: `totalSteps` считает записи, а не шаги: день `[(1, 100), (2, 50)]` → ничья `1` и `2` с `steps = 1` вместо `([1], 100)`
- @1 `totalDays`: за каждую запись прибавляется число дней, а не шаги: день `[(1, 100), (2, 50)]` → ничья `1` и `2` с `steps = 1` вместо `([1], 100)`
- @1 `full`: `full` объявлен ниже, после цикла: `+ full` не скомпилируется
- @1 `totalSteps.keys`: к числу не прибавить множество: `+ totalSteps.keys` не скомпилируется
- @1 `daysActive.size`: к шагам прибавляется текущее число юзеров в `daysActive`: день `[(1, 100), (2, 50)]` → `ChampionResult([2], 1)` вместо `([1], 100)`
- @2 `e.steps`: `daysActive` копит шаги, а не дни, и не совпадёт с `totalDays`: день `[(1, 100)]` → `daysActive[1] = 100`, ответ `([], 0)` вместо `([1], 100)`
- @2 `totalDays`: за каждый день прибавляется число дней: дни `[(1, 100)]`, `[(1, 100)]` → `daysActive[1] = 4` вместо `2`, ответ `([], 0)` вместо `([1], 200)`
- @2 `full`: `full` объявлен ниже, после цикла: `+ full` не скомпилируется
- @2 `totalSteps.keys`: к числу не прибавить множество: `+ totalSteps.keys` не скомпилируется
- @2 `daysActive.size`: первая запись юзера прибавляет `0` — пока в `daysActive` никого нет: день `[(1, 100)]` → `daysActive[1] = 0`, ответ `([], 0)` вместо `([1], 100)`
- @2 `e.userId`: прибавляется номер юзера, а не `1` за день: день `[(2, 100)]` → `daysActive[2] = 2` вместо `1`, ответ `([], 0)` вместо `([2], 100)`
- @3 `e.steps`: после цикла `e` вне области видимости: `it == e.steps` не скомпилируется
- @3 `1`: остаются те, кто был ровно один день, а не все дни: дни `[(1, 100)]`, `[(1, 100)]` → `([], 0)` вместо `([1], 200)`
- @3 `full`: `full` ссылается на саму себя: `val full = daysActive.filterValues { it == full }` не скомпилируется
- @3 `totalSteps.keys`: число дней не сравнить с множеством: `it == totalSteps.keys` не скомпилируется
- @3 `e.userId`: после цикла `e` вне области видимости: `it == e.userId` не скомпилируется
- @4 `e.steps`: после цикла `e` вне области видимости: `e.steps.maxOfOrNull { … }` не скомпилируется
- @4 `1`: у числа нет `maxOfOrNull`, нужна коллекция юзеров: `1.maxOfOrNull { … }` не скомпилируется
- @4 `totalDays`: у числа нет `maxOfOrNull`, нужна коллекция юзеров: `totalDays.maxOfOrNull { … }` не скомпилируется
- @4 `daysActive.size`: у числа нет `maxOfOrNull`, нужна коллекция юзеров: `daysActive.size.maxOfOrNull { … }` не скомпилируется
- @4 `e.userId`: после цикла `e` вне области видимости: `e.userId.maxOfOrNull { … }` не скомпилируется
? Тебе нужны две вещи на каждого юзера: суммарные шаги и в скольких днях он участвовал. Две `Map` за один двойной проход.
? Шаги копим по `e.steps`, дни — по одному за запись.
? «Без пропусков» = число дней участия равно `statistics.size`.
? Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).
