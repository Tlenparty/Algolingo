```kotlin
// оракул: перебор юзеров, «был во все дни» = есть запись в каждом дне (не счётчик);
// все наборы из 0..3 дней, в дне юзер 1 и юзер 2 либо отсутствуют, либо с шагами 0 или 100
fun oracle(st: List<List<StepEntry>>): Pair<List<Int>, Int> {
    val users = st.flatten().map { it.userId }.distinct()
    val full = users.filter { u -> st.all { day -> day.any { it.userId == u } } }
    val total = full.associateWith { u -> st.flatten().filter { it.userId == u }.sumOf { it.steps } }
    val best = total.values.maxOrNull() ?: 0
    return full.filter { total[it] == best }.sorted() to best
}
val opts = listOf(-1, 0, 100) // -1 = юзера в этот день нет

    for (m in 0 until pw(9, d)) {

            val code = (m / pw(9, k)) % 9

}
```

## theory Когда две Map
signals:
- По каждому юзеру нужны и сумма, и счётчик
- «Во все дни», «без пропусков» — счётчик дней равен числу дней
- «Максимум среди тех, кто…» — сначала фильтр, потом максимум
body: Две `HashMap` за один двойной проход: `totalSteps` копит шаги, `daysActive` — дни участия. O(N) по числу записей, O(U) по числу юзеров.

## theory Каркас
skeleton:
```kotlin
// один проход по всем записям
for (day in statistics) for (entry in day) {
    totalSteps[entry.userId] = totalSteps.getOrDefault(entry.userId, 0) + entry.steps
    daysActive[entry.userId] = daysActive.getOrDefault(entry.userId, 0) + 1
}
// кто участвовал во все дни
val allDaysUsers = daysActive.filterValues { it == totalDays }.keys
// лучший результат среди них
val maxSteps = allDaysUsers.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
// все с максимумом
val champions = allDaysUsers.filter { totalSteps[it] == maxSteps }
```
body: Фильтр → максимум → сбор всех с этим максимумом. Сначала отфильтруй тех, кто был все дни, и только среди них ищи максимум.

## theory Грабли
pitfalls:
- Победителей может быть несколько (равный максимум) → возвращаем список, а не одного
- Максимум по всем юзерам, а не только по участникам всех дней: юзер с пропуском задаст недостижимый максимум, и победителей не останется
- Без участников `maxOfOrNull` вернёт `null` — нужен `?: 0`

## e1
```kotlin
data class StepEntry(val userId: Int, val steps: Int)
data class ChampionResult(val userIds: List<Int>, val steps: Int)

fun findChampions(statistics: List<List<StepEntry>>): ChampionResult {
    // сколько всего дней
    val totalDays = statistics.size
    // userId -> сумма шагов
    val totalSteps = HashMap<Int, Int>()
    // userId -> дней участия
    val daysActive = HashMap<Int, Int>()

    // один проход по всем записям
    for (day in statistics) for (entry in day) {
        totalSteps[entry.userId] = totalSteps.getOrDefault(entry.userId, 0) + entry.steps
        daysActive[entry.userId] = daysActive.getOrDefault(entry.userId, 0) + 1
    }

    // кто участвовал во все дни
    val allDaysUsers = daysActive.filterValues { it == totalDays }.keys
    // лучший результат среди них
    val maxSteps = ⟦allDaysUsers⟧.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
    // все с максимумом
    val champions = allDaysUsers.filter { totalSteps[it] == maxSteps }
    return ChampionResult(champions, maxSteps)
}
```
- `totalSteps.keys` [wrong]: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
- `daysActive.keys` [wrong]: те же ключи, что у `totalSteps` — максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
? «Без пропусков» = число дней участия равно `statistics.size`. Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).

- `totalSteps.keys` [wrong]: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
- `listOf(champions.first())` [wrong]: при равном максимуме теряется второй победитель: день `[(1, 100), (2, 100)]` → в `userIds` один юзер вместо `1` и `2`
- `listOf(maxSteps)` [wrong]: в список победителей попадают шаги, а не `userId`: день `[(1, 100)]` → `ChampionResult([100], 100)` вместо `([1], 100)`

- @1 `listOf(maxSteps)` [compile]: `maxSteps` ссылается на саму себя: `val maxSteps = listOf(maxSteps)…` не скомпилируется
- @2 `allDaysUsers` [compile]: `keys` — это `Set`, а `ChampionResult` ждёт `List<Int>`: `ChampionResult(allDaysUsers, maxSteps)` не скомпилируется
- @2 `totalSteps.keys` [compile]: `keys` — это `Set`, а `ChampionResult` ждёт `List<Int>`: `ChampionResult(totalSteps.keys, maxSteps)` не скомпилируется

## e3
```kotlin
data class StepEntry(val userId: Int, val steps: Int)
data class ChampionResult(val userIds: List<Int>, val steps: Int)

fun findChampions(statistics: List<List<StepEntry>>): ChampionResult {
    // сколько всего дней
    val totalDays = statistics.size
    // userId -> сумма шагов
    val totalSteps = HashMap<Int, Int>()
    // userId -> дней участия
    val daysActive = HashMap<Int, Int>()

    // один проход по всем записям
    for (day in statistics) for (entry in day) {
        totalSteps[entry.userId] = totalSteps.getOrDefault(entry.userId, 0) + ⟦entry.steps⟧
        daysActive[entry.userId] = daysActive.getOrDefault(entry.userId, 0) + ⟦1⟧
    }

    // кто участвовал во все дни
    val allDaysUsers = daysActive.filterValues { it == ⟦totalDays⟧ }.keys
    // лучший результат среди них
    val maxSteps = ⟦allDaysUsers⟧.maxOfOrNull { totalSteps[it] ?: 0 } ?: 0
    // все с максимумом
    val champions = allDaysUsers.filter { totalSteps[it] == maxSteps }
    return ChampionResult(champions, maxSteps)
}
```
- `totalSteps.keys` [wrong]: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `ChampionResult([], 500)` вместо `([1], 200)`
- `daysActive.size` [wrong]: это число юзеров, а не дней: день `[(1, 100), (2, 50)]` → дней `1`, юзеров `2`, ответ `([], 0)` вместо `([1], 100)`
- `entry.userId` [wrong]: к шагам прибавляется номер юзера: день `[(1, 100), (2, 50)]` → `ChampionResult([2], 2)` вместо `([1], 100)`
- @1 `1` [wrong]: `totalSteps` считает записи, а не шаги: день `[(1, 100), (2, 50)]` → ничья `1` и `2` с `steps = 1` вместо `([1], 100)`
- @1 `totalDays` [wrong]: за каждую запись прибавляется число дней, а не шаги: день `[(1, 100), (2, 50)]` → ничья `1` и `2` с `steps = 1` вместо `([1], 100)`
- @1 `allDaysUsers` [compile]: `allDaysUsers` объявлен ниже, после цикла: `+ allDaysUsers` не скомпилируется
- @1 `totalSteps.keys` [compile]: к числу не прибавить множество: `+ totalSteps.keys` не скомпилируется
- @1 `daysActive.size` [wrong]: к шагам прибавляется текущее число юзеров в `daysActive`: день `[(1, 100), (2, 50)]` → `ChampionResult([2], 1)` вместо `([1], 100)`
- @2 `entry.steps` [wrong]: `daysActive` копит шаги, а не дни, и не совпадёт с `totalDays`: день `[(1, 100)]` → `daysActive[1] = 100`, ответ `([], 0)` вместо `([1], 100)`
- @2 `totalDays` [wrong]: за каждый день прибавляется число дней: дни `[(1, 100)]`, `[(1, 100)]` → `daysActive[1] = 4` вместо `2`, ответ `([], 0)` вместо `([1], 200)`
- @2 `allDaysUsers` [compile]: `allDaysUsers` объявлен ниже, после цикла: `+ allDaysUsers` не скомпилируется
- @2 `totalSteps.keys` [compile]: к числу не прибавить множество: `+ totalSteps.keys` не скомпилируется
- @2 `daysActive.size` [wrong]: первая запись юзера прибавляет `0` — пока в `daysActive` никого нет: день `[(1, 100)]` → `daysActive[1] = 0`, ответ `([], 0)` вместо `([1], 100)`
- @2 `entry.userId` [wrong]: прибавляется номер юзера, а не `1` за день: день `[(2, 100)]` → `daysActive[2] = 2` вместо `1`, ответ `([], 0)` вместо `([2], 100)`
- @3 `entry.steps` [compile]: после цикла `entry` вне области видимости: `it == entry.steps` не скомпилируется
- @3 `1` [wrong]: остаются те, кто был ровно один день, а не все дни: дни `[(1, 100)]`, `[(1, 100)]` → `([], 0)` вместо `([1], 200)`
- @3 `allDaysUsers` [compile]: `allDaysUsers` ссылается на саму себя: `val allDaysUsers = daysActive.filterValues { it == allDaysUsers }` не скомпилируется
- @3 `totalSteps.keys` [compile]: число дней не сравнить с множеством: `it == totalSteps.keys` не скомпилируется
- @3 `entry.userId` [compile]: после цикла `entry` вне области видимости: `it == entry.userId` не скомпилируется
- @4 `entry.steps` [compile]: после цикла `entry` вне области видимости: `entry.steps.maxOfOrNull { … }` не скомпилируется
- @4 `1` [compile]: у числа нет `maxOfOrNull`, нужна коллекция юзеров: `1.maxOfOrNull { … }` не скомпилируется
- @4 `totalDays` [compile]: у числа нет `maxOfOrNull`, нужна коллекция юзеров: `totalDays.maxOfOrNull { … }` не скомпилируется
- @4 `daysActive.size` [compile]: у числа нет `maxOfOrNull`, нужна коллекция юзеров: `daysActive.size.maxOfOrNull { … }` не скомпилируется
- @4 `entry.userId` [compile]: после цикла `entry` вне области видимости: `entry.userId.maxOfOrNull { … }` не скомпилируется

? Шаги копим по `entry.steps`, дни — по одному за запись.
? «Без пропусков» = число дней участия равно `statistics.size`.
? Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).
