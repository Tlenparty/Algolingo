# l1.2
note: 1.2 Первый неповторяющийся символ
title: Первый уникальный символ
trains: `Map` частот + второй проход по строке
pitfalls:
- Нельзя искать уникальный по самой `Map`: она не гарантирует порядок вставки, иди по строке
- Один проход не работает: пока строка не дочитана, неизвестно, повторится ли символ
examples:
- assertEquals('c', firstUniqueChar("abacb"))
- assertNull(firstUniqueChar("aabb"))
- assertEquals('z', firstUniqueChar("z"))
- assertNull(firstUniqueChar(""))
- assertEquals('b', firstUniqueChar("ba"))
checks:
```kotlin
// оракул: первый символ с s.count == 1 (квадратичный подсчёт, без Map); все строки длины 0..5 из {a, b, c}
for (n in 0..5) case {
    for (m in 0 until pw(3, n)) {
        val s = CharArray(n) { 'a' + (m / pw(3, it)) % 3 }.concatToString()
        assertEquals(s.firstOrNull { c -> s.count { it == c } == 1 }, firstUniqueChar(s))
    }
}
case { assertEquals('a', firstUniqueChar("abb")) } // уникальный первым
case { assertEquals('b', firstUniqueChar("aab")) } // уникальный последним
case { assertNull(firstUniqueChar("abcabc")) }
// контрпримеры из причин
case { assertNull(firstUniqueChar("aa")) }
case { assertEquals('a', firstUniqueChar("ab")) }
```

## theory Когда Map частот
signals:
- «Сколько раз встречается?»
- «Ровно один раз», «чаще всего»
- «Первый такой» — важен порядок исходных данных
body: `HashMap<Char, Int>` считает частоты за один проход O(n); память O(k), где k — размер алфавита.

## theory Каркас: два прохода
skeleton:
```kotlin
// символ -> сколько раз
val counts = HashMap<Char, Int>()
// 1-й проход: считаем частоты
for (char in s) counts[char] = counts.getOrDefault(char, 0) + 1
// 2-й проход: первый уникальный
for (char in s) if (counts[char] == 1) return char
```
body: Первый проход считает, второй идёт снова по строке `s`: только она знает, какой символ был первым.

## theory Грабли
pitfalls:
- Искать уникальный по самой `Map`: `HashMap` не хранит порядок вставки, иди по строке
- Пытаться в один проход: пока строка не дочитана, неизвестно, повторится ли символ
- Стартовое значение счётчика `1` вместо `0`: каждый символ посчитается дважды

## e1
```kotlin
fun firstUniqueChar(s: String): Char? {
    // символ -> сколько раз
    val counts = HashMap<Char, Int>()
    // 1-й проход: считаем частоты
    for (char in s) counts[char] = counts.getOrDefault(char, 0) + 1
    // 2-й проход: первый уникальный
    for (char in ⟦s⟧) if (counts[char] == 1) return char
    // уникального символа нет
    return null
}
```
- `counts.keys` [wrong]: `HashMap` не обещает порядок обхода: на JVM `"ba"` → `'a'` вместо `'b'`. Что iOS случайно обходит по вставке, — не гарантия
- `s.reversed()` [wrong]: с конца найдётся последний уникальный, а не первый: `"ab"` → `'b'` вместо `'a'`
? Первый проход — считаем частоты. Второй проход **по исходной строке** (порядок важен!) — первый символ с частотой 1.

## e2
```kotlin
fun firstUniqueChar(s: String): Char? {
    // символ -> сколько раз
    val counts = HashMap<Char, Int>()
    // 1-й проход: считаем частоты
    for (char in s) counts[char] = counts.getOrDefault(char, ⟦0⟧) + 1
    // 2-й проход: первый уникальный
    for (char in s) if (counts[char] == ⟦1⟧) return char
    // уникального символа нет
    return null
}
```
- `2` [wrong]: ищем символ, который встретился ровно дважды: `"aab"` → `'a'` вместо `'b'`
- @1 `2` [wrong]: каждый символ начинает с `2`, частоты ≥ 3: `"z"` → `null` вместо `'z'`
- @1 `1` [wrong]: счёт начинается с `1`, у одиночки частота `2`: `"z"` → `null` вместо `'z'`
- @2 `0` [wrong]: символ из строки встретился хотя бы раз, `0` не бывает: `"z"` → `null` вместо `'z'`
? Нового символа в `counts` ещё нет — сколько раз мы его видели до этого?
? Уникальный — тот, что встретился ровно один раз.

## e3
```kotlin
fun firstUniqueChar(s: String): Char? {
    // символ -> сколько раз
    val counts = HashMap<Char, Int>()
    // 1-й проход: считаем частоты
    for (char in s) counts[char] = counts.getOrDefault(char, ⟦0⟧) + 1
    // 2-й проход: первый уникальный
    for (char in ⟦s⟧) if (counts[char] == ⟦1⟧) return char
    // уникального символа нет
    return ⟦null⟧
}
```
- `counts.keys` [wrong]: `HashMap` не обещает порядок обхода: на JVM `"ba"` → `'a'` вместо `'b'`. Что iOS случайно обходит по вставке, — не гарантия
- `' '` [wrong]: «не нашли» — это `null`, а пробел выглядит как найденный символ: `"aa"` → `' '` вместо `null`
- @1 `s` [compile]: значение по умолчанию станет общим типом `Int` и `String`, к нему не прибавить `1`: `counts.getOrDefault(char, s) + 1` не скомпилируется
- @1 `1` [wrong]: счёт начинается с `1`, у одиночки частота `2`: `"z"` → `null` вместо `'z'`
- @1 `null` [compile]: `getOrDefault(char, null)` вернёт `Int?`, и `+ 1` не скомпилируется
- @1 `counts.keys` [compile]: результат — `Any`, к нему не прибавить `1`: `counts.getOrDefault(char, counts.keys) + 1` не скомпилируется
- @1 `' '` [compile]: результат — не число, к нему не прибавить `1`: `counts.getOrDefault(char, ' ') + 1` не скомпилируется
- @2 `0` [compile]: по числу не пройти циклом: `for (char in 0)` не скомпилируется
- @2 `1` [compile]: по числу не пройти циклом: `for (char in 1)` не скомпилируется
- @2 `null` [compile]: по `null` не пройти циклом: `for (char in null)` не скомпилируется
- @2 `' '` [compile]: по одному символу не пройти циклом: `for (char in ' ')` не скомпилируется
- @3 `0` [wrong]: символ из строки встретился хотя бы раз, `0` не бывает: `"z"` → `null` вместо `'z'`
- @3 `s` [compile]: частота — `Int?`, со строкой её не сравнить: `counts[char] == s` не скомпилируется
- @3 `null` [wrong]: каждый символ строки есть в `counts`, условие всегда ложно: `"z"` → `null` вместо `'z'`
- @3 `counts.keys` [compile]: частота — `Int?`, с множеством её не сравнить: `counts[char] == counts.keys` не скомпилируется
- @3 `' '` [compile]: частота — `Int?`, с символом её не сравнить: `counts[char] == ' '` не скомпилируется
- @4 `0` [compile]: функция возвращает `Char?`, а не число: `return 0` не скомпилируется
- @4 `s` [compile]: функция возвращает `Char?`, а не строку: `return s` не скомпилируется
- @4 `1` [compile]: функция возвращает `Char?`, а не число: `return 1` не скомпилируется
- @4 `counts.keys` [compile]: функция возвращает `Char?`, а не множество: `return counts.keys` не скомпилируется
? Первый проход — считаем частоты. Второй проход **по исходной строке** (порядок важен!) — первый символ с частотой 1.
? Уникального нет — честно верни «ничего».
