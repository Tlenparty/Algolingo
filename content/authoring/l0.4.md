# l0.4
note: 0.4 Бинарный поиск
examples:
- assertEquals(2, binarySearch(intArrayOf(1, 3, 5, 7), 5))
- assertEquals(-1, binarySearch(intArrayOf(1, 3), 0))
- assertEquals(0, binarySearch(intArrayOf(5), 5))
- assertEquals(-1, binarySearch(intArrayOf(), 1))
checks:
```kotlin
// оракул: a.contains(t) + «по найденному индексу лежит t» (при дублях индекс не единственный)
// все отсортированные массивы длины 0..5 из {0..3}, target -1..4
for (n in 0..5) case {
    for (m in 0 until pw(4, n)) {
        val a = IntArray(n) { (m / pw(4, it)) % 4 }.also { it.sort() }
        for (t in -1..4) {
            val r = binarySearch(a, t)
            if (a.contains(t)) assertTrue(r in a.indices && a[r] == t) else assertEquals(-1, r)
        }
    }
}
```

## theory Когда бинпоиск
signals:
- Массив отсортирован
- Нужно уложиться в O(log n)
- Ищем индекс или границу
body: Каждый шаг выбрасывает половину диапазона, поэтому O(log n).

## theory Каркас
skeleton:
```kotlin
// ответ внутри [left, right]
var left = 0
var right = nums.size - 1
// сужаем диапазон
while (left <= right) {
    // середина диапазона
    val mid = left + (right - left) / 2
    // нашли / вправо / влево
}
```
body: Инвариант: ответ, если он есть, всегда внутри `[left, right]`.

## theory Грабли
pitfalls:
- `left < right` вместо `<=` пропустит последний элемент
- `(left + right) / 2` может переполниться на больших индексах

## e1
```kotlin
fun binarySearch(nums: IntArray, target: Int): Int {
    // ответ внутри [left, right]
    var left = 0
    var right = nums.size - 1
    // сужаем диапазон
    while (⟦left <= right⟧) {
        // середина диапазона
        val mid = left + (right - left) / 2
        when {
            // нашли target
            nums[mid] == target -> return mid
            // target правее
            nums[mid] < target  -> left = mid + 1
            // target левее
            else                -> right = mid - 1
        }
    }
    // target в массиве нет
    return -1
}
```
- `left < right` [wrong]: при `left == right` цикл не зайдёт и последний кандидат пропущен: `[5]`, target `5` вернёт `-1`
- `left != right` [hang]: при `left == right` цикл останавливается, не проверив последний кандидат: `[1, 3]`, target `3` вернёт `-1`; а если `right` уйдёт ниже `left`, условие останется истинным: `[1, 3]`, target `0` зацикливается
- `left >= right` [wrong]: условие ложно с самого начала: на `[1, 3]`, target `1` цикл не выполнится ни разу
? Цикл идёт, пока диапазон `[left, right]` не пуст, то есть пока `left <= right`.

## e2
```kotlin
fun binarySearch(nums: IntArray, target: Int): Int {
    // ответ внутри [left, right]
    var left = 0
    var right = nums.size - 1
    // сужаем диапазон
    while (⟦left <= right⟧) {
        // середина диапазона
        val mid = ⟦left + (right - left) / 2 | ~(left + right) ushr 1 | ~(left + right) / 2 | ~right - left / 2⟧
        when {
            // нашли target
            nums[mid] == target -> return mid
            // target правее
            nums[mid] < target  -> left = mid + 1
            // target левее
            else                -> right = mid - 1
        }
    }
    // target в массиве нет
    return -1
}
```
- ~`(left + right) ushr 1`: работает, но эталон читаемее и не опирается на беззнаковый сдвиг
- `left < right` [wrong]: при `left == right` цикл не зайдёт: `[5]`, target `5` вернёт `-1`
- ~`(left + right) / 2`: работает, пока в массиве меньше 2^30 элементов; на огромных индексах `left + right` переполнит `Int`, эталон `left + (right - left) / 2` безопаснее
- ~`right - left / 2`: верно, но это линейный проход O(n) справа налево, а не бинпоиск: `left / 2` всегда `0`
- @1 `(left + right) / 2` [compile]: `while` ждёт `Boolean`, а это `Int`: не скомпилируется
- @1 `right - left / 2` [compile]: `while` ждёт `Boolean`, а это `Int`: не скомпилируется
- @2 `left < right` [compile]: `mid` станет `Boolean`, и `nums[mid]` не скомпилируется
? Цикл идёт, пока диапазон `[left, right]` не пуст, то есть пока `left <= right`.
? Середина `mid = left + (right - left) / 2` (защита от переполнения). Три ветки: нашли / ушли вправо / ушли влево.

## e3
```kotlin
fun binarySearch(nums: IntArray, target: Int): Int {
    // ответ внутри [left, right]
    var left = 0
    var right = nums.size - 1
    // сужаем диапазон
    while (⟦left <= right⟧) {
        // середина диапазона
        val mid = left + (right - left) / 2
        when {
            // нашли target
            nums[mid] == target -> return ⟦mid⟧
            // target правее
            nums[mid] < target  -> left = mid + ⟦1⟧
            // target левее
            else                -> right = mid - ⟦1⟧
        }
    }
    // target в массиве нет
    return -1
}
```
- `left < right` [wrong]: при `left == right` цикл не зайдёт: `[5]`, target `5` вернёт `-1`
- `0` [hang]: `left = mid + 0` зацикливается: на `[1, 3]`, target `3` `left` остаётся `0` навсегда
- `-1` [hang]: `left = mid + -1` уводит границу назад: на `[1, 3]`, target `3` `left = -1`, `mid` снова `0`, цикл бесконечный
- @1 `0` [compile]: `while` ждёт `Boolean`, а это `Int`: не скомпилируется
- @1 `-1` [compile]: `while` ждёт `Boolean`, а это `Int`: не скомпилируется
- @2 `0` [wrong]: вернёт `0` вместо найденного индекса: `[1, 3]`, target `3` даст `0`
- @2 `-1` [wrong]: скажет «не найдено», хотя элемент есть: `[5]`, target `5` даст `-1`
- @2 `left < right` [compile]: здесь нужен `Int`, а `left < right` — `Boolean`: не скомпилируется
- @2 `1` [wrong]: вернёт константу `1`, а не индекс: `[5]`, target `5` даст `1` — такого индекса нет
- @3 `left < right` [compile]: здесь нужен `Int`, а `left < right` — `Boolean`: не скомпилируется
- @3 `mid` [hang]: `left = mid + mid` = 2·`mid`: `[1, 3]`, target `3` — `mid = 0`, `left` остаётся `0`, цикл бесконечный
- @4 `0` [hang]: `right = mid - 0` не исключает `mid`: `[1, 3]`, target `0` — `right = 0`, `mid` снова `0`, цикл бесконечный
- @4 `-1` [hang]: `right = mid - -1 = mid + 1` не сужает диапазон: `[1, 3]`, target `0` — `mid = 0`, `right` снова `1`, цикл бесконечный
- @4 `left < right` [compile]: здесь нужен `Int`, а `left < right` — `Boolean`: не скомпилируется
- @4 `mid` [wrong]: `right = mid - mid` всегда `0`: `[1, 3, 5, 7, 9]`, target `3` — `right = 0`, вернёт `-1`
? Середина `mid = left + (right - left) / 2` (защита от переполнения). Три ветки: нашли / ушли вправо / ушли влево.
? Если нашли, возвращаем `mid`; иначе сдвигаем границу за `mid`: `left = mid + 1` или `right = mid - 1`.
