# l2.2
note: 2.2 Удаление дубликатов из отсортированного массива
title: Удаление дубликатов
examples:
- assertEquals(2, removeDuplicates(intArrayOf(1, 1, 2)))
- assertContentEquals(intArrayOf(1, 2), intArrayOf(1, 1, 2).let { it.copyOf(removeDuplicates(it)) })
- assertContentEquals(intArrayOf(0, 1, 2, 3, 4), intArrayOf(0, 0, 1, 1, 1, 2, 2, 3, 3, 4).let { it.copyOf(removeDuplicates(it)) })
checks:
```kotlin
// оракул: distinct() отсортированного массива; ответ k и первые k ячеек
// все отсортированные массивы длины 0..6 из {0..3}
for (n in 0..6) case {
    for (m in 0 until pw(4, n)) {
        val a = IntArray(n) { (m / pw(4, it)) % 4 }.also { it.sort() }
        val expected = a.distinct()
        val got = a.copyOf()
        val k = removeDuplicates(got)
        assertEquals(expected.size, k, a.toList().toString())
        assertEquals(expected, got.take(k), a.toList().toString())
    }
}
case { assertEquals(0, removeDuplicates(intArrayOf())) }
case { assertContentEquals(intArrayOf(-3, 0, 7), intArrayOf(-3, -3, 0, 7, 7, 7).let { it.copyOf(removeDuplicates(it)) }) }
case { assertContentEquals(intArrayOf(Int.MIN_VALUE, Int.MAX_VALUE), intArrayOf(Int.MIN_VALUE, Int.MAX_VALUE, Int.MAX_VALUE).let { it.copyOf(removeDuplicates(it)) }) }
// контрпримеры из причин
case { assertContentEquals(intArrayOf(1, 2), intArrayOf(1, 2).let { it.copyOf(removeDuplicates(it)) }) }
case { assertContentEquals(intArrayOf(1, 2), intArrayOf(1, 1, 2).let { it.copyOf(removeDuplicates(it)) }) }
case { assertEquals(1, removeDuplicates(intArrayOf(2, 2))) }
case { assertEquals(1, removeDuplicates(intArrayOf(5, 5))) }
case { assertEquals(1, removeDuplicates(intArrayOf(1))) }
```

## theory Когда fast/slow с длиной
signals:
- Массив **отсортирован**: одинаковые стоят рядом
- Убрать повторы **на месте**, без второго массива
- Вернуть надо длину, а не новый массив
body: `fast` читает каждый элемент, `slow` — длина готовой части и место для следующего нового значения. Новое оно или нет, видно по последнему записанному `nums[slow - 1]`. Ответ — сам `slow`.

## theory Каркас
skeleton:
```kotlin
// первый всегда остаётся
var slow = 1
// fast ищет новые значения
for (fast in 1 until nums.size) {
    // новое — пишем в slow
    if (isNew(nums[fast])) {
        nums[slow] = nums[fast]
        slow++
    }
}
// slow — это и есть длина
return slow
```
body: Что лежит после `slow`, не важно: проверяют только первые `slow` ячеек. Пустой массив отсекаем заранее, иначе `slow = 1` соврёт.

## theory Грабли
pitfalls:
- Вернуть `slow - 1`: `slow` уже указывает на первую свободную ячейку, это и есть длина
- `slow = 0`: `nums[slow - 1]` читает `nums[-1]` и падает
- Сравнивать с `nums[slow]` — это свободная ячейка, а не последнее записанное значение: `[1, 2]` → `1`
- Забыть про пустой массив: ответ `0`, а не `1`

## e1
```kotlin
fun removeDuplicates(nums: IntArray): Int {
    // пустой — уникальных нет
    if (nums.isEmpty()) return 0
    // nums[0] всегда остаётся
    var slow = 1
    // fast ищет новые значения
    for (fast in 1 until nums.size) {
        // не равно последнему?
        if (nums[fast] != ⟦nums[slow - 1] | ~nums[fast - 1]⟧) {
            // пишем на место slow
            nums[slow] = nums[fast]
            slow++
        }
    }
    // длина без дубликатов
    return slow
}
```
- ~`nums[fast - 1]`: тоже верно: это предыдущий прочитанный, запись идёт только левее `fast`, и он не испорчен. Но `nums[slow - 1]` — последний записанный, и этот вариант обобщается: для LeetCode 80 сравнивают с `nums[slow - 2]`
- `nums[slow]` [wrong]: `nums[slow]` — свободная ячейка, а не последнее записанное: `[1, 2]` → `1` вместо `2`
- `nums[fast]` [wrong]: число равно самому себе, новое не найдётся никогда: `[1, 2]` → `1` вместо `2`
? Массив отсортирован: новое значение отличается от последнего записанного.

## e2
```kotlin
fun removeDuplicates(nums: IntArray): Int {

```
- ~`nums[fast - 1]`: тоже верно: это предыдущий прочитанный, запись идёт только левее `fast`, и он не испорчен. Но `nums[slow - 1]` — последний записанный, и этот вариант обобщается: для LeetCode 80 сравнивают с `nums[slow - 2]`
- `nums[slow]` [wrong]: `nums[slow]` — свободная ячейка, а не последнее записанное: `[1, 2]` → `1` вместо `2`
- `slow - 1` [wrong]: `slow` уже указывает на первую свободную ячейку, это и есть длина: `[1, 1, 2]` → `1` вместо `2`
- `nums.size` [wrong]: длина вместе с дубликатами: `[1, 1, 2]` → `3` вместо `2`
- @1 `slow` [wrong]: сравниваем число с индексом: `[2, 2]` → `2 != 1`, дубликат записан, ответ `2` вместо `1`
- @1 `slow - 1` [wrong]: сравниваем число с индексом: `[1, 1]` → `1 != 0`, дубликат записан, ответ `2` вместо `1`
- @1 `nums.size` [wrong]: сравниваем число с длиной массива: `[1, 1]` → `1 != 2`, дубликат записан, ответ `2` вместо `1`
- @2 `nums[slow - 1]` [wrong]: вернём последнее значение, а не длину: `[5, 5]` → `5` вместо `1`
- @2 `nums[fast - 1]` [compile]: `fast` живёт только внутри `for`: `return nums[fast - 1]` не скомпилируется
- @2 `nums[slow]` [crash]: без дубликатов `slow` дойдёт до конца массива: `[1, 2]` → `nums[2]` падает с `ArrayIndexOutOfBoundsException`
? Массив отсортирован: новое значение отличается от последнего записанного.
? `slow` указывает на первую свободную ячейку.
