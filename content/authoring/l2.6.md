# l2.6
note: 2.6 Максимальное среднее подмассива длины k
title: Максимальное среднее подмассива
examples:
- assertEquals(12.75, findMaxAverage(intArrayOf(1, 12, -5, -6, 50, 3), 4), 1e-9)
- assertEquals(5.0, findMaxAverage(intArrayOf(5), 1), 1e-9)
checks:
```kotlin
// оракул: сумма каждого окна заново, лучшая / k; все массивы длины 1..5 из {-2..2}, все k
for (n in 1..5) case {
    for (m in 0 until pw(5, n)) {
        val a = IntArray(n) { (m / pw(5, it)) % 5 - 2 }
        for (k in 1..n) {
            val best = (0..n - k).maxOf { start -> (start until start + k).sumOf { a[it] } }
            assertEquals(best.toDouble() / k, findMaxAverage(a.copyOf(), k), 1e-9, "${a.toList()} $k")
        }
    }
}
case { assertEquals(-1.5, findMaxAverage(intArrayOf(-3, -1, -2), 2), 1e-9) }
case { assertEquals(0.0, findMaxAverage(intArrayOf(0, 0, 0), 3), 1e-9) }
case { assertEquals(10000.0, findMaxAverage(IntArray(5) { 10000 }, 5), 1e-9) }
case { assertEquals(5.0, findMaxAverage(intArrayOf(1, 2, 3, 4, 5, 6), 3), 1e-9) }
// контрпримеры из причин
case { assertEquals(-1.0, findMaxAverage(intArrayOf(-1), 1), 1e-9) }
case { assertEquals(2.5, findMaxAverage(intArrayOf(1, 2, 3), 2), 1e-9) }
case { assertEquals(2.0, findMaxAverage(intArrayOf(1, 2), 1), 1e-9) }
case { assertEquals(2.0, findMaxAverage(intArrayOf(2, 1), 1), 1e-9) }
```

## theory Когда окно фиксированной длины
signals:
- Подряд идущий отрезок **ровно** из `k` элементов
- Лучшая сумма или среднее по всем таким отрезкам
- Нужно O(n), а не O(n·k)
body: Соседние окна отличаются двумя числами: справа вошло `nums[i]`, слева ушло `nums[i - k]`. Сумму не пересчитываем, а поправляем за O(1). Длина окна постоянна, поэтому максимальное среднее — это максимальная сумма, делённая на `k`.

## theory Каркас
skeleton:
```kotlin
// сумма первого окна
var windowSum = 0
for (i in 0 until k) windowSum += nums[i]
// сдвигаем окно на 1
for (i in k until nums.size) {
    // вошёл новый, ушёл старый
    windowSum += nums[i] - nums[i - k]
    // обновляем ответ
}
```
body: Делим один раз, в самом конце: внутри цикла хватает целых сумм.

## theory Грабли
pitfalls:
- `maxSum / k`: `Int` на `Int` даёт `Int`, дробь теряется: `51 / 4 = 12`, а нужно `12.75`
- `maxSum = 0`: у окна из отрицательных сумма меньше нуля: `[-1]`, `k = 1` → `0.0`
- Вычитать `nums[i - 1]` вместо `nums[i - k]`: из окна уходит не тот элемент
- Пересчитывать сумму каждого окна заново — O(n·k)

## e1
```kotlin
fun findMaxAverage(nums: IntArray, k: Int): Double {
    // сумма первого окна
    var windowSum = 0
    for (i in 0 until k) windowSum += nums[i]
    // лучшая сумма пока что
    var maxSum = windowSum
    // сдвигаем окно на 1
    for (i in k until nums.size) {
        // вошёл новый, ушёл старый
        windowSum += nums[i] - nums[i - k]
        // запоминаем лучшее
        maxSum = maxOf(maxSum, windowSum)
    }
    // среднее с дробной частью
    return ⟦maxSum.toDouble() / k⟧
}
```
- `(maxSum / k).toDouble()` [wrong]: делим ещё в `Int`, дробь теряется до `toDouble()`: `[1, 12, -5, -6, 50, 3]`, `k = 4` → `12.0` вместо `12.75`
- `maxSum / k` [compile]: `Int` на `Int` даёт `Int`, а функция возвращает `Double`: `return maxSum / k` не скомпилируется
? Средним может быть `12.75`. Что будет с дробью при делении целого на целое?

## e3
```kotlin
fun findMaxAverage(nums: IntArray, k: Int): Double {
    // сумма первого окна
    var windowSum = 0
    for (i in 0 until k) windowSum += nums[i]
    // лучшая сумма пока что
    var maxSum = ⟦windowSum⟧
    // сдвигаем окно на 1
    for (i in k until nums.size) {
        // вошёл новый, ушёл старый
        windowSum += ⟦nums[i] - nums[i - k]⟧
        // запоминаем лучшее
        maxSum = ⟦maxOf⟧(maxSum, windowSum)
    }
    // среднее с дробной частью
    return maxSum.toDouble() / k
}
```
- `0` [wrong]: у окна из отрицательных сумма меньше нуля, и `0` её не пустит: `[-1]`, `k = 1` → `0.0` вместо `-1.0`
- `nums[i] - nums[i - 1]` [wrong]: из окна уходит не тот элемент: `[1, 2, 3]`, `k = 2` → `2.0` вместо `2.5`
- `minOf` [wrong]: запоминаем худшее окно, а не лучшее: `[1, 2]`, `k = 1` → `1.0` вместо `2.0`
- @1 `nums[i] - nums[i - k]` [compile]: `i` живёт только внутри цикла, здесь его нет: `var maxSum = nums[i] - nums[i - k]` не скомпилируется
- @1 `nums[i] - nums[i - 1]` [compile]: `i` живёт только внутри цикла, здесь его нет: `var maxSum = nums[i] - nums[i - 1]` не скомпилируется
- @1 `maxOf` [compile]: `maxOf` — функция, без скобок с аргументами это не число: `var maxSum = maxOf` не скомпилируется
- @1 `minOf` [compile]: `minOf` — функция, без скобок с аргументами это не число: `var maxSum = minOf` не скомпилируется
- @2 `windowSum` [wrong]: сумма удваивается вместо сдвига: `[2, 1]`, `k = 1` → `4.0` вместо `2.0`
- @2 `0` [wrong]: сумма окна не меняется, окно стоит на месте: `[1, 2]`, `k = 1` → `1.0` вместо `2.0`
- @2 `maxOf` [compile]: прибавить можно число, а не функцию: `windowSum += maxOf` не скомпилируется
- @2 `minOf` [compile]: прибавить можно число, а не функцию: `windowSum += minOf` не скомпилируется
- @3 `windowSum` [compile]: число нельзя вызвать как функцию: `windowSum(maxSum, windowSum)` не скомпилируется
- @3 `nums[i] - nums[i - k]` [compile]: число нельзя вызвать как функцию: `nums[i - k](maxSum, windowSum)` не скомпилируется
- @3 `0` [compile]: число нельзя вызвать как функцию: `0(maxSum, windowSum)` не скомпилируется
- @3 `nums[i] - nums[i - 1]` [compile]: число нельзя вызвать как функцию: `nums[i - 1](maxSum, windowSum)` не скомпилируется
