# l4.2
note: 4.2 Максимальная сумма подмассива (Кадане)
title: Максимальная сумма подмассива
statement: Найди максимальную сумму непрерывного подмассива непустого массива (LeetCode 53).
trains: алгоритм Кадане: продолжить серию или начать заново
pitfalls:
- Начинать с `0`, а не с `nums[0]`: на всех отрицательных вернёшь `0` вместо максимума: `[-3, -1, -2]` → `-1`
- `Int.MIN_VALUE` как старт `current`: `current + nums[i]` переполнится и станет огромным плюсом
- Цикл с `0` при `current = nums[0]`: первый элемент посчитается дважды
- Перебирать все подмассивы — O(n²) или O(n³), а Кадане проходит один раз
variations:
- старт `best = Int.MIN_VALUE`, `current = 0` и цикл с `0`, где `current = maxOf(x, current + x)` — тоже верно
- нужны границы подмассива: запоминай `start`, когда серия начинается заново, и `end`, когда растёт `best`
- «разделяй и властвуй» — O(n log n): лучшее слева, справа или через середину
examples:
- assertEquals(6, maxSubArray(intArrayOf(-2, 1, -3, 4, -1, 2, 1, -5, 4)))
- assertEquals(1, maxSubArray(intArrayOf(1)))
- assertEquals(-1, maxSubArray(intArrayOf(-3, -1, -2)))
checks:
```kotlin
// оракул: перебор всех подмассивов; все массивы длины 1..5 из {-2..2}
for (n in 1..5) case {
    for (m in 0 until pw(5, n)) {
        val a = IntArray(n) { (m / pw(5, it)) % 5 - 2 }
        var best = a[0]
        for (l in 0 until n) for (r in l until n) best = maxOf(best, (l..r).sumOf { a[it] })
        assertEquals(best, maxSubArray(a.copyOf()), "${a.toList()}")
    }
}
// оракул на длинных случайных массивах из {-100..100}
case {
    repeat(50) {
        val a = IntArray(1 + rnd.nextInt(40)) { rnd.nextInt(201) - 100 }
        var best = a[0]
        for (l in a.indices) {
            var sum = 0
            for (r in l until a.size) {
                sum += a[r]
                best = maxOf(best, sum)
            }
        }
        assertEquals(best, maxSubArray(a.copyOf()), "${a.toList()}")
    }
}
case { assertEquals(15, maxSubArray(intArrayOf(1, 2, 3, 4, 5))) } // весь массив
case { assertEquals(-10000, maxSubArray(intArrayOf(-10000))) }
case { assertEquals(0, maxSubArray(intArrayOf(-1, 0, -2))) }
case { assertEquals(7, maxSubArray(intArrayOf(5, -1, 3))) } // через минус
case { assertEquals(9, maxSubArray(intArrayOf(5, -9, 9))) } // начать заново
// контрпримеры из причин
case { assertEquals(3, maxSubArray(intArrayOf(1, 2))) }
case { assertEquals(2, maxSubArray(intArrayOf(1, -1, 2))) }
case { assertEquals(6, maxSubArray(intArrayOf(1, 2, 3))) }
case { assertEquals(1, maxSubArray(intArrayOf(1, -1))) }
case { assertEquals(5, maxSubArray(intArrayOf(5))) }
case { assertEquals(-1, maxSubArray(intArrayOf(-1))) }
case { assertEquals(-1, maxSubArray(intArrayOf(-1, -2))) }
case { assertEquals(2, maxSubArray(intArrayOf(-1, 2))) }
```

## theory Когда Кадане
signals:
- Подряд идущий отрезок с **максимальной суммой**
- Числа бывают отрицательными, длина отрезка любая
- Нужно O(n) и O(1) памяти
body: Идём слева направо и держим `current` — лучшую сумму отрезка, который кончается на `i`. Для каждого `nums[i]` выбор один: продолжить серию (`current + nums[i]`) или начать заново с него (`nums[i]`). Ответ `best` — максимум всех `current`.

## theory Каркас
skeleton:
```kotlin
// кончается на i
var current = nums[0]
// лучшая вообще
var best = nums[0]
for (i in 1 until nums.size) {
    // продолжить или заново
    current = maxOf(nums[i],
        current + nums[i])
    best = maxOf(best, current)
}
```
body: Старт — первый элемент, поэтому цикл идёт с `1`. Хвост с минусом выгоднее отрезать: тогда `nums[i]` один больше, чем `current + nums[i]`.

## theory Грабли
pitfalls:
- `best = 0`: на всех отрицательных ответ `0`, а нужно `-1`: `[-3, -1, -2]`
- `current = 0`: `nums[0]` выпадает из сумм: `[1, 2]` → `2` вместо `3`
- Цикл с `0`: `nums[0]` посчитается дважды: `[1]` → `2` вместо `1`
- `best + nums[i]` вместо `current + nums[i]`: отрезок склеится через выкинутые минусы: `[1, -1, 2]` → `3` вместо `2`

## e1
```kotlin
// Случай 1: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
//   → 6 (подмассив [4, -1, 2, 1])
// Случай 2: [1] → 1
// Случай 3: [-3, -1, -2] → -1
fun maxSubArray(nums: IntArray): Int {
    // лучшая сумма, кончающаяся на i
    var current = nums[0]
    // лучшая сумма вообще
    var best = nums[0]
    for (i in 1 until nums.size) {
        // продолжить серию или начать заново
        current = maxOf(nums[i], ⟦current + nums[i]⟧)
        best = maxOf(best, current)
    }
    return best
}
```
- `current` [wrong]: серия не копится, `current` — просто максимум из элементов: `[1, 2]` → `2` вместо `3`
- `best + nums[i]` [wrong]: к лучшей сумме приклеивается `nums[i]` через выкинутые элементы: `[1, -1, 2]` → `3` вместо `2`
- `nums[i - 1] + nums[i]` [wrong]: это только пара соседей, а не вся серия: `[1, 2, 3]` → `5` вместо `6`
? Серия, которая кончается на `i`, — это серия до `i - 1` плюс сам `nums[i]`.

## e2
```kotlin
// Случай 1: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
//   → 6 (подмассив [4, -1, 2, 1])
// Случай 2: [1] → 1
// Случай 3: [-3, -1, -2] → -1
fun maxSubArray(nums: IntArray): Int {
    // лучшая сумма, кончающаяся на i
    var current = ⟦nums[0]⟧
    // лучшая сумма вообще
    var best = ⟦nums[0]⟧
    for (i in 1 until nums.size) {
        // продолжить серию или начать заново
        current = maxOf(nums[i], current + nums[i])
        best = maxOf(best, current)
    }
    return best
}
```
- `0`
- `Int.MIN_VALUE`
- `nums[1]` [crash]: на массиве из одного элемента выход за границы: `[1]` упадёт на `nums[1]`
- @1 `0` [wrong]: `nums[0]` выпадает из всех сумм, цикл начинает с `1`: `[1, 2]` → `2` вместо `3`
- @2 `0` [wrong]: на всех отрицательных `0` так и останется ответом: `[-1]` → `0` вместо `-1`
- @1 `Int.MIN_VALUE` [wrong]: `Int.MIN_VALUE + (-1)` переполняется в огромный плюс: `[1, -1]` → `2147483647` вместо `1`
- @2 `Int.MIN_VALUE` [wrong]: цикл с `1` не сравнит `best` с `nums[0]`: `[5]` → `-2147483648` вместо `5`
? Цикл начинается с `1`. Кто тогда отвечает за первый элемент?
? Сумма из одного `nums[0]` — уже честный подмассив.

## e3
```kotlin
// Случай 1: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
//   → 6 (подмассив [4, -1, 2, 1])
// Случай 2: [1] → 1
// Случай 3: [-3, -1, -2] → -1
fun maxSubArray(nums: IntArray): Int {
    // лучшая сумма, кончающаяся на i
    var current = nums[0]
    // лучшая сумма вообще
    var best = nums[0]
    for (i in ⟦1⟧ until nums.size) {
        // продолжить серию или начать заново
        current = maxOf(nums[i], ⟦current + nums[i]⟧)
        best = maxOf(best, ⟦current⟧)
    }
    return best
}
```
- `0` [wrong]: `nums[0]` уже в `current`, а цикл прибавит его снова: `[1]` → `2` вместо `1`
- `nums[i]` [wrong]: серия не копится, ответ — просто максимум из элементов: `[1, 2]` → `2` вместо `3`
- `best + nums[i]` [wrong]: к лучшей сумме приклеивается `nums[i]` через выкинутые элементы: `[1, -1, 2]` → `3` вместо `2`
- @1 `current + nums[i]` [compile]: `i` появится только внутри цикла: `for (i in current + nums[i] until nums.size)` не скомпилируется
- @1 `current` [crash]: цикл начнётся с индекса `nums[0]`, а он бывает отрицательным: `[-1, 2]` упадёт на `nums[-1]`
- @1 `nums[i]` [compile]: `i` появится только внутри цикла: `for (i in nums[i] until nums.size)` не скомпилируется
- @1 `best + nums[i]` [compile]: `i` появится только внутри цикла: `for (i in best + nums[i] until nums.size)` не скомпилируется
- @2 `1` [wrong]: вместо серии — константа `1`, на отрицательных выйдет плюс: `[-1, -2]` → `1` вместо `-1`
- @2 `current` [wrong]: серия не копится, `current` — просто максимум из элементов: `[1, 2]` → `2` вместо `3`
- @2 `0` [wrong]: серия не копится, а `0` пролезает в ответ: `[-1, -2]` → `0` вместо `-1`
- @3 `1` [wrong]: `best` сравнивается с константой, а не с серией: `[1, 2]` → `1` вместо `3`
- @3 `current + nums[i]` [wrong]: `nums[i]` уже в `current`, он прибавится дважды: `[1, 2]` → `5` вместо `3`
- @3 `0` [wrong]: `best` сравнивается с нулём, а не с серией: `[1, 2]` → `1` вместо `3`
? Первый элемент уже стоит в `current` и `best`.
? Продолжить серию — это прибавить `nums[i]` к серии, которая кончилась на `i - 1`.
? Лучший ответ — максимум из всех серий.
