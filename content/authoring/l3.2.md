# l3.2
note: 3.2 Корректность скобок
title: Корректность скобок
trains: стек открытых + карта «закрывающая → открывающая»
pitfalls:
- Забыть финальную проверку `stack.isEmpty()`: `"("` ошибочно пройдёт как валидная
- Снимать вершину без проверки на пустоту: `")"` → падение на пустом стеке
- `removeFirst()` вместо `removeLast()` — это уже очередь: `"([)]"` пройдёт как валидная
examples:
- assertTrue(isValidBrackets("()[]{}"))
- assertFalse(isValidBrackets("([)]"))
- assertFalse(isValidBrackets("("))
- assertTrue(isValidBrackets("{[()]}"))
- assertTrue(isValidBrackets(""))
checks:
```kotlin
// оракул: прочие символы выкидываем, пары (), [], {} вычёркиваем, пока есть; пусто → true
fun oracle(t: String): Boolean {
    var r = t.filter { it in "()[]{}" }
    repeat(t.length) { r = r.replace("()", "").replace("[]", "").replace("{}", "") }
    return r.isEmpty()
}
// все строки длины 0..6 из ()[]{}
for (n in 0..6) case {
    for (m in 0 until pw(6, n)) {
        val s = CharArray(n) { "()[]{}"[(m / pw(6, it)) % 6] }.concatToString()
        assertEquals(oracle(s), isValidBrackets(s), s)
    }
}
// посторонние символы пропускаются: все строки длины 0..5 из ( ] x )
for (n in 0..5) case {
    for (m in 0 until pw(4, n)) {
        val s = CharArray(n) { "(]x)"[(m / pw(4, it)) % 4] }.concatToString()
        assertEquals(oracle(s), isValidBrackets(s), s)
    }
}
case { assertTrue(isValidBrackets("a(b)c")) }
case { assertTrue(isValidBrackets("([]{()})")) }
case { assertFalse(isValidBrackets("((")) }
case { assertFalse(isValidBrackets("))")) }
case { assertFalse(isValidBrackets("(]")) }
case { assertFalse(isValidBrackets("()(")) }
// контрпримеры из причин
case { assertFalse(isValidBrackets("(")) }
case { assertTrue(isValidBrackets("()")) }
case { assertFalse(isValidBrackets("([)]")) }
case { assertFalse(isValidBrackets(")")) }
```

## theory Когда стек
signals:
- Скобки, теги, любая вложенность
- «Последний открытый закрывается первым»
- Сверить пару с самым свежим открытым
body: Стек хранит открытые скобки, которые ждут пару. Закрывающая всегда сверяется с самой свежей открытой — это вершина стека. Каждый символ кладём и снимаем не больше раза: O(n) по времени, O(n) по памяти.

## theory Каркас
skeleton:
```kotlin
// закрывающая -> открывающая
val pairs = mapOf(')' to '(', ']' to '[', '}' to '{')
val stack = ArrayDeque<Char>()
for (char in s) {
    // открывающая: в стек
    if (char in pairs.values) stack.addLast(char)
    // закрывающая: снять и сверить
    else if (char in pairs.keys) {
        if (stack.isEmpty() || stack.removeLast() != pairs[char]) return false
    }
}
// все открытые закрылись
return stack.isEmpty()
```
body: Карта `pairs` хранит «закрывающая → открывающая»: ключи — закрывающие, значения — открывающие, а `pairs[char]` сразу даёт, кого ждём на вершине. `ArrayDeque` как стек: `addLast` кладёт, `removeLast` снимает. Проверка `stack.isEmpty()` стоит первой: на пустом стеке `removeLast()` упадёт.

## theory Грабли
pitfalls:
- Забыть финальное `stack.isEmpty()`: `"("` → `true`, хотя скобка не закрыта
- Снять вершину, не проверив пустоту: `")"` → `NoSuchElementException`
- `removeFirst()` вместо `removeLast()` — это очередь: `"([)]"` → `true`
- `last()` вместо `removeLast()`: вершину посмотрели, но не сняли: `"()"` → `false`
- `&&` вместо `||`: на непустом стеке условие сразу ложно, вершина не снимается

## e1
```kotlin
// Случай 1: "()[]{}" → true
// Случай 2: "([)]" → false
// Случай 3: "(" → false
fun isValidBrackets(s: String): Boolean {
    // открытые, ждущие пары
    val stack = ArrayDeque<Char>()
    // закрывающая -> открывающая
    val pairs = mapOf(')' to '(', ']' to '[', '}' to '{')
    for (char in s) {
        // открывающая: в стек
        if (char in pairs.values) stack.addLast(char)
        // закрывающая: сверяем с вершиной
        else if (char in pairs.keys) {
            if (stack.isEmpty() || stack.removeLast() != pairs[char]) return false
        }
    }
    // все открытые закрылись
    return ⟦stack.isEmpty()⟧
}
```
- `true` [wrong]: незакрытые открывающие так и остались в стеке: `"("` → `true` вместо `false`
- `stack.isNotEmpty()` [wrong]: условие наоборот, правильная строка оставляет стек пустым: `"()"` → `false` вместо `true`
- `false` [wrong]: ответ `false` для любого входа: `"()"` → `false` вместо `true`
- `stack.size` [compile]: функция возвращает `Boolean`, а `stack.size` — `Int`: `return stack.size` не скомпилируется
? Цикл прошёл без ошибок. Но что, если какая-то открывающая так и не закрылась?

## e2
```kotlin
// Случай 1: "()[]{}" → true
// Случай 2: "([)]" → false
// Случай 3: "(" → false
fun isValidBrackets(s: String): Boolean {
    // открытые, ждущие пары
    val stack = ArrayDeque<Char>()
    // закрывающая -> открывающая
    val pairs = mapOf(')' to '(', ']' to '[', '}' to '{')

```

- `char`
- `pairs.values()`

- @1 `pairs.keys` [wrong]: ключи карты — закрывающие: в стек пойдут они, а открывающие пропустим: `"()"` → `false` вместо `true`

- @1 `pairs.values()` [compile]: в Kotlin `values` — свойство, а не функция: `char in pairs.values()` не скомпилируется
- @2 `pairs.values` [compile]: символ не сравнить с коллекцией: `stack.removeLast() != pairs.values` не скомпилируется
- @2 `pairs.keys` [compile]: символ не сравнить с коллекцией: `stack.removeLast() != pairs.keys` не скомпилируется
- @2 `char` [wrong]: на вершине открывающая, а `char` — закрывающая, они никогда не равны: `"()"` → `false` вместо `true`
- @2 `pairs.values()` [compile]: в Kotlin `values` — свойство, а не функция: `stack.removeLast() != pairs.values()` не скомпилируется
