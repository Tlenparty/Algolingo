# l0.2
note: 0.2 Разворот строки на месте
title: Разворот строки
pitfalls:
- `l <= r` работает, но на нечётной длине средний символ меняется сам с собой: лишний шаг
- `r = s.size` вместо `s.size - 1`: первый же `s[r]` вне массива
- `l != r`: на чётной длине указатели проскочат друг друга и выйдут за границы
examples:
- assertEquals("dcba", "abcd".toCharArray().also { reverse(it) }.concatToString())
- assertEquals("cba", "abc".toCharArray().also { reverse(it) }.concatToString())
- assertEquals("a", "a".toCharArray().also { reverse(it) }.concatToString())
- assertEquals("", "".toCharArray().also { reverse(it) }.concatToString())

## theory Когда два указателя навстречу
signals:
- «Развернуть / симметрия»
- «Палиндром»
- Отсортированный массив + «пара / сумма»
body: Указатели стоят по краям и идут навстречу, обрабатывая пару `s[l]`, `s[r]`: время O(n), память O(1).

## theory Каркас
skeleton:
```kotlin
var l = 0
var r = n - 1
while (l < r) {
    // обработать пару s[l], s[r]
    l++; r--
}
```
body: В шпаргалке 04 `<=` назван ошибкой: элемент возьмётся дважды. В развороте это безвредный лишний шаг, поэтому здесь `l <= r` засчитывается с пометкой.

## theory Грабли
pitfalls:
- `r = s.size`: первый же `s[r]` вне массива
- `l != r` на чётной длине: указатели проскочат друг друга, `abcd` → `s[4]`
- Обмен без временной переменной: `s[l] = s[r]; s[r] = s[l]` превратит `ab` в `bb`

## e1
```kotlin
fun reverse(s: CharArray) {
    var l = 0
    var r = s.size - 1
    while (⟦l < r | ~l <= r⟧) {
        val t = s[l]; s[l] = s[r]; s[r] = t
        l++; r--
    }
}
```
- ~`l <= r`: работает, но на нечётной длине средний символ меняется сам с собой: `abc` делает лишний шаг на `b`
- `l > r` [wrong]: цикл не выполнится ни разу: `abcd` останется `abcd`
- `l != r` [crash]: на чётной длине указатели проскочат друг друга: `abcd` → выход за границы на `s[4]`
? `l = 0`, `r = n - 1`, меняем местами, пока `l < r`.
? Именно `<`: при `<=` средний символ поменяется сам с собой (не страшно, но лишний шаг).

## e2
```kotlin
fun reverse(s: CharArray) {
    var l = 0
    var r = ⟦s.size - 1⟧
    while (⟦l < r | ~l <= r⟧) {
        val t = s[l]; s[l] = s[r]; s[r] = t
        l++; r--
    }

```
- ~`l <= r`: работает, но на нечётной длине средний символ меняется сам с собой: `abc` делает лишний шаг на `b`
- `s.size` [crash]: первый же `s[r]` вне массива: `abcd` → `s[4]`
- `l > r` [wrong]: цикл не выполнится ни разу: `abcd` останется `abcd`
- `l != r` [crash]: на чётной длине указатели проскочат друг друга: `abcd` → выход за границы на `s[4]`
- @1 `l > r` [compile]: здесь нужен индекс `Int`, а `l > r` — `Boolean`: не скомпилируется
- @1 `l != r` [compile]: здесь нужен индекс `Int`, а `l != r` — `Boolean`: не скомпилируется
- @2 `s.size` [compile]: `while` ждёт `Boolean`, а `s.size` — `Int`: не скомпилируется
? `r` — индекс последнего символа: `s.size - 1`.
? Меняем местами, пока `l < r`.

## e3
```kotlin
fun reverse(s: CharArray) {
    var l = 0
    var r = s.size - 1
    while (⟦l < r⟧) {
        val t = s[l]; s[l] = s[r]; s[r] = ⟦t⟧
        l⟦++⟧; r⟦--⟧
    }
}
```
- `s[l]` [wrong]: `s[l]` уже перезаписан значением `s[r]`: `ab` превратится в `bb`
- `l > r` [wrong]: цикл не выполнится ни разу: `abcd` останется `abcd`
- @1 `s[l]` [compile]: `while` ждёт `Boolean`, а `s[l]` — `Char`: не скомпилируется
- @3 `s[l]` [compile]: `ls[l]` не скомпилируется: здесь нужен оператор `++`
- @4 `s[l]` [compile]: `rs[l]` не скомпилируется: здесь нужен оператор `--`
- @2 `l > r` [compile]: в `s[r]` нужен `Char`, а `l > r` — `Boolean`: не скомпилируется
- @3 `l > r` [compile]: `ll > r` не скомпилируется: здесь нужен оператор `++`
- @4 `l > r` [compile]: `rl > r` не скомпилируется: здесь нужен оператор `--`
- @3 `--` [wrong]: `l--` уводит левый указатель за начало: `abcd` → `s[-1]`
- @4 `++` [wrong]: `r++` уводит правый указатель за конец: `abcd` → `s[4]`
? Обмен через временную `t`: `s[l]` к этому моменту уже перезаписан.
? Левый указатель идёт вправо (`l++`), правый — влево (`r--`).
