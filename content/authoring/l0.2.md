# l0.2
note: 0.2 Разворот строки на месте
title: Разворот строки
pitfalls:
- `left <= right` работает, но на нечётной длине средний символ меняется сам с собой: лишний шаг
- `right = s.size` вместо `s.size - 1`: первый же `s[right]` вне массива
- `left != right`: на чётной длине указатели проскочат друг друга и выйдут за границы
examples:
- assertEquals("dcba", "abcd".toCharArray().also { reverse(it) }.concatToString())
- assertEquals("cba", "abc".toCharArray().also { reverse(it) }.concatToString())
- assertEquals("a", "a".toCharArray().also { reverse(it) }.concatToString())
- assertEquals("", "".toCharArray().also { reverse(it) }.concatToString())
checks:
```kotlin
// оракул: stdlib reversedArray(); все строки длины 0..6 из {a, b, c}
for (n in 0..6) case {
    for (m in 0 until pw(3, n)) {
        val a = CharArray(n) { 'a' + (m / pw(3, it)) % 3 }
        val exp = a.reversedArray().concatToString()
        reverse(a)
        assertEquals(exp, a.concatToString())
    }
}
// контрпримеры из причин
case { assertEquals("ba", "ab".toCharArray().also { reverse(it) }.concatToString()) }
```

## theory Когда два указателя навстречу
signals:
- «Развернуть / симметрия»
- «Палиндром»
- Отсортированный массив + «пара / сумма»
body: Указатели стоят по краям и идут навстречу, обрабатывая пару `s[left]`, `s[right]`: время O(n), память O(1).

## theory Каркас
skeleton:
```kotlin
// левый указатель — с начала
var left = 0
// правый указатель — с конца
var right = n - 1
// идём навстречу
while (left < right) {
    // обработать s[left], s[right]
    // оба указателя — к центру
    left++; right--
}
```
body: В шпаргалке 04 `<=` назван ошибкой: элемент возьмётся дважды. В развороте это безвредный лишний шаг, поэтому здесь `left <= right` засчитывается с пометкой.

## theory Грабли
pitfalls:
- `right = s.size`: первый же `s[right]` вне массива
- `left != right` на чётной длине: указатели проскочат друг друга, `abcd` → `s[4]`
- Обмен без временной переменной: `s[left] = s[right]; s[right] = s[left]` превратит `ab` в `bb`

## e1
```kotlin
fun reverse(s: CharArray) {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = s.size - 1
    // идём навстречу
    while (⟦left < right | ~left <= right⟧) {
        // обмен через temp
        val temp = s[left]; s[left] = s[right]; s[right] = temp
        // оба указателя — к центру
        left++; right--
    }
}
```
- ~`left <= right`: работает, но на нечётной длине средний символ меняется сам с собой: `abc` делает лишний шаг на `b`
- `left > right` [wrong]: цикл не выполнится ни разу: `abcd` останется `abcd`
- `left != right` [crash]: на чётной длине указатели проскочат друг друга: `abcd` → выход за границы на `s[4]`
? `left = 0`, `right = n - 1`, меняем местами, пока `left < right`.
? Именно `<`: при `<=` средний символ поменяется сам с собой (не страшно, но лишний шаг).

## e3
```kotlin
fun reverse(s: CharArray) {
    // левый указатель — с начала
    var left = 0
    // правый указатель — с конца
    var right = s.size - 1
    // идём навстречу
    while (⟦left < right⟧) {
        // обмен через temp
        val temp = s[left]; s[left] = s[right]; s[right] = ⟦temp⟧
        // оба указателя — к центру
        left⟦++⟧; right⟦--⟧
    }
}
```
- `s[left]` [wrong]: `s[left]` уже перезаписан значением `s[right]`: `ab` превратится в `bb`
- `left > right` [wrong]: цикл не выполнится ни разу: `abcd` останется `abcd`
- @1 `s[left]` [compile]: `while` ждёт `Boolean`, а `s[left]` — `Char`: не скомпилируется
- @3 `s[left]` [compile]: `lefts[left]` не скомпилируется: здесь нужен оператор `++`
- @4 `s[left]` [compile]: `rights[left]` не скомпилируется: здесь нужен оператор `--`
- @2 `left > right` [compile]: в `s[right]` нужен `Char`, а `left > right` — `Boolean`: не скомпилируется
- @3 `left > right` [compile]: `leftleft > right` не скомпилируется: здесь нужен оператор `++`
- @4 `left > right` [compile]: `rightleft > right` не скомпилируется: здесь нужен оператор `--`
- @3 `--` [crash]: `left--` уводит левый указатель за начало: `abcd` → `s[-1]`
- @4 `++` [crash]: `right++` уводит правый указатель за конец: `abcd` → `s[4]`
? Обмен через временную `temp`: `s[left]` к этому моменту уже перезаписан.
? Левый указатель идёт вправо (`left++`), правый — влево (`right--`).
