# l1.3
note: 1.3 Анаграмма / одинаковый набор букв 🔥Avito
title: Анаграмма
examples:
- assertTrue(sameLetters("йцукен", "некуцй"))
- assertFalse(sameLetters("ффффа", "фффа"))
- assertFalse(sameLetters("ab", "ac"))
- assertFalse(sameLetters("aab", "abb"))
- assertTrue(sameLetters("", ""))
checks:
```kotlin
// оракул: сравнение отсортированных списков букв; все пары строк длины 0..3 из {a, b, c}
val words = mutableListOf<String>()
for (n in 0..3) for (m in 0 until pw(3, n)) words += CharArray(n) { 'a' + (m / pw(3, it)) % 3 }.concatToString()
for (a in words) case {
    for (b in words) assertEquals(a.toList().sorted() == b.toList().sorted(), sameLetters(a, b))
}
case { assertFalse(sameLetters("", "a")) }
case { assertFalse(sameLetters("abc", "abcc")) }
// контрпримеры из причин
case { assertTrue(sameLetters("ab", "ba")) }
case { assertTrue(sameLetters("a", "a")) }

case { assertFalse(sameLetters("ab", "a")) }
case { assertFalse(sameLetters("ab", "aa")) }
```

## theory Когда сравнивать частоты
signals:
- «Одинаковый набор букв», «перестановка», «анаграмма»
- «С учётом количества» — важно, сколько раз, а не только есть ли
- Нужно уложиться в O(n)
body: Одна `HashMap<Char, Int>`: плюсуем буквы `a`, минусуем буквы `b`. O(n) по времени, O(k) по памяти.

## theory Каркас
skeleton:
```kotlin
// быстрая проверка длин
if (a.length != b.length) return false
// считаем буквы первого слова
for (char in a) counts[char] = counts.getOrDefault(char, 0) + 1
// вычитаем буквы второго слова
for (char in b) {
    // остаток этой буквы
    val remaining = (counts[char] ?: 0) - 1
    // в b лишняя буква
    if (remaining < 0) return false
    counts[char] = remaining
}
// длины равны, минуса не было
return true
```
body: Длины равны и счётчик ни разу не ушёл в минус ⇒ частоты совпали. Однострочник `a.groupingBy { it }.eachCount() == b.groupingBy { it }.eachCount()` тоже верен, но на собесе пиши цикл.

## theory Грабли
pitfalls:
- «Отсортировать обе строки и сравнить» — O(n log n), а `Map` даёт O(n)
- Без проверки длины `"ab"` и `"a"` пройдут: лишние буквы `a` никто не заметит
- Буква, которой нет в `a`, должна дать `-1`: старт `(counts[char] ?: 0)`, а не `1`

## e1
```kotlin
fun sameLetters(a: String, b: String): Boolean {
    // быстрая проверка длин
    if (a.length != b.length) return false
    // буква -> сколько раз
    val counts = HashMap<Char, Int>()
    // считаем буквы первого слова
    for (char in a) counts[char] = counts.getOrDefault(char, 0) + 1
    // вычитаем буквы второго слова
    for (char in b) {
        // остаток этой буквы
        val remaining = (counts[char] ?: 0) - 1
        // в b лишняя буква
        if (remaining ⟦<⟧ 0) return false
        counts[char] = remaining
    }
    // длины равны, минуса не было
    return true
}
```
- `<=` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `false` вместо `true`
- `==` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `false` вместо `true`
- `>` [wrong]: перевёрнуто, минус никогда не ловится: `"ab"` / `"ac"` → `true` вместо `false`
? Буква лишняя, если счётчик ушёл в минус.

## e3
```kotlin
fun sameLetters(a: String, b: String): Boolean {
    // быстрая проверка длин
    if (a.length ⟦!=⟧ b.length) return false
    // буква -> сколько раз
    val counts = HashMap<Char, Int>()
    // считаем буквы первого слова
    for (char in a) counts[char] = counts.getOrDefault(char, 0) + 1
    // вычитаем буквы второго слова
    for (char in b) {
        // остаток этой буквы
        val remaining = (counts[char] ?: ⟦0⟧) - 1
        // в b лишняя буква
        if (remaining ⟦<⟧ 0) return false
        counts[char] = ⟦remaining⟧
    }
    // длины равны, минуса не было
    return true
}
```
- `==` [wrong]: равные длины сразу дают «не анаграмма»: `"ab"` / `"ba"` → `false` вместо `true`
- `1` [wrong]: буква, которой нет в `a`, даст `0`, а не минус: `"ab"` / `"ac"` → `true` вместо `false`
- `<=` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `false` вместо `true`
- `remaining + 1` [wrong]: в `counts` возвращается старое значение, уменьшение теряется: `"ab"` / `"aa"` → `true` вместо `false`
- @1 `0` [compile]: между длинами нужен оператор сравнения: `a.length 0 b.length` не скомпилируется
- @1 `<` [wrong]: длинная `a` проскочит, её лишние буквы никто не проверит: `"ab"` / `"a"` → `true` вместо `false`
- @1 `remaining` [compile]: `remaining` ещё не объявлен и это не оператор: `a.length remaining b.length` не скомпилируется
- @1 `<=` [wrong]: равные длины сразу дают «не анаграмма»: `"a"` / `"a"` → `false` вместо `true`
- @1 `1` [compile]: между длинами нужен оператор сравнения: `a.length 1 b.length` не скомпилируется
- @1 `remaining + 1` [compile]: `remaining` ещё не объявлен и это не оператор: `a.length remaining + 1 b.length` не скомпилируется
- @2 `!=` [compile]: после `?:` нужно значение, а не оператор: `(counts[char] ?: !=) - 1` не скомпилируется
- @2 `<` [compile]: после `?:` нужно значение, а не оператор: `(counts[char] ?: <) - 1` не скомпилируется
- @2 `remaining` [compile]: внутри своего же объявления `remaining` ещё не существует: `val remaining = (counts[char] ?: remaining) - 1` не скомпилируется
- @2 `==` [compile]: после `?:` нужно значение, а не оператор: `(counts[char] ?: ==) - 1` не скомпилируется
- @2 `<=` [compile]: после `?:` нужно значение, а не оператор: `(counts[char] ?: <=) - 1` не скомпилируется
- @2 `remaining + 1` [compile]: внутри своего же объявления `remaining` ещё не существует: `val remaining = (counts[char] ?: remaining + 1) - 1` не скомпилируется
- @3 `!=` [wrong]: любой остаток кроме `0` — уже «лишняя»: `"aa"` / `"aa"` → `false` вместо `true`
- @3 `0` [compile]: между `remaining` и `0` нужен оператор: `if (remaining 0 0)` не скомпилируется
- @3 `remaining` [compile]: между `remaining` и `0` нужен оператор: `if (remaining remaining 0)` не скомпилируется
- @3 `==` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `false` вместо `true`
- @3 `1` [compile]: между `remaining` и `0` нужен оператор: `if (remaining 1 0)` не скомпилируется

- @4 `0` [wrong]: счётчик обнуляется после первой же буквы: `"aa"` / `"aa"` → `false` вместо `true`
- @4 `<` [compile]: справа от `=` нужно значение, а не оператор: `counts[char] = <` не скомпилируется
- @4 `==` [compile]: справа от `=` нужно значение, а не оператор: `counts[char] = ==` не скомпилируется

- @4 `<=` [compile]: справа от `=` нужно значение, а не оператор: `counts[char] = <=` не скомпилируется
