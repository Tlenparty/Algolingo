# l0.1
note: 0.1 Сумма и максимум массива
title: Сумма и максимум
examples:
- assertEquals(6 to 3, sumAndMax(intArrayOf(1, 2, 3)))
- assertEquals(-7 to -2, sumAndMax(intArrayOf(-5, -2)))
- assertEquals(7 to 7, sumAndMax(intArrayOf(7)))

## theory Когда один проход
signals:
- «Пройти и накопить»: сумма, счётчик
- «Найти max/min» без сортировки
body: Один `for` и одна переменная-аккумулятор: время O(n), память O(1). Никакой структуры данных не нужно.

## theory Каркас
skeleton:
```kotlin
var acc = start
for (x in nums) {
    // обновить acc по x
}
```
body: Старт для суммы — `0`, для максимума — первый элемент `nums[0]`.

## theory Грабли
pitfalls:
- `max = 0` ломается на `[-5, -2]`: вернёт `0`, а такого элемента нет
- Пустой массив: уточни у интервьюера, что делать (исключение или `null`)

## e1
```kotlin
fun sumAndMax(nums: IntArray): Pair<Int, Int> {
    var sum = 0
    var max = ⟦nums[0] | ~Int.MIN_VALUE⟧
    for (x in nums) {
        sum += x
        if (x > max) max = x
    }
    return sum to max
}
```
- ~`Int.MIN_VALUE`: работает, но на пустом массиве молча вернёт max `Int.MIN_VALUE` вместо ошибки; `nums[0]` честнее
- `0` [wrong]: на отрицательных числах `x > max` не сработает: `[-5, -2]` вернёт max `0`, а такого элемента нет
- `Int.MAX_VALUE` [wrong]: `x > max` никогда не сработает: `[1, 2]` вернёт max `2147483647`
- `nums[1]` [crash]: на массиве из одного элемента выход за границы: `[7]` упадёт на `nums[1]`
? Максимум инициализируй **первым элементом**, не нулём: числа могут быть отрицательными.

## e3
```kotlin
fun sumAndMax(nums: IntArray): Pair<Int, Int> {
    var sum = ⟦0⟧
    var max = ⟦nums[0] | ~Int.MIN_VALUE⟧
    for (x in nums) {
        sum ⟦+=⟧ x
        if (x ⟦>⟧ max) max = x
    }
    return sum to max
}
```
- ~`Int.MIN_VALUE`: работает, но на пустом массиве молча вернёт max `Int.MIN_VALUE` вместо ошибки; `nums[0]` честнее
- `=` [wrong]: `sum = x` перезаписывает, а не копит: `[1, 2]` даст sum `2`
- `<` [wrong]: `x < max` ищет минимум: `[3, 1]` вернёт max `1`
- @1 `nums[0]` [wrong]: цикл ещё раз прибавит первый элемент: `[1, 2, 3]` даст sum `7`
- @1 `Int.MIN_VALUE` [wrong]: сумма начнётся не с нуля: `[1, 2, 3]` даст sum `-2147483642`
- @2 `0` [wrong]: на отрицательных числах `x > max` не сработает: `[-5, -2]` вернёт max `0`, а такого элемента нет
- @1 `=` [compile]: `var sum = =` не скомпилируется: здесь нужно начальное значение
- @2 `=` [compile]: `var max = =` не скомпилируется: здесь нужно начальное значение
- @4 `=` [compile]: `if (x = max)` не скомпилируется: присваивание в Kotlin не выражение, а `if` ждёт `Boolean`
- @1 `<` [compile]: `var sum = <` не скомпилируется: здесь нужно начальное значение
- @2 `<` [compile]: `var max = <` не скомпилируется: здесь нужно начальное значение
- @3 `<` [wrong]: `sum < x` только сравнивает и ничего не копит: `[1, 2]` даст sum `0`
? Одна переменная-аккумулятор, один `for`: `sum += x` копит сумму.
? Максимум обновляем, когда встретили больший элемент: `x > max`.
