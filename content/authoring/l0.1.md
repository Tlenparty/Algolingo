# l0.1
note: 0.1 Сумма и максимум массива
title: Сумма и максимум
examples:
- assertEquals(6 to 3, sumAndMax(intArrayOf(1, 2, 3)))
- assertEquals(-7 to -2, sumAndMax(intArrayOf(-5, -2)))
- assertEquals(7 to 7, sumAndMax(intArrayOf(7)))
checks:
```kotlin
// оракул: stdlib sum()/max(), а не ручной проход; все массивы длины 1..5 из {-3, -1, 0, 2}
val vals = intArrayOf(-3, -1, 0, 2)
for (n in 1..5) case {
    for (m in 0 until pw(4, n)) {
        val a = IntArray(n) { vals[(m / pw(4, it)) % 4] }
        assertEquals(a.sum() to a.max(), sumAndMax(a))
    }
}
case { assertEquals(0 to 0, sumAndMax(intArrayOf(0))) }
case { assertEquals(Int.MAX_VALUE to Int.MAX_VALUE, sumAndMax(intArrayOf(Int.MAX_VALUE))) }
case { assertEquals(Int.MIN_VALUE to Int.MIN_VALUE, sumAndMax(intArrayOf(Int.MIN_VALUE))) }
case { assertEquals(-1 to Int.MAX_VALUE, sumAndMax(intArrayOf(Int.MIN_VALUE, Int.MAX_VALUE))) }
case { assertEquals(9 to 5, sumAndMax(intArrayOf(5, 1, 3))) } // максимум первым
case { assertEquals(9 to 5, sumAndMax(intArrayOf(1, 3, 5))) } // максимум последним
// контрпримеры из причин
case { assertEquals(3 to 2, sumAndMax(intArrayOf(1, 2))) }
case { assertEquals(4 to 3, sumAndMax(intArrayOf(3, 1))) }
case { assertEquals(1 to 1, sumAndMax(intArrayOf(1))) }
```

## theory Когда один проход
signals:
- «Пройти и накопить»: сумма, счётчик
- «Найти max/min» без сортировки
body: Один `for` и одна переменная-аккумулятор: время O(n), память O(1). Никакой структуры данных не нужно.

## theory Каркас
skeleton:
```kotlin
// аккумулятор: сумма, максимум…
var acc = start
// один проход по массиву
for (num in nums) {
    // обновить acc по num
}
```
body: Старт для суммы — `0`, для максимума — первый элемент `nums[0]`.

## theory Грабли
pitfalls:
- `max = 0` ломается на `[-5, -2]`: вернёт `0`, а такого элемента нет
- Пустой массив: уточни у интервьюера, что делать (исключение или `null`)

## e1
```kotlin
fun sumAndMax(nums: IntArray): Pair<Int, Int> {
    // сумма всех чисел
    var sum = 0
    // текущий максимум
    var max = ⟦nums[0] | ~Int.MIN_VALUE⟧
    // один проход по массиву
    for (num in nums) {
        sum += num
        // новый максимум
        if (num > max) max = num
    }
    // пара (сумма, максимум)
    return sum to max
}
```
- ~`Int.MIN_VALUE`: работает, но на пустом массиве молча вернёт max `Int.MIN_VALUE` вместо ошибки; `nums[0]` честнее
- `0` [wrong]: на отрицательных числах `num > max` не сработает: `[-5, -2]` вернёт max `0`, а такого элемента нет
- `Int.MAX_VALUE` [wrong]: `num > max` никогда не сработает: `[1, 2]` вернёт max `2147483647`
- `nums[1]` [crash]: на массиве из одного элемента выход за границы: `[7]` упадёт на `nums[1]`
? Максимум инициализируй **первым элементом**, не нулём: числа могут быть отрицательными.

## e3
```kotlin
fun sumAndMax(nums: IntArray): Pair<Int, Int> {
    // сумма всех чисел
    var sum = ⟦0⟧
    // текущий максимум
    var max = ⟦nums[0] | ~Int.MIN_VALUE⟧
    // один проход по массиву
    for (num in nums) {
        sum ⟦+=⟧ num
        // новый максимум
        if (num ⟦>⟧ max) max = num
    }
    // пара (сумма, максимум)
    return sum to max
}
```
- ~`Int.MIN_VALUE`: работает, но на пустом массиве молча вернёт max `Int.MIN_VALUE` вместо ошибки; `nums[0]` честнее
- `=` [wrong]: `sum = num` перезаписывает, а не копит: `[1, 2]` даст sum `2`
- `<` [wrong]: `num < max` ищет минимум: `[3, 1]` вернёт max `1`
- @1 `nums[0]` [wrong]: цикл ещё раз прибавит первый элемент: `[1, 2, 3]` даст sum `7`
- @1 `Int.MIN_VALUE` [wrong]: сумма начнётся не с нуля: `[1, 2, 3]` даст sum `-2147483642`
- @2 `0` [wrong]: на отрицательных числах `num > max` не сработает: `[-5, -2]` вернёт max `0`, а такого элемента нет
- @1 `=` [compile]: `var sum = =` не скомпилируется: здесь нужно начальное значение
- @2 `=` [compile]: `var max = =` не скомпилируется: здесь нужно начальное значение
- @4 `=` [compile]: `if (num = max)` не скомпилируется: присваивание в Kotlin не выражение, а `if` ждёт `Boolean`
- @1 `<` [compile]: `var sum = <` не скомпилируется: здесь нужно начальное значение
- @2 `<` [compile]: `var max = <` не скомпилируется: здесь нужно начальное значение
- @3 `<` [wrong]: `sum < num` только сравнивает и ничего не копит: `[1, 2]` даст sum `0`
? Одна переменная-аккумулятор, один `for`: `sum += num` копит сумму.
? Максимум обновляем, когда встретили больший элемент: `num > max`.
