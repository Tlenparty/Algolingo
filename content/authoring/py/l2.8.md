# l2.8
note: 2.8 Самая длинная подстрока без повторов
lang: python
title: Подстрока без повторов
statement: Верни длину самой длинной подстроки без повторяющихся символов (LeetCode 3).
trains: скользящее окно переменной длины + словарь последних позиций
pitfalls:
- Без `last_index[ch] >= left` старая позиция за окном тянет `left` назад: `"abba"` → `3` вместо `2`
- `last_index[ch]` без проверки `ch in last_index` падает с `KeyError` на новом символе
- `left = last_index[ch]` без `+ 1`: повтор остаётся в окне
- Длина окна `left..right` — `right - left + 1`, обе границы входят
variations:
- `last_index.get(ch, -1) >= left` — то же условие без отдельной проверки `in`
- множество `seen` + `while s[right] in seen`: убираем символы слева по одному — тоже O(n), но левая граница шагает, а не прыгает
- в лоб: перебор всех подстрок и `len(set(sub)) == len(sub)` — O(n³)
examples:
- assert longest_unique("abcabcbb") == 3
- assert longest_unique("bbbbb") == 1
- assert longest_unique("pwwkew") == 3
- assert longest_unique("") == 0
checks:
```python
# оракул: перебор всех подстрок, длиннейшая без повторов (set); все строки длины 0..6 из {a, b, c, d}
for n in range(7):
    with case():
        for m in range(pw(4, n)):
            s = "".join("abcd"[(m // pw(4, k)) % 4] for k in range(n))
            exp = max((j - i for i in range(n + 1) for j in range(i, n + 1) if len(set(s[i:j])) == j - i), default=0)
            got = longest_unique(s)
            assert got == exp and type(got) is int, (s, got)
with case():
    assert longest_unique(" ") == 1
with case():
    assert longest_unique("dvdf") == 3
with case():
    assert longest_unique("tmmzuxt") == 5
with case():
    assert longest_unique("шалаш") == 3
with case():
    assert longest_unique("abcdefghijklmnopqrstuvwxyz") == 26
# контрпримеры из причин
with case():
    assert longest_unique("aa") == 1
with case():
    assert longest_unique("abba") == 2
with case():
    assert longest_unique("abab") == 2
with case():
    assert longest_unique("a") == 1
with case():
    assert longest_unique("abc") == 3
```

## theory Когда окно переменной длины
signals:
- Подряд идущий отрезок: подстрока или подсписок
- «Самый длинный такой, что…» — условие на всё окно
- Нарушение чинится сдвигом левой границы
body: Правая граница `right` идёт по строке и расширяет окно. Если новый символ уже есть внутри окна, левая граница `left` прыгает сразу за его прошлую позицию. Обе границы двигаются только вперёд, поэтому O(n).

## theory Каркас
skeleton:
```python
# символ -> последний индекс
last_index = {}
left = 0
for right, ch in enumerate(s):
    # повтор внутри окна: ужимаем
    if (ch in last_index
            and last_index[ch] >= left):
        left = last_index[ch] + 1
    last_index[ch] = right
    # окно left..right без повторов
```
body: `enumerate(s)` даёт пары «индекс, символ». Длина окна `left..right` — это `right - left + 1`: обе границы входят в окно.

## theory Грабли
pitfalls:
- Без `last_index[ch] >= left` старая позиция за окном тянет `left` назад: `"abba"` → `3` вместо `2`
- `left = last_index[ch]`: повтор остаётся в окне: `"aa"` → `2` вместо `1`
- Длина `right - left` без `+ 1`: `"a"` → `0` вместо `1`
- `for right, ch in s`: строка даёт символы, а не пары: `"abc"` → `ValueError`

## e1
```python
# Случай 1: "abcabcbb" → 3 ("abc")
# Случай 2: "bbbbb" → 1 ("b")
# Случай 3: "pwwkew" → 3 ("wke")
def longest_unique(s: str) -> int:
    # символ -> последний индекс
    last_index = {}
    # левая граница окна
    left = 0
    # лучшая длина пока что
    best = 0
    # правая граница идёт по строке
    for right, ch in enumerate(s):
        # повтор внутри окна: ужимаем
        if ch in last_index and ⟦last_index[ch] >= left⟧:
            left = last_index[ch] + 1
        last_index[ch] = right
        # длина окна left..right
        best = max(best, right - left + 1)
    return best
```
- `True` [wrong]: старая позиция символа за окном тянет `left` назад: `"abba"` → `3` вместо `2`: на втором `a` окно снова захватывает `bba`
- `last_index[ch] > left` [wrong]: повтор на самой левой границе окна не ловится: `"aa"` → `2` вместо `1`
? Символ мог встречаться раньше, но уже **за** левой границей. Тогда окно трогать не надо.

## e3
```python
# Случай 1: "abcabcbb" → 3 ("abc")
# Случай 2: "bbbbb" → 1 ("b")
# Случай 3: "pwwkew" → 3 ("wke")
def longest_unique(s: str) -> int:
    # символ -> последний индекс
    last_index = {}
    # левая граница окна
    left = 0
    # лучшая длина пока что
    best = 0
    # правая граница идёт по строке
    for right, ch in ⟦enumerate(s)⟧:
        # повтор внутри окна: ужимаем
        if ch in last_index and ⟦last_index[ch] >= left⟧:
            left = last_index[ch] + 1
        last_index[ch] = ⟦right⟧
        # длина окна left..right
        best = max(best, right - left + 1)
    return best
```

- `range(len(s))` [crash]: `range` даёт числа, их не разложить на два имени: `"abc"` → `TypeError: cannot unpack non-iterable int object`
- `last_index[ch] > left` [wrong]: повтор на самой левой границе окна не ловится: `"aa"` → `2` вместо `1`
- `left` [wrong]: запоминаем не позицию символа, а границу окна: `"abab"` → `3` вместо `2`
