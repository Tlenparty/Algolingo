# l1.4
note: 1.4 Two Sum (массив НЕ отсортирован)
lang: python
title: Two Sum
statement: Верни индексы двух чисел с суммой `target` или `None`, если такой пары нет.
trains: словарь «значение → индекс», поиск дополнения `target - x`
pitfalls:
- сначала проверь `target - x in seen`, потом клади `seen[x] = i` — иначе на `target = 2*x` вернёшь один индекс дважды
- `{}` — пустой словарь, а `set()` — множество: индекс по числу хранит только словарь
variations:
- нужны сами числа, а не индексы: хватит `set()` и `return (target - x, x)`
- массив отсортирован: два указателя, O(1) памяти (уровень 2)
- нужны все пары: не `return`, а копить ответы в список
examples:
- assert two_sum([2, 7, 11, 15], 9) == (0, 1)
- assert two_sum([3, 2, 4], 6) == (1, 2)
- assert two_sum([3, 3], 6) == (0, 1)
- assert two_sum([1, 2], 7) is None
checks:
```python
# оракул: перебор всех пар i < j; все массивы длины 0..4 из {-1, 0, 1, 2}, target -2..4
for n in range(5):
    with case():
        for m in range(pw(4, n)):
            a = [(m // pw(4, k)) % 4 - 1 for k in range(n)]
            for t in range(-2, 5):
                exists = any(a[i] + a[j] == t for i in range(n) for j in range(i + 1, n))
                r = two_sum(a, t)
                if exists:
                    assert type(r) is tuple and len(r) == 2 and r[0] < r[1] and a[r[0]] + a[r[1]] == t, (a, t, r)
                else:
                    assert r is None, (a, t, r)
with case():
    assert two_sum([], 0) is None
with case():
    assert two_sum([3], 6) is None  # target = 2·x, но индекс один
with case():
    assert two_sum([-3, 4, 1], -2) == (0, 2)
with case():
    assert two_sum([0, 4, 0], 0) == (0, 2)
with case():
    assert two_sum([5, 5, 5], 10) == (0, 1)
# контрпримеры из причин
with case():
    assert two_sum([2, 7], 9) == (0, 1)
```

## theory Когда словарь значение → индекс
signals:
- «Найди пару с суммой `target`»
- Массив не отсортирован
- Вернуть нужно индексы, а не сами числа
body: Для каждого `x` ищем дополнение `target - x` среди уже пройденных: словарь `seen` «значение → индекс» отвечает на `in` за O(1). Если массив отсортирован — это два указателя (уровень 2).

## theory Каркас
skeleton:
```python
seen = {}
for i, x in enumerate(nums):
    if target - x in seen:
        return (seen[target - x], i)
    seen[x] = i
return None
```
body: Один проход: `enumerate` даёт и индекс, и число. Сначала ищем дополнение, потом кладём текущее. O(n) по времени и памяти.

## theory Грабли
pitfalls:
- Сначала `seen[x] = i`, потом проверка: `[3, 2, 4]`, `6` → `3` найдёт сам себя, ответ `(0, 0)` вместо `(1, 2)`
- `seen = set()` вместо `{}`: множество не хранит индекс, `seen[x] = i` падает с `TypeError`. `{}` — это пустой словарь, а не множество
- `nums.index(target - x)` вместо `seen[target - x]`: ответ верный, но `index` ищет линейно — снова O(n²)
- `for i, x in nums` без `enumerate`: число `2` не распаковать в `i, x` — `TypeError`
- Вернуть `-1` или `[]` вместо `None`: вызывающий код проверяет `is None`

## e1
```python
def two_sum(nums: list[int], target: int) -> tuple[int, int] | None:
    seen = {}
    for i, x in enumerate(nums):
        if target ⟦-⟧ x ⟦in⟧ seen:
            return (seen[target - x], i)
        seen[x] = i
    return None
```
- `+` [wrong]: дополнение — это разность, а не сумма: `[2, 7]`, `9` → ищем `11` и `16`, ответ `None` вместо `(0, 1)`
- `not in` [crash]: условие перевёрнуто, и читаем ключ, которого нет: `[2, 7]`, `9` → `7` нет в `seen`, `seen[7]` падает с `KeyError`
- @1 `in` [crash]: `target in x` ищет внутри числа: `[2, 7]`, `9` → `TypeError: argument of type 'int' is not iterable`
- @1 `not in` [crash]: `target not in x` ищет внутри числа: `[2, 7]`, `9` → `TypeError: argument of type 'int' is not iterable`
- @2 `-` [crash]: `target - x - seen` вычитает словарь из числа: `[2, 7]`, `9` → `TypeError: unsupported operand type(s)`
- @2 `+` [crash]: `target - x + seen` складывает число и словарь: `[2, 7]`, `9` → `TypeError: unsupported operand type(s)`
? Для текущего `x` нужно `target - x`.
? Если оно уже в `seen` — ответ найден.

## e2
```python
def two_sum(nums: list[int], target: int) -> tuple[int, int] | None:
    seen = {}
    for i, x in ⟦enumerate(nums)⟧:
        if target - x ⟦in⟧ seen:
            return (seen[target - x], i)
        seen[⟦x⟧] = i
    return None
```
- `nums` [crash]: по списку идут только числа, индекса нет: `[2, 7]` → `2` не распаковать в `i, x`, `TypeError`
- `not in` [crash]: условие перевёрнуто, и читаем ключ, которого нет: `[2, 7]`, `9` → `7` нет в `seen`, `seen[7]` падает с `KeyError`
- `target - x` [wrong]: кладём дополнение, а не само число — потом найдётся только равное число: `[2, 7]`, `9` → `seen` = `{7: 0}`, на `7` ищем `2` — нет, `None` вместо `(0, 1)`
- @1 `in` [compile]: после `in` нужен список, а не оператор: `for i, x in in:` — `SyntaxError`, код не запустится
- @1 `not in` [compile]: после `in` нужен список, а не оператор: `for i, x in not in:` — `SyntaxError`, код не запустится
- @1 `x` [crash]: `x` появится только внутри цикла: `for i, x in x:` → `UnboundLocalError` ещё до первого шага
- @1 `target - x` [crash]: `x` появится только внутри цикла: `for i, x in target - x:` → `UnboundLocalError` ещё до первого шага
- @2 `enumerate(nums)` [compile]: между `target - x` и `seen` нужен оператор: `target - x enumerate(nums) seen` — `SyntaxError`
- @2 `x` [compile]: между `target - x` и `seen` нужен оператор: `target - x x seen` — `SyntaxError`
- @2 `nums` [compile]: между `target - x` и `seen` нужен оператор: `target - x nums seen` — `SyntaxError`
- @2 `target - x` [compile]: между `target - x` и `seen` нужен оператор: `target - x target - x seen` — `SyntaxError`
- @3 `enumerate(nums)` [wrong]: ключом станет сам объект `enumerate`, числа не запоминаются: `[2, 7]`, `9` → `None` вместо `(0, 1)`
- @3 `in` [compile]: в скобках нужен ключ, а не оператор: `seen[in] = i` — `SyntaxError`
- @3 `not in` [compile]: в скобках нужен ключ, а не оператор: `seen[not in] = i` — `SyntaxError`
- @3 `nums` [crash]: список нельзя сделать ключом словаря: `[2, 7]`, `9` → `seen[nums] = i` падает с `TypeError: unhashable type: 'list'`
? `enumerate(nums)` даёт пары `(i, x)`: и индекс, и число.
? Для текущего `x` нужно `target - x`. Если оно уже в `seen` — ответ.
? Иначе кладём `x → i`: словарь хранит «значение → индекс».

## e3

def two_sum(nums: list[int], target: int) -> tuple[int, int] | None:
    seen = ⟦{}⟧
    for i, x in ⟦enumerate(nums)⟧:
