note: 1.5 Победители соревнования 🔥Avito
lang: python
title: Победители соревнования
statement: Дана статистика шагов по дням: список дней, день — список пар `(user_id, steps)`. Верни пару `(user_ids, steps)`: всех, кто набрал **максимум шагов**, **участвуя во все дни без пропусков**, и сам этот максимум. Порядок `user_ids` любой.
trains: два словаря одновременно (сумма + счётчик дней) + фильтр
pitfalls:
- Победителей может быть несколько (равный максимум) → возвращаем список, а не одного
- Максимум ищем только среди тех, кто был все дни: юзер с пропуском задаст недостижимую планку, и победителей не останется
- `max()` на пустой последовательности падает с `ValueError` — нужен `default=0`
- `total_steps[user] += steps` для нового юзера падает с `KeyError`: нужен `total_steps.get(user, 0) + steps`
- Ответ — кортеж `(champions, max_steps)`: список `[champions, max_steps]` с кортежем не равен
variations:
- в проде: `collections.Counter` для сумм; но `most_common(1)` вернёт одного, а победителей может быть несколько — на собесе покажи два словаря
- вместо счётчика дней: множество юзеров каждого дня и их пересечение `set.intersection(*({u for u, _ in day} for day in statistics))` — устойчиво, если юзер встречается в дне дважды
- нужен порядок по `user_id`: `sorted(champions)` перед возвратом, это ещё O(k log k)
examples:
- assert find_champions([[(1, 100), (2, 50)], [(1, 100), (2, 50)]]) == ([1], 200)
- assert find_champions([[(1, 100), (2, 500)], [(1, 100)]]) == ([1], 200)
- r = find_champions([[(1, 100), (2, 100)], [(2, 50), (1, 50)]]); assert sorted(r[0]) == [1, 2] and r[1] == 150
- assert find_champions([]) == ([], 0)
checks:
```python
# оракул: перебор юзеров, «был во все дни» = есть запись в каждом дне (не счётчик);
# все наборы из 0..3 дней, в дне юзер 1 и юзер 2 либо отсутствуют, либо с шагами 0 или 100
def oracle(st):
    users = sorted(set(u for day in st for u, _ in day))
    full = [u for u in users if all(any(v == u for v, _ in day) for day in st)]
    total = {u: sum(s for day in st for v, s in day if v == u) for u in full}
    best = max(total.values(), default=0)
    return ([u for u in full if total[u] == best], best)
opts = [-1, 0, 100]  # -1 = юзера в этот день нет
for d in range(4):
    with case():
        for m in range(pw(9, d)):
            st = []
            for k in range(d):
                code = (m // pw(9, k)) % 9
                st.append([(u, s) for u, s in ((1, opts[code % 3]), (2, opts[code // 3])) if s >= 0])
            r = find_champions(st)
            assert type(r) is tuple and len(r) == 2 and type(r[0]) is list, (st, r)
            assert (sorted(r[0]), r[1]) == oracle(st), (st, r)
with case():
    assert find_champions([[(1, 0)]]) == ([1], 0)
with case():
    assert find_champions([[]]) == ([], 0)  # день без записей
with case():
    assert find_champions([[(1, 100)], [(2, 100)]]) == ([], 0)  # никто не был все дни
# контрпримеры из причин
with case():
    assert find_champions([[(1, 100), (2, 50)]]) == ([1], 100)
with case():
    assert find_champions([[(1, 100)]]) == ([1], 100)
with case():
    assert find_champions([[(1, 100)], [(1, 100)]]) == ([1], 200)
with case():
    assert find_champions([[(2, 100)]]) == ([2], 100)
with case():
    r = find_champions([[(1, 100), (2, 100)]])
    assert sorted(r[0]) == [1, 2] and r[1] == 100
```

## theory Когда два словаря
signals:
- По каждому юзеру нужны и сумма, и счётчик
- «Во все дни», «без пропусков» — счётчик дней равен числу дней
- «Максимум среди тех, кто…» — сначала фильтр, потом максимум
body: Два `dict` за один двойной проход: `total_steps` копит шаги, `days_active` — дни участия. O(N) по числу записей, O(U) по числу юзеров.

## theory Каркас
skeleton:
```python
for day in statistics:
    for user, steps in day:
        total_steps[user] = total_steps.get(user, 0) + steps
        days_active[user] = days_active.get(user, 0) + 1
full = [u for u in days_active if days_active[u] == total_days]
max_steps = max((total_steps[u] for u in full), default=0)
champions = [u for u in full if total_steps[u] == max_steps]
```
body: Фильтр → максимум → сбор всех с этим максимумом. Сначала отфильтруй тех, кто был все дни, и только среди них ищи максимум. `default=0` нужен, когда таких нет: пустой `max()` падает с `ValueError`. Порядок `user_ids` в ответе условие не задаёт; в Python он совпадёт с порядком первого появления юзера, потому что `dict` помнит порядок вставки.

## theory Грабли
pitfalls:
- `total_steps[user] += steps` без начального значения: нового юзера в словаре ещё нет, `[[(1, 100)]]` → `KeyError: 1`
- `max(...)` без `default=0`: никто не был все дни, `[[(1, 100)], [(2, 100)]]` → `ValueError: max() arg is an empty sequence`
- Максимум по всем юзерам, а не по `full`: `[[(1, 100), (2, 500)], [(1, 100)]]` → `([], 500)` вместо `([1], 200)`
- Удалять «неполных» из `days_active` прямо в цикле по нему: `[[(1, 100), (2, 500)], [(1, 100)]]` → `RuntimeError: dictionary changed size during iteration`; фильтр — это новый список
- Вернуть одного победителя вместо списка: при равном максимуме `[[(1, 100), (2, 100)]]` второй потеряется

## e1
```python
def find_champions(statistics: list[list[tuple[int, int]]]) -> tuple[list[int], int]:
    total_days = len(statistics)
    total_steps = {}
    days_active = {}
    for day in statistics:
        for user, steps in day:
            total_steps[user] = total_steps.get(user, 0) + steps
            days_active[user] = days_active.get(user, 0) + 1
    full = [u for u in days_active if days_active[u] == total_days]
    max_steps = max((total_steps[u] for u in ⟦full⟧), default=0)
    champions = [u for u in full if total_steps[u] == max_steps]
    return (champions, max_steps)
```
- `total_steps` [wrong]: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `([], 500)` вместо `([1], 200)`
- `days_active` [wrong]: те же ключи, что у `total_steps`, — максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `([], 500)` вместо `([1], 200)`
- `total_steps.values()` [crash]: перебираем суммы шагов, а не юзеров: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `total_steps[200]` падает с `KeyError: 200`
? «Без пропусков» = число дней участия равно `len(statistics)`. Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).

- @2 `total_steps` [wrong]: вернём словарь сумм, а не список победителей: день `[(1, 100)]` → `({1: 100}, 100)` вместо `([1], 100)`

## e3
```python
def find_champions(statistics: list[list[tuple[int, int]]]) -> tuple[list[int], int]:
    total_days = len(statistics)
    total_steps = {}
    days_active = {}
    for day in statistics:
        for user, steps in day:
            total_steps[user] = total_steps.get(user, 0) + ⟦steps⟧
            days_active[user] = days_active.get(user, 0) + ⟦1⟧
    full = [u for u in days_active if days_active[u] == ⟦total_days⟧]
    max_steps = max((total_steps[u] for u in ⟦full⟧), default=0)
    champions = [u for u in full if total_steps[u] == max_steps]
    return (champions, max_steps)
```
- `total_steps` [wrong]: максимум по всем, а юзер с пропуском задаёт недостижимую планку: дни `[(1, 100), (2, 500)]`, `[(1, 100)]` → `([], 500)` вместо `([1], 200)`
- `len(days_active)` [wrong]: это число юзеров, а не дней: день `[(1, 100), (2, 50)]` → дней `1`, юзеров `2`, ответ `([], 0)` вместо `([1], 100)`
- `user` [wrong]: к шагам прибавляется номер юзера: день `[(1, 100), (2, 50)]` → `([2], 2)` вместо `([1], 100)`
- @1 `1` [wrong]: `total_steps` считает записи, а не шаги: день `[(1, 100), (2, 50)]` → ничья `1` и `2` с `1` шагом вместо `([1], 100)`
- @1 `total_days` [wrong]: за каждую запись прибавляется число дней, а не шаги: день `[(1, 100), (2, 50)]` → ничья `1` и `2` с `1` шагом вместо `([1], 100)`
- @1 `full` [crash]: `full` появится только после цикла: день `[(1, 100)]` → `UnboundLocalError`
- @1 `total_steps` [crash]: к числу не прибавить словарь: день `[(1, 100)]` → `TypeError: unsupported operand type(s) for +: 'int' and 'dict'`
- @1 `len(days_active)` [wrong]: к шагам прибавляется текущее число юзеров в `days_active`: день `[(1, 100), (2, 50)]` → `([2], 1)` вместо `([1], 100)`
- @2 `steps` [wrong]: `days_active` копит шаги, а не дни, и не совпадёт с `total_days`: день `[(1, 100)]` → `days_active[1] = 100`, ответ `([], 0)` вместо `([1], 100)`
- @2 `total_days` [wrong]: за каждый день прибавляется число дней: дни `[(1, 100)]`, `[(1, 100)]` → `days_active[1] = 4` вместо `2`, ответ `([], 0)` вместо `([1], 200)`
- @2 `full` [crash]: `full` появится только после цикла: день `[(1, 100)]` → `UnboundLocalError`
- @2 `total_steps` [crash]: к числу не прибавить словарь: день `[(1, 100)]` → `TypeError: unsupported operand type(s) for +: 'int' and 'dict'`
- @2 `len(days_active)` [wrong]: первая запись юзера прибавляет `0` — пока в `days_active` никого нет: день `[(1, 100)]` → `days_active[1] = 0`, ответ `([], 0)` вместо `([1], 100)`
- @2 `user` [wrong]: прибавляется номер юзера, а не `1` за день: день `[(2, 100)]` → `days_active[2] = 2` вместо `1`, ответ `([], 0)` вместо `([2], 100)`
- @3 `steps` [wrong]: в Python переменная цикла живёт и после него, `steps` — это шаги последней записи: день `[(1, 100)]` → `1 == 100` ложно, ответ `([], 0)` вместо `([1], 100)`
- @3 `1` [wrong]: остаются те, кто был ровно один день, а не все дни: дни `[(1, 100)]`, `[(1, 100)]` → `([], 0)` вместо `([1], 200)`
- @3 `full` [crash]: `full` ещё считается в этой самой строке: день `[(1, 100)]` → `NameError`
- @3 `total_steps` [wrong]: число дней никогда не равно словарю: день `[(1, 100)]` → `([], 0)` вместо `([1], 100)`
- @3 `user` [wrong]: в Python переменная цикла живёт и после него, `user` — это номер последнего юзера: дни `[(1, 100)]`, `[(1, 100)]` → `2 == 1` ложно, ответ `([], 0)` вместо `([1], 200)`
- @4 `steps` [crash]: по числу не пройти циклом: день `[(1, 100)]` → `TypeError: 'int' object is not iterable`
- @4 `1` [crash]: по числу не пройти циклом: день `[(1, 100)]` → `TypeError: 'int' object is not iterable`
- @4 `total_days` [crash]: по числу не пройти циклом: день `[(1, 100)]` → `TypeError: 'int' object is not iterable`
- @4 `len(days_active)` [crash]: по числу не пройти циклом: день `[(1, 100)]` → `TypeError: 'int' object is not iterable`
- @4 `user` [crash]: по числу не пройти циклом: день `[(1, 100)]` → `TypeError: 'int' object is not iterable`
? Тебе нужны две вещи на каждого юзера: суммарные шаги и в скольких днях он участвовал. Два словаря за один двойной проход.
? Шаги копим по `steps`, дни — по одному за запись.
? «Без пропусков» = число дней участия равно `len(statistics)`.
? Сначала отфильтруй таких, потом среди них ищи максимум, потом собери всех с этим максимумом (их может быть несколько!).
