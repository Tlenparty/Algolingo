# l0.2
note: 0.2 Разворот строки на месте
lang: python
title: Разворот строки
statement: Переверни список символов `s` на месте: `['a', 'b', 'c', 'd']` → `['d', 'c', 'b', 'a']`. Строка в Python неизменяема, поэтому символы приходят списком (`list("abcd")`). Без создания нового списка.
trains: два указателя навстречу (скелет [[04 Маркеры + Заготовки|#3]])
pitfalls:
- `lo <= hi` работает, но на нечётной длине средний символ меняется сам с собой: лишний шаг
- `hi = len(s)` вместо `len(s) - 1`: первый же `s[hi]` вне списка, `IndexError`
- `lo != hi`: на чётной длине указатели проскочат друг друга и выйдут за границы
- В Python нет `++`/`--`: `lo ++ 1` — это `lo + (+1)`, значение считается и выбрасывается, указатель стоит на месте
- `str` менять нельзя: `text[0] = "x"` падает с `TypeError`, поэтому работаем со списком и собираем строку через `"".join(s)`
variations:
- в проде: `s.reverse()` на списке или срез `text[::-1]` для строки — на собесе покажи два указателя
- проверка палиндрома — тот же скелет, но вместо обмена сравниваем `s[lo] != s[hi]` → `return False`
- развернуть кусок `s[i..j]`: тот же цикл со стартом `lo, hi = i, j`
examples:
- assert (reverse(s := list("abcd")), "".join(s)) == (None, "dcba")
- assert (reverse(s := list("abc")), "".join(s)) == (None, "cba")
- assert (reverse(s := list("a")), "".join(s)) == (None, "a")
- assert (reverse(s := []), s) == (None, [])
checks:
```python
# оракул: срез a[::-1]; все списки длины 0..6 из {a, b, c}
for n in range(7):
    with case():
        for m in range(pw(3, n)):
            a = ["abc"[(m // pw(3, k)) % 3] for k in range(n)]
            exp = a[::-1]
            r = reverse(a)
            assert r is None and a == exp, (exp, a, r)
# контрпримеры из причин
with case():
    a = list("ab")
    reverse(a)
    assert a == ["b", "a"], a
```

## theory Когда два указателя навстречу
signals:
- «Развернуть / симметрия»
- «Палиндром»
- Отсортированный массив + «пара / сумма»
body: Указатели стоят по краям и идут навстречу, обрабатывая пару `s[lo]`, `s[hi]`: время O(n), память O(1). Строка в Python неизменяема (`text[0] = "x"` → `TypeError`), поэтому на месте разворачивают список `list(text)`, а строку обратно собирает `"".join(s)`.

## theory Каркас
skeleton:
```python
lo, hi = 0, len(s) - 1
while lo < hi:
    # обработать пару s[lo], s[hi]
    lo += 1
    hi -= 1
```
body: Обмен в Python — кортежное присваивание `s[lo], s[hi] = s[hi], s[lo]`: правая часть считается целиком до записи, временная переменная не нужна. `++` в Python нет, шаг — `lo += 1`. `lo <= hi` засчитывается с пометкой: средний символ лишний раз поменяется сам с собой.

## theory Грабли
pitfalls:
- `hi = len(s)`: первый же `s[hi]` вне списка, `"abcd"` → `IndexError`
- `lo != hi` на чётной длине: указатели проскочат друг друга, `"abcd"` → `s[4]`, `IndexError`
- Обмен по одному: `s[lo] = s[hi]; s[hi] = s[lo]` превратит `ab` в `bb`; кортежное присваивание так не ошибается
- `lo++` не скомпилируется, а `lo ++ 1` — это `lo + (+1)`: ничего не меняет
- `hi = -1`: отрицательный индекс тоже последний символ, но `0 < -1` ложно — цикл не выполнится ни разу

## e1
```python
def reverse(s: list[str]) -> None:
    lo, hi = 0, len(s) - 1
    while ⟦lo < hi | ~lo <= hi⟧:
        s[lo], s[hi] = s[hi], s[lo]
        lo += 1
        hi -= 1
```
- ~`lo <= hi`: работает, но на нечётной длине средний символ меняется сам с собой: `abc` делает лишний шаг на `b`
- `lo > hi` [wrong]: цикл не выполнится ни разу: `abcd` останется `abcd`
- `lo != hi` [crash]: на чётной длине указатели проскочат друг друга: `abcd` → `s[4]`, `IndexError: list index out of range`
? `lo = 0`, `hi = len(s) - 1`, меняем местами, пока `lo < hi`.
? Именно `<`: при `<=` средний символ поменяется сам с собой (не страшно, но лишний шаг).

## e3
```python
def reverse(s: list[str]) -> None:
    lo, hi = 0, len(s) - 1
    while ⟦lo < hi⟧:
        s[lo], s[hi] = ⟦s[hi], s[lo]⟧
        lo ⟦+=⟧ 1
        hi ⟦-=⟧ 1
```
- `s[lo], s[hi]` [wrong]: каждый символ записывается сам в себя: `abcd` останется `abcd`
- `++` [wrong]: `lo ++ 1` — это `lo + (+1)`, значение выбрасывается, `lo` стоит на месте: `abcd` → `bcda` вместо `dcba`
- `--` [wrong]: `hi -- 1` — это `hi - (-1)`, значение выбрасывается, `hi` стоит на месте: `abcd` → `dabc` вместо `dcba`

- @1 `+=` [compile]: после `while` нужно условие, а не оператор: `while +=:` — `SyntaxError`
- @1 `-=` [compile]: после `while` нужно условие, а не оператор: `while -=:` — `SyntaxError`

- @2 `lo < hi` [crash]: справа одно значение, а слева два места: `abcd` → `TypeError: cannot unpack non-iterable bool object`
- @2 `+=` [compile]: после `=` нужны значения, а не оператор: `s[lo], s[hi] = +=` — `SyntaxError`
