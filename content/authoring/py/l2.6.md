# l2.6
note: 2.6 Максимальное среднее подмассива длины k
lang: python
title: Максимальное среднее подмассива
statement: Найди подряд идущий подсписок длины ровно `k` с максимальным средним и верни это среднее (LeetCode 643).
pitfalls:
- `max_sum // k` — целочисленное деление, дробь теряется: `51 // 4 = 12`; обычное `/` в Python 3 всегда даёт `float`
- `max_sum = 0`: у окна из отрицательных сумма меньше нуля
- `sum(nums[i:i + k])` в цикле — O(n·k): срез копирует всё окно на каждом шаге
- Вычитать `nums[i - 1]` вместо `nums[i - k]`: из окна уходит не тот элемент
variations:
- `max_sum = float('-inf')` вместо суммы первого окна — тоже верно, если первое окно учесть в цикле
- в лоб: `max(sum(nums[i:i + k]) for i in range(len(nums) - k + 1)) / k` — коротко, но O(n·k)
- префиксные суммы (`itertools.accumulate`): сумма любого окна за O(1), но O(n) памяти
examples:
- assert abs(find_max_average([1, 12, -5, -6, 50, 3], 4) - 12.75) < 1e-9
- assert abs(find_max_average([5], 1) - 5.0) < 1e-9
checks:
```python
# оракул: сумма каждого окна заново, лучшая / k; все списки длины 1..5 из {-2..2}, все k
for n in range(1, 6):
    with case():
        for m in range(pw(5, n)):
            a = [(m // pw(5, i)) % 5 - 2 for i in range(n)]
            for k in range(1, n + 1):
                best = max(sum(a[start:start + k]) for start in range(n - k + 1))
                got = find_max_average(a[:], k)
                assert abs(got - best / k) < 1e-9, (a, k, got)
with case():
    assert abs(find_max_average([-3, -1, -2], 2) - -1.5) < 1e-9
with case():
    assert abs(find_max_average([0, 0, 0], 3) - 0.0) < 1e-9
with case():
    assert abs(find_max_average([10000] * 5, 5) - 10000.0) < 1e-9
with case():
    assert abs(find_max_average([1, 2, 3, 4, 5, 6], 3) - 5.0) < 1e-9
# контрпримеры из причин
with case():
    assert abs(find_max_average([-1], 1) - -1.0) < 1e-9
with case():
    assert abs(find_max_average([1, 2, 3], 2) - 2.5) < 1e-9
with case():
    assert abs(find_max_average([1, 2], 1) - 2.0) < 1e-9
with case():
    assert abs(find_max_average([2, 1], 1) - 2.0) < 1e-9
```

## theory Когда окно фиксированной длины
signals:
- Подряд идущий отрезок **ровно** из `k` элементов
- Лучшая сумма или среднее по всем таким отрезкам
- Нужно O(n), а не O(n·k)
body: Соседние окна отличаются двумя числами: справа вошло `nums[i]`, слева ушло `nums[i - k]`. Сумму не пересчитываем, а поправляем за O(1). Длина окна постоянна, поэтому максимальное среднее — это максимальная сумма, делённая на `k`.

## theory Каркас
skeleton:
```python
# сумма первого окна
window_sum = sum(nums[:k])
# сдвигаем окно на 1
for i in range(k, len(nums)):
    # вошёл новый, ушёл старый
    window_sum += nums[i] - nums[i - k]
    # обновляем ответ
```
body: `sum(nums[:k])` — один раз, до цикла; внутри цикла сумму только поправляем. Делим один раз, в самом конце.

## theory Грабли
pitfalls:
- `max_sum // k` — целочисленное деление: `51 // 4 = 12`, а нужно `12.75`; среднее даёт `/`
- `max_sum = 0`: у окна из отрицательных сумма меньше нуля: `[-1]`, `k = 1` → `0`
- `sum(nums[i:i + k])` в цикле: верно, но O(n·k) — приём как раз в том, чтобы так не делать
- Вычитать `nums[i - 1]` вместо `nums[i - k]`: из окна уходит не тот элемент

## e1
```python
def find_max_average(nums: list[int], k: int) -> float:
    # сумма первого окна
    window_sum = sum(nums[:k])
    # лучшая сумма пока что
    max_sum = window_sum
    # сдвигаем окно на 1
    for i in range(k, len(nums)):
        # вошёл новый, ушёл старый
        window_sum += nums[i] - nums[i - k]
        # запоминаем лучшее
        max_sum = max(max_sum, window_sum)
    # среднее с дробной частью
    return ⟦max_sum / k⟧
```
- `max_sum // k` [wrong]: `//` — целочисленное деление, дробь теряется: `[1, 12, -5, -6, 50, 3]`, `k = 4` → `12` вместо `12.75`
- `max_sum / len(nums)` [wrong]: в окне `k` чисел, а не весь список: `[1, 12, -5, -6, 50, 3]`, `k = 4` → `8.5` вместо `12.75`

```python
def find_max_average(nums: list[int], k: int) -> float:
    # сумма первого окна
    window_sum = sum(nums[:k])
    # лучшая сумма пока что
    max_sum = ⟦window_sum⟧
    # сдвигаем окно на 1
    for i in range(k, len(nums)):
        # вошёл новый, ушёл старый
        window_sum += ⟦nums[i] - nums[i - k]⟧
        # запоминаем лучшее
        max_sum = ⟦max⟧(max_sum, window_sum)
    # среднее с дробной частью
    return max_sum / k
```
- `0` [wrong]: у окна из отрицательных сумма меньше нуля, и `0` её не пустит: `[-1]`, `k = 1` → `0.0` вместо `-1.0`
- `nums[i] - nums[i - 1]` [wrong]: из окна уходит не тот элемент: `[1, 2, 3]`, `k = 2` → `2.0` вместо `2.5`
- `min` [wrong]: запоминаем худшее окно, а не лучшее: `[1, 2]`, `k = 1` → `1.0` вместо `2.0`
- @1 `nums[i] - nums[i - k]` [crash]: `i` появится только в цикле, здесь его ещё нет: `[5]`, `k = 1` → `UnboundLocalError`
