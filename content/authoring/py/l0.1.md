# l0.1
note: 0.1 Сумма и максимум массива
lang: python
title: Сумма и максимум
statement: Верни сумму всех чисел списка и (отдельно) максимальный элемент парой `(сумма, максимум)`. Список непустой.
trains: базовый линейный проход с аккумулятором
pitfalls:
- `best = 0` ломается на `[-5, -2]`: вернёт `(-7, 0)`, а такого элемента нет
- `total =+ x` — это `total = +x`: сумма не копится, `[1, 2, 3]` даст `(3, 3)`
- Имена `sum` и `max` для переменных перекрывают встроенные функции: дальше `max(a, b)` упадёт с `TypeError`
- Пустой список: уточни у интервьюера, что делать (`nums[0]` бросит `IndexError`)
variations:
- в проде: `return (sum(nums), max(nums))` — коротко, но два прохода; на собесе покажи один проход
- минимум вместо максимума: старт `nums[0]`, сравнение `x < best`
- среднее: `total / len(nums)` — в Python `/` всегда даёт `float`, целое деление — `//`
- минимум и максимум сразу: ещё одна переменная в том же проходе
examples:
- assert sum_and_max([1, 2, 3]) == (6, 3)
- assert sum_and_max([-5, -2]) == (-7, -2)
- assert sum_and_max([7]) == (7, 7)
checks:
```python
# оракул: встроенные sum()/max(), а не ручной проход; все списки длины 1..5 из {-3, -1, 0, 2}
vals = [-3, -1, 0, 2]
for n in range(1, 6):
    with case():
        for m in range(pw(4, n)):
            a = [vals[(m // pw(4, k)) % 4] for k in range(n)]
            r = sum_and_max(a)
            assert type(r) is tuple and r == (sum(a), max(a)), (a, r)
            assert type(r[0]) is int and type(r[1]) is int, (a, r)
with case():
    assert sum_and_max([0]) == (0, 0)
with case():
    assert sum_and_max([10 ** 20, 10 ** 20]) == (2 * 10 ** 20, 10 ** 20)  # переполнения в Python нет
with case():
    assert sum_and_max([5, 1, 3]) == (9, 5)  # максимум первым
with case():
    assert sum_and_max([1, 3, 5]) == (9, 5)  # максимум последним
# контрпримеры из причин
with case():
    assert sum_and_max([3, 1]) == (4, 3)
```

## theory Когда один проход
signals:
- «Пройти и накопить»: сумма, счётчик
- «Найти max/min» без сортировки
body: Один `for` и одна переменная-аккумулятор: время O(n), память O(1). В проде хватит `sum(nums)` и `max(nums)`, но на собесе просят показать сам проход.

## theory Каркас
skeleton:
```python
acc = start
for x in nums:
    # обновить acc по x
    ...
```
body: Старт для суммы — `0`, для максимума — первый элемент `nums[0]`. Переменные не называй `sum` и `max`: это встроенные функции.

## theory Грабли
pitfalls:
- `best = 0` ломается на `[-5, -2]`: вернёт `(-7, 0)`, а такого элемента нет
- `total =+ x` — это `total = +x`: каждый шаг перезаписывает сумму, `[1, 2, 3]` даст `(3, 3)`
- `best = None`: `x > None` в Python 3 падает с `TypeError`
- Пустой список: уточни у интервьюера, что делать (`nums[0]` бросит `IndexError`)

## e1
```python
def sum_and_max(nums: list[int]) -> tuple[int, int]:
    total = 0
    best = ⟦nums[0] | ~float('-inf')⟧
    for x in nums:
        total += x
        if x > best:
            best = x
    return (total, best)
```
- ~`float('-inf')`: работает, но на пустом списке молча вернёт `(0, -inf)` вместо ошибки; `nums[0]` честнее
- `0` [wrong]: на отрицательных числах `x > best` не сработает: `[-5, -2]` → `(-7, 0)`, а такого элемента нет
- `float('inf')` [wrong]: `x > best` никогда не сработает: `[1, 2, 3]` → `(6, inf)` вместо `(6, 3)`
- `None` [crash]: с `None` число не сравнить: `[1, 2, 3]` → `1 > None` падает с `TypeError: '>' not supported between instances of 'int' and 'NoneType'`
- `nums[1]` [crash]: на списке из одного элемента второго нет: `[7]` → `IndexError: list index out of range`
? Максимум инициализируй **первым элементом**, не нулём: числа могут быть отрицательными.

## e3
```python
def sum_and_max(nums: list[int]) -> tuple[int, int]:
    total = ⟦0⟧
    best = ⟦nums[0] | ~float('-inf')⟧
    for x in nums:
        total ⟦+=⟧ x
        if x ⟦>⟧ best:
            best = x
    return (total, best)
```
- ~`float('-inf')`: работает, но на пустом списке молча вернёт `(0, -inf)` вместо ошибки; `nums[0]` честнее
- `=+` [wrong]: `total =+ x` — это `total = +x`, сумма перезаписывается: `[1, 2, 3]` → `(3, 3)` вместо `(6, 3)`
- `<` [wrong]: `x < best` ищет минимум: `[1, 2, 3]` → `(6, 1)` вместо `(6, 3)`
- @1 `nums[0]` [wrong]: цикл ещё раз прибавит первый элемент: `[1, 2, 3]` → `(7, 3)` вместо `(6, 3)`
- @1 `float('-inf')` [wrong]: к минус бесконечности ничего не прибавить: `[1, 2, 3]` → `(-inf, 3)` вместо `(6, 3)`
- @1 `+=` [compile]: после `=` нужно начальное значение: `total = +=` — `SyntaxError`
- @1 `>` [compile]: после `=` нужно начальное значение: `total = >` — `SyntaxError`
- @1 `=+` [compile]: после `=` нужно начальное значение: `total = =+` — `SyntaxError`
- @1 `<` [compile]: после `=` нужно начальное значение: `total = <` — `SyntaxError`
- @2 `0` [wrong]: на отрицательных числах `x > best` не сработает: `[-5, -2]` → `(-7, 0)`, а такого элемента нет
- @2 `+=` [compile]: после `=` нужно начальное значение: `best = +=` — `SyntaxError`
- @2 `>` [compile]: после `=` нужно начальное значение: `best = >` — `SyntaxError`
- @2 `=+` [compile]: после `=` нужно начальное значение: `best = =+` — `SyntaxError`
- @2 `<` [compile]: после `=` нужно начальное значение: `best = <` — `SyntaxError`
- @3 `0` [compile]: между `total` и `x` нужен оператор: `total 0 x` — `SyntaxError`
- @3 `nums[0]` [compile]: между `total` и `x` нужен оператор: `total nums[0] x` — `SyntaxError`
- @3 `>` [wrong]: `total > x` только сравнивает и ничего не копит: `[1, 2, 3]` → `(0, 3)` вместо `(6, 3)`
- @3 `float('-inf')` [compile]: между `total` и `x` нужен оператор: `total float('-inf') x` — `SyntaxError`
- @3 `<` [wrong]: `total < x` только сравнивает и ничего не копит: `[1, 2, 3]` → `(0, 3)` вместо `(6, 3)`
- @4 `0` [compile]: между `x` и `best` нужен оператор сравнения: `if x 0 best:` — `SyntaxError`
- @4 `nums[0]` [compile]: между `x` и `best` нужен оператор сравнения: `if x nums[0] best:` — `SyntaxError`
- @4 `+=` [compile]: в условии `if` присваивать нельзя: `if x += best:` — `SyntaxError`
- @4 `float('-inf')` [compile]: между `x` и `best` нужен оператор сравнения: `if x float('-inf') best:` — `SyntaxError`
- @4 `=+` [compile]: в условии `if` присваивать нельзя: `if x =+ best:` — `SyntaxError`
? Одна переменная-аккумулятор, один `for`: `total += x` копит сумму.
? Максимум обновляем, когда встретили больший элемент: `x > best`.
