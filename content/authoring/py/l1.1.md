# l1.1
note: 1.1 Есть ли дубликат
lang: python
title: Есть ли дубликат
statement: Верни `True`, если в списке есть хоть один повтор, иначе `False`.
trains: множество `set()` «уже видели» и ранний выход
pitfalls:
- Двойной цикл «каждый с каждым» даёт O(n²) вместо O(n)
- `{}` — пустой словарь, а не множество: `seen.add(x)` падает с `AttributeError`
- `set.add` в Python возвращает `None`, а не `bool`: проверка `x in seen` идёт отдельной строкой до добавления
- `in` по списку `[]` ищет линейно: даже если бы список подошёл, вышло бы O(n²)
variations:
- в проде: `return len(set(nums)) != len(nums)` — одна строка, но всегда строит множество целиком, без раннего выхода; на собесе покажи цикл
- повтор на расстоянии не больше `k`: словарь «значение → последний индекс» вместо множества
- список отсортирован: повтор — это равные соседи `nums[i] == nums[i - 1]`, O(1) памяти
examples:
- assert has_duplicate([1, 2, 3]) is False
- assert has_duplicate([1, 2, 1]) is True
- assert has_duplicate([]) is False
- assert has_duplicate([7, 7]) is True
checks:
```python
# оракул: len(set(a)) != len(a); все списки длины 0..5 из {-1, 0, 1, 2}; ответ строго bool
for n in range(6):
    with case():
        for m in range(pw(4, n)):
            a = [(m // pw(4, k)) % 4 - 1 for k in range(n)]
            assert has_duplicate(a) is (len(set(a)) != len(a)), a
with case():
    assert has_duplicate([5]) is False
with case():
    assert has_duplicate([1, 2, 3, 1]) is True  # дубль первого и последнего
with case():
    assert has_duplicate([1, 2, 3, 3]) is True  # дубль в самом конце
with case():
    assert has_duplicate([10 ** 20, -10 ** 20, 0]) is False
# контрпримеры из причин
with case():
    assert has_duplicate([1, 2]) is False
with case():
    assert has_duplicate([1, 1]) is True
with case():
    assert has_duplicate([1]) is False
```

## theory Когда множество
signals:
- «Есть ли повтор?», «видели ли раньше?»
- Важно только наличие элемента, не количество
- Нужно уложиться в O(n)
body: `set` отвечает на `x in seen` в среднем за O(1), поэтому весь проход — O(n) по времени и O(n) по памяти. Повтор нашли — сразу `return True`, дальше смотреть незачем.

## theory Каркас
skeleton:
```python
seen = set()
for x in nums:
    if x in seen:
        return True
    seen.add(x)
return False
```
body: Сначала проверка, потом добавление. В Kotlin `add` сам говорит, был ли элемент, а в Python `seen.add(x)` всегда возвращает `None`, поэтому проверка `x in seen` идёт отдельной строкой. Пустое множество — только `set()`: `{}` — это пустой словарь.

## theory Грабли
pitfalls:
- `seen = {}`: это словарь, у него нет `add`: `[1, 2, 3]` → `AttributeError: 'dict' object has no attribute 'add'`
- `if seen.add(x):` — `add` возвращает `None`, условие всегда ложно: `[1, 2, 1]` → `False`
- Сначала `seen.add(x)`, потом `x in seen`: проверка всегда истинна, `[1, 2, 3]` → `True`
- `seen = []` и `seen.append(x)`: ответ верный, но `in` по списку линейный — снова O(n²)
- Ответ строго `True`/`False`: вернуть `seen` или `None` — не то же самое, даже если в `if` они ведут себя похоже

## e1
```python
def has_duplicate(nums: list[int]) -> bool:
    seen = set()
    for x in nums:
        if ⟦x in seen⟧:
            return True
        seen.add(x)
    return False
```
- `x not in seen` [wrong]: условие перевёрнуто, первый же новый элемент даёт ответ: `[1, 2, 3]` → `True` вместо `False`
- `seen.add(x)` [wrong]: `add` возвращает `None`, условие всегда ложно: `[1, 2, 1]` → `False` вместо `True`
- `x in nums` [wrong]: `x` всегда есть в своём же списке: `[1, 2, 3]` → `True` вместо `False`
? Повтор — это `x`, который уже лежит в `seen`.

## e3
```python
def has_duplicate(nums: list[int]) -> bool:
    seen = ⟦set()⟧
    for x in nums:
        if ⟦x in seen⟧:
            return ⟦True | ~x in seen⟧
        seen.add(x)
    return ⟦False⟧
```
