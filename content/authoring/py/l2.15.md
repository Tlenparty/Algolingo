# l2.15
note: 2.15 Валидный палиндром
lang: python
title: Валидный палиндром
statement: Строка — палиндром, если читать только буквы и цифры и не различать регистр? Верни `True` или `False` (LeetCode 125).
trains: два указателя навстречу с пропуском лишних символов
pitfalls:
- `isalpha()` вместо `isalnum()`: цифры выпадут, `"0P"` → `True`
- Без `lower()`: `"Aa"` → `False`
- Пропуск справа двигает не тот указатель: `"ab."` → `True`
- На несовпадении `False`, после цикла `True`
variations:
- в лоб: `t = "".join(c.lower() for c in s if c.isalnum())` и `t == t[::-1]` — коротко, но O(n) памяти
- «палиндром, если удалить не больше одного символа»: на первом расхождении проверить две подстроки
examples:
- assert is_valid_palindrome("A man, a plan, a canal: Panama") is True
- assert is_valid_palindrome("race a car") is False
- assert is_valid_palindrome(" ") is True
- assert is_valid_palindrome("0P") is False
checks:
```python
# оракул: оставить буквы и цифры, в нижний регистр, сравнить с разворотом; все строки длины 0..5 из {a, A, b, 0, пробел, запятая}; ответ строго bool
abc = "aAb0 ,"
for n in range(6):
    with case():
        for m in range(pw(6, n)):
            s = "".join(abc[(m // pw(6, k)) % 6] for k in range(n))
            t = "".join(c.lower() for c in s if c.isalnum())
            assert is_valid_palindrome(s) is (t == t[::-1]), s
with case():
    assert is_valid_palindrome("") is True
with case():
    assert is_valid_palindrome(".,") is True
with case():
    assert is_valid_palindrome("Шалаш!") is True
# контрпримеры из причин
with case():
    assert is_valid_palindrome(".ab") is False
with case():
    assert is_valid_palindrome("ab.") is False
with case():
    assert is_valid_palindrome(".a") is True
with case():
    assert is_valid_palindrome("ab") is False
with case():
    assert is_valid_palindrome("aba") is True
with case():

```

## theory Когда пропускать по пути
signals:
- Палиндром, но «только буквы и цифры»
- «Регистр не важен»
- Память O(1): копию строки не строим
body: Скелет 0.3. Перед сравнением каждый указатель сам пропускает лишний символ: шаг и `continue`, на следующем круге проверка заново. Сравниваем `lower()` обеих сторон. Время O(n), память O(1).

## theory Каркас
skeleton:
```python
while left < right:
    # слева лишний -> left += 1, continue
    # справа лишний -> right -= 1, continue
    # сравнить без регистра
    left += 1
    right -= 1
```
body: `continue` нужен, чтобы после шага снова проверить `left < right` и новый символ.

## theory Грабли
pitfalls:
- `isalpha()` вместо `isalnum()`: цифры выпадут, `"0P"` → `True`
- Без `lower()`: `"Aa"` → `False`
- Пропуск справа двигает не тот указатель: `"ab."` → `True`
- На несовпадении `False`, после цикла `True`

## e1
```python
# Случай 1: "A man, a plan, a canal: Panama" → True
# Случай 2: "race a car" → False
# Случай 3: " " → True
def is_valid_palindrome(s: str) -> bool:
    # левый указатель — с начала
    left = 0
    # правый указатель — с конца
    right = len(s) - 1
    # идём навстречу
    while left < right:
        # слева не буква и не цифра — пропускаем
        if not s[left].isalnum():
            ⟦left += 1⟧
            continue
        # справа так же
        if not s[right].isalnum():
            right -= 1
            continue
        # сравниваем без учёта регистра
        if s[left].lower() != s[right].lower():
            return False
        # оба указателя — к центру
        left += 1
        right -= 1
    # все пары совпали
    return True
```
- `right -= 1` [wrong]: лишний символ слева так и остаётся, а правый указатель съедает буквы: `".ab"` вернёт `True`
- `break` [wrong]: на первом лишнем символе проверка бросается: `".ab"` вернёт `True`
? Лишний символ слева — сдвигаем левый указатель внутрь.
