# l2.5
note: 2.5 Является ли подпоследовательностью
lang: python
title: Подпоследовательность
statement: Верни `True`, если `s` получается из `t` удалением некоторых символов без изменения порядка остальных (LeetCode 392).
pitfalls:
- `return t_index == len(t)`: `t` дочитывается до конца и тогда, когда `s` не нашлась
- Двигать `t_index` только при совпадении: на первом несовпадении цикл встаёт навсегда
- `or` вместо `and`: индекс уходит за конец строки — `IndexError`
- Пустая `s` — подпоследовательность любой строки, даже пустой
variations:
- `s in t` проверяет подстроку (подряд), а не подпоследовательность: `"ac" in "abc"` → `False`
- в проде коротко: `it = iter(t)` и `all(ch in it for ch in s)` — `in` по итератору съедает `t` до совпадения; тот же жадный проход, но трюк надо знать
- много запросов `s` к одной `t` — заранее список позиций каждой буквы в `t` и `bisect` по нему
examples:
- assert is_subsequence("abc", "ahbgdc") is True
- assert is_subsequence("axc", "ahbgdc") is False
checks:
```python
# оракул: перебор всех подпоследовательностей t по маске; все s и t из {a, b} длины 0..3 и 0..4
for s_len in range(4):
    for t_len in range(5):
        with case():
            for x in range(pw(2, s_len)):
                for y in range(pw(2, t_len)):
                    s = "".join("ab"[(x // pw(2, i)) % 2] for i in range(s_len))
                    t = "".join("ab"[(y // pw(2, i)) % 2] for i in range(t_len))
                    expected = any("".join(t[i] for i in range(t_len) if (mask // pw(2, i)) % 2) == s
                                   for mask in range(pw(2, t_len)))
                    assert is_subsequence(s, t) is expected, (s, t)
with case():
    assert is_subsequence("", "") is True
with case():
    assert is_subsequence("", "abc") is True
with case():
    assert is_subsequence("a", "") is False
with case():
    assert is_subsequence("abc", "abc") is True
with case():
    assert is_subsequence("aaa", "aa") is False
with case():
    assert is_subsequence("ab", "ba") is False
# контрпримеры из причин
with case():
    assert is_subsequence("a", "a") is True
with case():
    assert is_subsequence("b", "ab") is True
with case():
    assert is_subsequence("ab", "abc") is True
```

## theory Когда по указателю на строку
signals:
- Две последовательности, и **порядок** элементов важен
- «Получается ли одна из другой вычёркиванием»
- Нужно O(n) и O(1) памяти
body: `t_index` читает `t` по одному символу, `s_index` ждёт свой очередной символ из `s`. Совпало — `s` продвинулась на шаг. Брать самое раннее совпадение всегда безопасно: позднее оставило бы для остатка `s` меньше символов `t`.

## theory Каркас
skeleton:
```python
# по указателю на строку
s_index, t_index = 0, 0
# пока обе не кончились
while s_index < len(s) and t_index < len(t):
    # совпало — двигаем s
    # t двигается всегда
# нашли всю s?
```
body: `t_index` растёт на каждом шаге, поэтому цикл сделает не больше `len(t)` шагов. После цикла смотрим на `s_index`: дошёл до конца `s` — значит, все её символы нашлись по порядку.

## theory Грабли
pitfalls:
- `return t_index == len(t)`: `t` дочитывается до конца и тогда, когда `s` не нашлась: `"axc"`, `"ahbgdc"` → `True`
- Двигать `t_index` только при совпадении: на первом же несовпадении цикл встаёт навсегда
- `or` вместо `and`: индекс уходит за конец одной из строк — `IndexError`
- `s in t` ищет подстроку подряд, а не подпоследовательность: `"ac" in "abc"` → `False`

## e1
```python
def is_subsequence(s: str, t: str) -> bool:
    # указатель в s
    s_index = 0
    # указатель в t
    t_index = 0
    # пока обе не кончились
    while s_index < len(s) and t_index < len(t):
        # совпало — двигаем s
        if s[s_index] == t[t_index]:
            s_index += 1
        # t двигается всегда
        t_index += 1
    # всю s нашли по порядку?
    return ⟦s_index == len(s)⟧
```
- `t_index == len(t)` [wrong]: `t` дочитывается до конца и тогда, когда `s` не нашлась: `"axc"`, `"ahbgdc"` → `True` вместо `False`
- `s_index < len(s)` [wrong]: условие наоборот — «нашли не всё»: `"abc"`, `"ahbgdc"` → `False` вместо `True`
? `t` может кончиться и тогда, когда `s` не нашлась. Какой указатель знает, сколько символов `s` уже найдено?
