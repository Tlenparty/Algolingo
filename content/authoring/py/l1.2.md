# l1.2
note: 1.2 Первый неповторяющийся символ
lang: python
title: Первый уникальный символ
statement: Верни первый символ строки, встречающийся ровно один раз, иначе `None`.
trains: словарь частот `dict` + второй проход по строке
pitfalls:
- Один проход не работает: пока строка не дочитана, неизвестно, повторится ли символ
- `counts[ch] += 1` без начального значения падает с `KeyError`: нового символа в словаре ещё нет, поэтому `counts.get(ch, 0) + 1`
- `{}` — пустой словарь, а `set()` — множество: частоты хранит только словарь
- «Не нашли» — это `None`, а не `""` или `-1`
variations:
- в проде: `collections.Counter(s)` вместо ручного подсчёта — на собесе покажи словарь
- `s.count(ch) == 1` в цикле по строке тоже верно, но каждый `count` проходит всю строку — O(n²)
- нужен индекс, а не символ: `for i, ch in enumerate(s)` и `return i`, «не нашли» — `-1`
examples:
- assert first_unique_char("abacb") == "c"
- assert first_unique_char("aabb") is None
- assert first_unique_char("z") == "z"
- assert first_unique_char("") is None
- assert first_unique_char("ba") == "b"
checks:
```python
# оракул: первый символ с s.count(c) == 1 (квадратичный подсчёт, без словаря); все строки длины 0..5 из {a, b, c}
for n in range(6):
    with case():
        for m in range(pw(3, n)):
            s = "".join("abc"[(m // pw(3, k)) % 3] for k in range(n))
            exp = next((c for c in s if s.count(c) == 1), None)
            r = first_unique_char(s)
            assert r == exp and type(r) is type(exp), (s, r)
with case():
    assert first_unique_char("abb") == "a"  # уникальный первым
with case():
    assert first_unique_char("aab") == "b"  # уникальный последним
with case():
    assert first_unique_char("abcabc") is None
with case():
    assert first_unique_char("шалаш") == "л"
# контрпримеры из причин
with case():
    assert first_unique_char("aa") is None
with case():
    assert first_unique_char("ab") == "a"
```

## theory Когда словарь частот
signals:
- «Сколько раз встречается?»
- «Ровно один раз», «чаще всего»
- «Первый такой» — важен порядок исходных данных
body: Словарь `counts` «символ → сколько раз» считается за один проход O(n); память O(k), где k — число разных символов. Готовый `collections.Counter` делает то же самое, но на собесе покажи словарь руками.

## theory Каркас: два прохода
skeleton:
```python
counts = {}
for ch in s:
    counts[ch] = counts.get(ch, 0) + 1
for ch in s:
    if counts[ch] == 1:
        return ch
return None
```
body: Первый проход считает, второй идёт снова по строке `s`: она знает, какой символ был первым. `counts.get(ch, 0)` вернёт `0` для символа, которого ещё нет, а `counts[ch]` на нём упадёт с `KeyError`. Обход самого словаря тоже даст верный ответ: с Python 3.7 `dict` помнит порядок вставки, а ключи вставлены в порядке первого появления. Но приём «второй проход по строке» не зависит от этой гарантии и работает в любом языке (в Kotlin `HashMap` порядок не хранит).

## theory Грабли
pitfalls:
- `counts[ch] + 1` без `get`: на первом же символе ключа ещё нет, `"abacb"` → `KeyError: 'a'`
- `counts.get(ch)` без значения по умолчанию вернёт `None`: `"abacb"` → `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`
- Стартовое значение `1` вместо `0`: каждый символ посчитается на раз больше, `"z"` → `None` вместо `"z"`
- `counts = set()`: у множества нет `get`, `"abacb"` → `AttributeError: 'set' object has no attribute 'get'`
- Пытаться в один проход: пока строка не дочитана, неизвестно, повторится ли символ

## e1
```python
def first_unique_char(s: str) -> str | None:
    counts = {}
    for ch in s:
        counts[ch] = counts.get(ch, 0) + 1
    for ch in ⟦s | ~counts⟧:
        if counts[ch] == 1:
            return ch
    return None
```
- ~`counts`: работает: с Python 3.7 словарь помнит порядок вставки, а ключи вставлены в порядке первого появления; но приём — второй проход по строке, он не зависит от этой гарантии
- `reversed(s)` [wrong]: с конца найдётся последний уникальный, а не первый: `"ba"` → `"a"` вместо `"b"`
- `sorted(s)` [wrong]: после сортировки порядок строки потерян, найдётся наименьший уникальный: `"ba"` → `"a"` вместо `"b"`
? Первый проход считает частоты. Второй проход **по исходной строке** (порядок важен!) — первый символ с частотой 1.

## e2
```python
def first_unique_char(s: str) -> str | None:
    counts = {}
    for ch in s:
        counts[ch] = ⟦counts.get(ch, 0)⟧ + 1
    for ch in s:
        if counts[ch] == ⟦1⟧:
            return ch
    return None
```
- `counts[ch]` [crash]: нового символа в словаре ещё нет: `"abacb"` → `KeyError: 'a'` на первом же символе
- `counts.get(ch)` [crash]: без второго аргумента `get` вернёт `None`: `"abacb"` → `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`
- `counts.get(ch, 1)` [wrong]: счёт начинается с `1`, у одиночки частота `2`: `"z"` → `None` вместо `"z"`
- `2` [wrong]: ищем символ, который встретился ровно дважды: `"abacb"` → `"a"` вместо `"c"`
- @1 `1` [wrong]: `counts[ch] = 1 + 1` — частота каждого символа всегда `2`: `"z"` → `None` вместо `"z"`
- @1 `2` [wrong]: `counts[ch] = 2 + 1` — частота каждого символа всегда `3`: `"z"` → `None` вместо `"z"`
- @2 `counts.get(ch, 0)` [wrong]: частота сравнивается сама с собой, условие всегда истинно: `"aabb"` → `"a"` вместо `None`
- @2 `counts[ch]` [wrong]: частота сравнивается сама с собой, условие всегда истинно: `"aabb"` → `"a"` вместо `None`
- @2 `counts.get(ch)` [wrong]: частота сравнивается сама с собой, условие всегда истинно: `"aabb"` → `"a"` вместо `None`
- @2 `counts.get(ch, 1)` [wrong]: символ из строки всегда есть в словаре, это та же частота — условие всегда истинно: `"aabb"` → `"a"` вместо `None`
? Нового символа в `counts` ещё нет — сколько раз мы его видели до этого? `get` с запасным значением.
? Уникальный — тот, что встретился ровно один раз.

## e3
```python
def first_unique_char(s: str) -> str | None:
    counts = ⟦{}⟧
    for ch in s:
        counts[ch] = counts.get(ch, ⟦0⟧) + 1
    for ch in ⟦s | ~counts⟧:
        if counts[ch] == 1:
            return ch
    return ⟦None⟧
```
- ~`counts`: работает: с Python 3.7 словарь помнит порядок вставки, а ключи вставлены в порядке первого появления; но приём — второй проход по строке, он не зависит от этой гарантии
- `set()` [crash]: множество не хранит частоты, у него нет `get`: `"abacb"` → `AttributeError: 'set' object has no attribute 'get'`
- `1` [wrong]: счёт начинается с `1`, у одиночки частота `2`: `"z"` → `None` вместо `"z"`
- `""` [wrong]: «не нашли» — это `None`, а пустая строка — тоже строка: `"aabb"` → `""` вместо `None`
- `-1` [wrong]: «не нашли» — это `None`, `-1` — привычка из поиска индекса: `"aabb"` → `-1` вместо `None`
- @1 `0` [crash]: `counts = 0` — это число, у него нет `get`: `"abacb"` → `AttributeError: 'int' object has no attribute 'get'`
- @1 `s` [crash]: `counts = s` — это строка, у неё нет `get`: `"abacb"` → `AttributeError: 'str' object has no attribute 'get'`
- @1 `None` [crash]: у `None` нет `get`: `"abacb"` → `AttributeError: 'NoneType' object has no attribute 'get'`
- @1 `counts` [crash]: `counts = counts` читает имя, которого ещё нет: `"abacb"` → `UnboundLocalError` на первой же строке
- @1 `1` [crash]: `counts = 1` — это число, у него нет `get`: `"abacb"` → `AttributeError: 'int' object has no attribute 'get'`
- @1 `""` [crash]: `counts = ""` — это строка, у неё нет `get`: `"abacb"` → `AttributeError: 'str' object has no attribute 'get'`
- @1 `-1` [crash]: `counts = -1` — это число, у него нет `get`: `"abacb"` → `AttributeError: 'int' object has no attribute 'get'`
- @2 `{}` [crash]: к словарю не прибавить `1`: `"abacb"` → `TypeError: unsupported operand type(s) for +: 'dict' and 'int'`
- @2 `s` [crash]: для нового символа `get` вернёт строку, а к строке не прибавить число: `"abacb"` → `TypeError: can only concatenate str (not "int") to str`
- @2 `None` [crash]: к `None` не прибавить `1`: `"abacb"` → `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`
- @2 `counts` [crash]: для нового символа `get` вернёт сам словарь, а к словарю не прибавить `1`: `"abacb"` → `TypeError: unsupported operand type(s) for +: 'dict' and 'int'`
- @2 `set()` [crash]: к множеству не прибавить `1`: `"abacb"` → `TypeError: unsupported operand type(s) for +: 'set' and 'int'`
- @2 `""` [crash]: к пустой строке не прибавить число: `"abacb"` → `TypeError: can only concatenate str (not "int") to str`
- @2 `-1` [wrong]: счёт начинается с `-1`, у одиночки частота `0`, у пары — `1`: `"abacb"` → `"a"` вместо `"c"`
- @3 `{}` [wrong]: обходим пустой словарь, второй цикл не выполнится ни разу: `"z"` → `None` вместо `"z"`
- @3 `0` [crash]: по числу не пройти циклом: `"z"` → `TypeError: 'int' object is not iterable`
- @3 `None` [crash]: по `None` не пройти циклом: `"z"` → `TypeError: 'NoneType' object is not iterable`
- @3 `set()` [wrong]: обходим пустое множество, второй цикл не выполнится ни разу: `"z"` → `None` вместо `"z"`
- @3 `1` [crash]: по числу не пройти циклом: `"z"` → `TypeError: 'int' object is not iterable`
- @3 `""` [wrong]: обходим пустую строку, второй цикл не выполнится ни разу: `"z"` → `None` вместо `"z"`
- @3 `-1` [crash]: по числу не пройти циклом: `"z"` → `TypeError: 'int' object is not iterable`
- @4 `{}` [wrong]: «не нашли» — это `None`, а не пустой словарь: `"aabb"` → `{}` вместо `None`
- @4 `0` [wrong]: «не нашли» — это `None`, а не число: `"aabb"` → `0` вместо `None`
- @4 `s` [wrong]: вернём всю строку вместо «ничего»: `"aabb"` → `"aabb"` вместо `None`
- @4 `counts` [wrong]: вернём словарь частот вместо «ничего»: `"aabb"` → `{'a': 2, 'b': 2}` вместо `None`
- @4 `set()` [wrong]: «не нашли» — это `None`, а не пустое множество: `"aabb"` → `set()` вместо `None`
- @4 `1` [wrong]: «не нашли» — это `None`, а не число: `"aabb"` → `1` вместо `None`
? Частоты хранит словарь `{}`; нового символа в нём ещё нет — значит, видели его `0` раз.
? Второй проход **по исходной строке** — первый символ с частотой 1.
? Уникального нет — честно верни «ничего»: `None`.
