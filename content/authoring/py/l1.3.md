# l1.3
note: 1.3 Анаграмма / одинаковый набор букв 🔥Avito
lang: python
title: Анаграмма
statement: Даны два слова. Верни `True`, если они состоят из одинакового набора букв с учётом количества, иначе `False`.
trains: словарь частот `dict`: плюсуем буквы `a`, минусуем буквы `b`
pitfalls:
- Сначала сравни длины: без этого `"ab"` и `"a"` пройдут — лишнюю букву `a` никто не заметит
- `counts[ch] - 1` для буквы, которой нет в `a`, падает с `KeyError`: нужен `counts.get(ch, 0) - 1`
- `{}` — пустой словарь, а `set()` — множество: частоты хранит только словарь
- «Отсортировать обе строки и сравнить» — O(n log n), а словарь даёт O(n)
variations:
- в проде: `collections.Counter(a) == Counter(b)` — на собесе покажи словарь руками
- `sorted(a) == sorted(b)` тоже верно, но это O(n log n); скажи, что словарь даёт O(n)
- без учёта регистра и пробелов: сначала нормализуй строки, например `a.lower().replace(" ", "")`
- без проверки длины: плюсуем `a`, минусуем `b`, а в конце проверяем, что все счётчики стали нулями: `all(v == 0 for v in counts.values())`
examples:
- assert same_letters("йцукен", "некуцй") is True
- assert same_letters("ффффа", "фффа") is False
- assert same_letters("ab", "ac") is False
- assert same_letters("aab", "abb") is False
- assert same_letters("", "") is True
checks:
```python
# оракул: сравнение отсортированных списков букв; все пары строк длины 0..3 из {a, b, c}
words = []
for n in range(4):
    for m in range(pw(3, n)):
        words.append("".join("abc"[(m // pw(3, k)) % 3] for k in range(n)))
for a in words:
    with case():
        for b in words:
            r = same_letters(a, b)
            assert r is (sorted(a) == sorted(b)), (a, b, r)
with case():
    assert same_letters("", "a") is False
with case():
    assert same_letters("abc", "abcc") is False
with case():
    assert same_letters("Аб", "бА") is True  # регистр важен: это те же буквы
with case():
    assert same_letters("Аб", "аб") is False
# контрпримеры из причин
with case():
    assert same_letters("ab", "ba") is True
with case():
    assert same_letters("a", "a") is True
with case():
    assert same_letters("aa", "aa") is True
with case():
    assert same_letters("ab", "a") is False
with case():
    assert same_letters("ab", "aa") is False
```

## theory Когда сравнивать частоты
signals:
- «Одинаковый набор букв», «перестановка», «анаграмма»
- «С учётом количества» — важно, сколько раз, а не только есть ли
- Нужно уложиться в O(n)
body: Один словарь `counts` «буква → сколько осталось»: плюсуем буквы `a`, минусуем буквы `b`. O(n) по времени, O(k) по памяти, где k — число разных букв. Готовые `collections.Counter(a) == Counter(b)` и `sorted(a) == sorted(b)` тоже верны, но на собесе покажи словарь: `sorted` — это O(n log n).

## theory Каркас
skeleton:
```python
if len(a) != len(b):
    return False
counts = {}
for ch in a:
    counts[ch] = counts.get(ch, 0) + 1
for ch in b:
    left = counts.get(ch, 0) - 1
    if left < 0:
        return False
    counts[ch] = left
return True
```
body: Длины равны и счётчик ни разу не ушёл в минус ⇒ частоты совпали: если бы какой-то буквы `b` не хватило, её счётчик стал бы `-1`. `counts.get(ch, 0)` вернёт `0` для буквы, которой нет в словаре, а `counts[ch]` на ней упадёт с `KeyError`.

## theory Грабли
pitfalls:
- Без проверки длины лишние буквы `a` никто не заметит: `"ab"` / `"a"` → `True` вместо `False`
- `counts[ch] - 1` вместо `get`: буквы `c` нет в `a`, `"ab"` / `"ac"` → `KeyError: 'c'`
- Запасное значение `1` вместо `0`: буква, которой нет в `a`, даст `0`, а не минус: `"ab"` / `"ac"` → `True` вместо `False`
- `counts = set()`: у множества нет `get`, `"ab"` / `"ba"` → `AttributeError: 'set' object has no attribute 'get'`
- `left <= 0`: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `False` вместо `True`

## e1
```python
def same_letters(a: str, b: str) -> bool:
    if len(a) != len(b):
        return False
    counts = {}
    for ch in a:
        counts[ch] = counts.get(ch, 0) + 1
    for ch in b:
        left = counts.get(ch, 0) - 1
        if left ⟦<⟧ 0:
            return False
        counts[ch] = left
    return True
```
- `<=` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `False` вместо `True`
- `==` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `False` вместо `True`
- `>` [wrong]: условие перевёрнуто, минус никогда не ловится: `"ab"` / `"ac"` → `True` вместо `False`
? Буква лишняя, если её счётчик ушёл в минус.


- `<=` [wrong]: `0` — это «буква израсходована ровно», а не «лишняя»: `"a"` / `"a"` → `False` вместо `True`
- @1 `<` [wrong]: длинная `a` проскочит, её лишние буквы никто не проверит: `"ab"` / `"a"` → `True` вместо `False`
- @1 `<=` [wrong]: равные длины сразу дают «не анаграмма»: `"a"` / `"a"` → `False` вместо `True`
- @2 `!=` [wrong]: любой остаток, кроме `0`, считается «лишней» буквой: `"aa"` / `"aa"` → после первой `a` остаток `1`, ответ `False` вместо `True`

? Буква лишняя, если её счётчик ушёл в минус.
