# l4.2
note: 4.2 Максимальная сумма подмассива (Кадане)
lang: python
title: Максимальная сумма подмассива
statement: Найди максимальную сумму непрерывного подсписка непустого списка `nums` (LeetCode 53).
trains: алгоритм Кадане: продолжить серию или начать заново
pitfalls:
- Начинать с `0`, а не с `nums[0]`: на всех отрицательных вернёшь `0` вместо максимума: `[-3, -1, -2]` → `-1`
- `best = float('-inf')` без прохода по `nums[0]`: на списке из одного числа вернёшь `-inf`
- `range(len(nums))` при `current = nums[0]`: первый элемент посчитается дважды
- Перебирать все подсписки через `sum(nums[l:r + 1])` — O(n³), а Кадане проходит один раз
variations:
- без индексов: `for x in nums[1:]:` и `current = max(x, current + x)` — то же самое, но срез копирует список
- старт `best = float('-inf')`, `current = 0` и цикл по всем `nums` — тоже верно
- нужны границы подсписка: запоминай `start`, когда серия начинается заново, и `end`, когда растёт `best`
examples:
- assert max_sub_array([-2, 1, -3, 4, -1, 2, 1, -5, 4]) == 6
- assert max_sub_array([1]) == 1
- assert max_sub_array([-3, -1, -2]) == -1
checks:
```python
# оракул: перебор всех подсписков; все списки длины 1..5 из {-2..2}
for n in range(1, 6):
    with case():
        for m in range(pw(5, n)):
            a = [(m // pw(5, i)) % 5 - 2 for i in range(n)]
            best = max(sum(a[l:r + 1]) for l in range(n) for r in range(l, n))
            got = max_sub_array(a[:])
            assert got == best and type(got) is int, (a, got)
# оракул на длинных случайных списках из {-100..100}
import random
rnd = random.Random(1234)
with case():
    for _ in range(50):
        a = [rnd.randint(-100, 100) for _ in range(rnd.randint(1, 40))]
        best = max(sum(a[l:r + 1]) for l in range(len(a)) for r in range(l, len(a)))
        assert max_sub_array(a[:]) == best, a
with case():
    assert max_sub_array([1, 2, 3, 4, 5]) == 15  # весь список
with case():
    assert max_sub_array([-10000]) == -10000
with case():
    assert max_sub_array([-1, 0, -2]) == 0
with case():
    assert max_sub_array([5, -1, 3]) == 7  # через минус
with case():
    assert max_sub_array([5, -9, 9]) == 9  # начать заново
# контрпримеры из причин
with case():
    assert max_sub_array([1, 2]) == 3
with case():
    assert max_sub_array([1, -1, 2]) == 2
with case():
    assert max_sub_array([1, 2, 3]) == 6
with case():
    assert max_sub_array([5]) == 5
with case():
    assert max_sub_array([1]) == 1
with case():
    assert max_sub_array([-1]) == -1
with case():
    assert max_sub_array([-1, -2]) == -1
with case():
    assert max_sub_array([-1, 2]) == 2
```

## theory Когда Кадане
signals:
- Подряд идущий отрезок с **максимальной суммой**
- Числа бывают отрицательными, длина отрезка любая
- Нужно O(n) и O(1) памяти
body: Идём слева направо и держим `current` — лучшую сумму отрезка, который кончается на `i`. Для каждого `nums[i]` выбор один: продолжить серию (`current + nums[i]`) или начать заново с него (`nums[i]`). Ответ `best` — максимум всех `current`.

## theory Каркас
skeleton:
```python
# кончается на i
current = nums[0]
# лучшая вообще
best = nums[0]
for i in range(1, len(nums)):
    # продолжить или заново
    current = max(nums[i],
                  current + nums[i])
    best = max(best, current)
```
body: Старт — первый элемент, поэтому цикл идёт с `1`. Хвост с минусом выгоднее отрезать: тогда `nums[i]` один больше, чем `current + nums[i]`.

## theory Грабли
pitfalls:
- `best = 0`: на всех отрицательных ответ `0`, а нужно `-1`: `[-3, -1, -2]`
- `current = 0`: `nums[0]` выпадает из сумм: `[1, 2]` → `2` вместо `3`
- `range(len(nums))`: `nums[0]` посчитается дважды: `[1]` → `2` вместо `1`
- `best + nums[i]` вместо `current + nums[i]`: отрезок склеится через выкинутые минусы: `[1, -1, 2]` → `3` вместо `2`

## e1
```python
# Случай 1: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
#   → 6 (подсписок [4, -1, 2, 1])
# Случай 2: [1] → 1
# Случай 3: [-3, -1, -2] → -1
def max_sub_array(nums: list[int]) -> int:
    # лучшая сумма, кончающаяся на i
    current = nums[0]
    # лучшая сумма вообще
    best = nums[0]
    for i in range(1, len(nums)):
        # продолжить серию или начать заново
        current = max(nums[i], ⟦current + nums[i]⟧)
        best = max(best, current)
    return best
```
- `current` [wrong]: серия не копится, `current` — просто максимум из элементов: `[1, 2]` → `2` вместо `3`
- `best + nums[i]` [wrong]: к лучшей сумме приклеивается `nums[i]` через выкинутые элементы: `[1, -1, 2]` → `3` вместо `2`
- `nums[i - 1] + nums[i]` [wrong]: это только пара соседей, а не вся серия: `[1, 2, 3]` → `5` вместо `6`
? Серия, которая кончается на `i`, — это серия до `i - 1` плюс сам `nums[i]`.

## e3
```python
# Случай 1: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
#   → 6 (подсписок [4, -1, 2, 1])
# Случай 2: [1] → 1

    best = nums[0]
    for i in range(⟦1⟧, len(nums)):
        # продолжить серию или начать заново

        best = max(best, ⟦current⟧)
    return best
```
- `0` [wrong]: `nums[0]` уже в `current`, а цикл прибавит его снова: `[1]` → `2` вместо `1`
- `nums[i]` [wrong]: серия не копится, ответ — просто максимум из элементов: `[1, 2]` → `2` вместо `3`
- `best + nums[i]` [wrong]: к лучшей сумме приклеивается `nums[i]` через выкинутые элементы: `[1, -1, 2]` → `3` вместо `2`
- @1 `current + nums[i]` [crash]: `i` появится только в цикле, здесь его ещё нет: `[1]` → `UnboundLocalError`
- @1 `current` [wrong]: цикл начнётся с индекса `nums[0]`, а отрицательный индекс считает с конца: `[-1, 2]` → `3` вместо `2`
- @1 `nums[i]` [crash]: `i` появится только в цикле, здесь его ещё нет: `[1]` → `UnboundLocalError`
- @1 `best + nums[i]` [crash]: `i` появится только в цикле, здесь его ещё нет: `[1]` → `UnboundLocalError`
- @2 `1` [wrong]: вместо серии — константа `1`, на отрицательных выйдет плюс: `[-1, -2]` → `1` вместо `-1`
- @2 `current` [wrong]: серия не копится, `current` — просто максимум из элементов: `[1, 2]` → `2` вместо `3`
- @2 `0` [wrong]: серия не копится, а `0` пролезает в ответ: `[-1, -2]` → `0` вместо `-1`
- @3 `1` [wrong]: `best` сравнивается с константой, а не с серией: `[1, 2]` → `1` вместо `3`
- @3 `current + nums[i]` [wrong]: `nums[i]` уже в `current`, он прибавится дважды: `[1, 2]` → `5` вместо `3`
- @3 `0` [wrong]: `best` сравнивается с нулём, а не с серией: `[1, 2]` → `1` вместо `3`
