# Algolingo (Алголинго)

## What This Is

Duolingo для алгоритмов: мобильный тренажёр (Android + iOS на KMP + Compose Multiplatform), где решение задачи на Kotlin не печатается, а собирается из облачков-токенов — тап по облачку, и оно встаёт в «дырку» шаблона кода. Урок = короткая теория (карточки) → упражнения от простого к сложному. Сначала для себя (подготовка к алгоритмическим собеседованиям Android-разработчика), позже — в стор.

## Core Value

Быстро, с телефона, без клавиатуры прорешать алгоритмическую задачу: собрать решение из облачков, нажать «Проверить» и сразу понять, где грабли.

### Active

- [ ] Урок открывается теорией (карточки), затем идут упражнения «дырки»
- [ ] Упражнение «дырки»: шаблон Kotlin-кода с пропусками + банк облачков (верные + дистракторы); тап по облачку вставляет его в ближайшую пустую дырку, тап по вставленному — возвращает в банк
- [ ] Кнопка «Проверить»: сравнение собранной последовательности токенов с 1–3 эталонными вариантами; зелёное/красное + объяснение грабли для неверного облачка
- [ ] Ошибочные задания возвращаются в конец урока (без жизней)
- [ ] Подсказки открываются по одной, каждая уменьшает очки за задачу
- [ ] После решения показывается эталон, сложность и «грабли»
- [ ] Прогресс хранится локально: пройденные уроки, XP, streak дней
- [ ] Интервальные повторы задач: через 1 / 3 / 7 дней
- [ ] Контент уровня 0 «Разминка» из «05 Тренажёр решений»: 0.1 сумма и максимум, 0.2 разворот строки, 0.3 палиндром, 0.4 бинарный поиск
- [ ] Контент хранится в JSON в ресурсах приложения, сгенерированном из Obsidian-заметок (скрипт + ручная разметка дырок/дистракторов, ревью заказчиком)
- [ ] Приложение собирается и проходится на Android и на iOS-симуляторе

### Out of Scope

- Ввод кода с клавиатуры — на телефоне медленно; суть продукта в облачках
- Компиляция/запуск кода (на устройстве или сервере) — для облачков не нужна; возможна в v2 на отдельном VPS (не на личных серверах с другими сервисами: JVM-компилятор отнимет у них RAM, и чужой код рядом с ними небезопасен)
- Бэкенд, аккаунты, синхронизация — пока приложение для одного пользователя, офлайн
- Жизни/сердечки — выбран мягкий режим «повтор в конце урока»
- Тексты задач с LeetCode — авторское право; только свои формулировки + ссылка
- LLM-проверка/подсказки — платно, не для бесплатной версии
- Уровни 1–5 тренажёра — после того как уровень 0 работает end-to-end
- Другие языки решений (Java, Python) — пока только Kotlin
- Подпись iOS / TestFlight / публикация в стор — после MVP

## Context

- Заказчик — Android-разработчик, готовится к алгоритмическим собеседованиям (Avito, Glovo, Яндекс).
- Контент уже существует в Obsidian: `/Users/user/Yandex.Disk.localized/Матрицы/Алгоритмы/` — `00 Компас алгоритмов` (типы задач, таблица «сигнал → метод»), `01 Ключи и сигналы`, `02 Шаблон решения`, `03 Тренажёр задач` (распознавание метода), `04 Маркеры + Заготовки`, `05 Тренажёр решений` (лестница уровней 0–5, задачи с подсказками и эталонами на Kotlin), `06 Движок «маркеры и дырки»` (5-шаговая лестница одного приёма).
- Формат заметок машиночитаем: условие, «🎯 Тренируем», «⏱ Цель», callout `> [!question]-` = подсказка, callout `> [!success]-` = эталонное решение, «⚠️ Грабли», «🔁 Вариации». Грабли из заметок = источник дистракторов.
- Методика из заметок: «сначала сам, потом спойлер»; «умею» = решил с нуля за целевое время 3 раза с интервалами 1 / 3 / 7 дней.
- Будущие типы упражнений (v2): расставить строки по порядку (Parsons), собрать тело функции целиком из токенов, выбрать метод по сигналу в условии, предсказать вывод.

## Constraints

- **Tech stack**: Kotlin Multiplatform + Compose Multiplatform, общий UI для Android и iOS — заказчик Android-разработчик, один код на обе платформы
- **Offline**: всё работает без сети, без бэкенда — бесплатная версия, ноль инфраструктуры
- **Content language**: интерфейс и теория на русском; код на Kotlin
- **iOS**: на этапе MVP достаточно симулятора — нет Apple Developer подписи
- **Repo**: https://github.com/Tlenparty/Algolingo (private), ветка main

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Ответ собирается из облачков-токенов, а не печатается | Быстро и удобно на телефоне, как Duolingo | — Pending |
| Проверка локально: сравнение токенов с 1–3 эталонами | Не нужен компилятор и сервер; офлайн | — Pending |
| MVP = только тип «дырки» | Самый быстрый путь к рабочей версии; ложится на «движок маркеров и дырок» | — Pending |
| Проверка по кнопке «Проверить», ошибки — повтор в конце урока | Duolingo-паттерн, без наказания жизнями | — Pending |
| Контент: JSON в ресурсах, генерируется из Obsidian .md + ручная разметка | Заметки — единственный источник правды, приложение — «плеер» | — Pending |
| Старт с уровня 0 «Разминка» | Начать с самых простых задач с нуля | — Pending |
| GSD вместо superpowers | Многофазный greenfield-проект, нужен roadmap и состояние между сессиями | — Pending |
