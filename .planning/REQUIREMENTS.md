# Requirements: Algolingo (Алголинго)

**Defined:** 2026-10-21
**Core Value:** Быстро, с телефона, без клавиатуры прорешать алгоритмическую задачу: собрать решение из облачков, нажать «Проверить» и сразу понять, где грабли.

## v1 Requirements

MVP = уровень 0 «Разминка» (0.1 сумма и максимум, 0.2 разворот строки, 0.3 палиндром, 0.4 бинарный поиск) проходится end-to-end на Android и iOS-симуляторе.

### Platform

- [ ] **PLAT-01**: Пользователь может установить и запустить приложение на Android (эмулятор/устройство)
- [ ] **PLAT-02**: Пользователь может запустить то же приложение на iOS-симуляторе (общий Compose UI)
- [ ] **PLAT-03**: Приложение полностью работает офлайн, без аккаунта и сети

### Lesson Flow

- [ ] **LESS-01**: Пользователь видит список уроков уровня 0 со статусами «пройден / доступен / закрыт»; следующий урок открывается после прохождения предыдущего
- [ ] **LESS-02**: Урок начинается с 2–4 карточек теории (сигналы, скелет, грабли), листаются кнопкой «Дальше»
- [ ] **LESS-03**: Урок = одна задача; внутри 2–3 упражнения на том же коде с растущим числом дырок (лесенка, например 1 → 2 → 4)
- [ ] **LESS-04**: Пользователь видит прогресс-бар урока
- [ ] **LESS-05**: Неверно решённые упражнения возвращаются в конец урока (не более 2 повторов на упражнение), банк облачков перемешивается; жизней нет
- [ ] **LESS-06**: В конце урока пользователь видит итог: оценка (✅ чисто / 💡 с подсказками или повтором / ❌ не решил или открыл ответ) и заработанные XP

### Exercise («дырки»)

- [ ] **EXER-01**: Пользователь видит условие задачи и шаблон Kotlin-кода моноширинным шрифтом с подсветкой синтаксиса и пустыми дырками в строке
- [ ] **EXER-02**: Под кодом общий банк облачков (верные + ложные, ≤ ~10); облачко может быть целым выражением (`lo + (hi - lo) / 2`)
- [ ] **EXER-03**: Тап по облачку вставляет его в выделенную (по умолчанию — первую пустую) дырку; в банке остаётся серый «призрак»
- [ ] **EXER-04**: Тап по вставленному облачку возвращает его в банк; тап по дырке делает её выделенной
- [ ] **EXER-05**: Одинаковые по тексту облачка (`mid`, `1`) работают корректно — каждое отдельный объект
- [ ] **EXER-06**: Кнопка «Проверить» активна, только когда все дырки заполнены
- [ ] **EXER-07**: После проверки каждая дырка подсвечивается: зелёная (верно), жёлтая «принято, но…» (работает, но эталон лучше — с пояснением), красная (неверно)
- [ ] **EXER-08**: При ошибке снизу выезжает панель с объяснением грабли для неверного облачка (например, «`max = 0` ломается на `[-5, -2]`») и верным вариантом
- [ ] **EXER-09**: Пользователь может открыть подсказки по одной; каждая снижает оценку; кнопка скрыта, если подсказок нет
- [ ] **EXER-10**: После решения задачи пользователь видит эталонное решение, сложность (время/память), грабли и вариации

### Progress

- [ ] **PROG-01**: Пользователь получает XP за решённые упражнения (меньше при подсказках/повторах)
- [ ] **PROG-02**: Пользователь видит серию дней (streak) — считается по локальной календарной дате
- [ ] **PROG-03**: Прогресс (пройденные уроки, XP, streak, повторы) сохраняется между запусками (DataStore, один версионированный документ)
- [ ] **PROG-04**: Задача уходит на интервальное повторение 1 / 3 / 7 дней: ✅ — шаг вперёд, 💡 — шаг на месте, ❌ — сброс на 1 день; ✅ на последнем шаге = «освоено»
- [ ] **PROG-05**: На главной есть «Повтор сегодня (N)»; повтор запускает тот же плеер урока для задач, у которых наступил срок

### Content

- [ ] **CONT-01**: Контент уроков лежит в приложении как JSON (index + файл на урок), сгенерированный скриптом из Obsidian-заметок + файлов разметки дырок
- [ ] **CONT-02**: Генератор проверяет контент: у каждой дырки ≥ 1 верное облачко, у каждого ложного облачка есть объяснение и контрпример, id уроков стабильны, разметка без дырок совпадает с эталоном из заметки
- [ ] **CONT-03**: Для 0.1–0.4 размечены дырки, лесенки упражнений и дистракторы из «Граблей»; «работает, но не идеально» (`l <= r`, `Int.MIN_VALUE`, `ushr`) размечено как «принято, но…»
- [ ] **CONT-04**: Для 0.1–0.4 написаны карточки теории (на основе 04 «Маркеры + Заготовки», 00 «Компас», 03) и недостающие дистракторы для 0.2/0.3
- [ ] **CONT-05**: Эталоны уровня 0 и принятые варианты проверены тестами на примерах из условия
- [ ] **CONT-06**: Заказчик отревьюил контент уровня 0

## v2 Requirements

Отложено. Отслеживается, но не в текущем roadmap.

### Exercise Types

- **EXV2-01**: Расставить строки решения по порядку (Parsons)
- **EXV2-02**: Собрать тело функции целиком из атомарных токенов
- **EXV2-03**: Выбрать метод по сигнальным словам в условии (из 03 / 01)
- **EXV2-04**: Предсказать вывод / значение переменной
- **EXV2-05**: Лёгкий режим: в банке только кандидаты для выделенной дырки

### Learning Aids

- **AIDV2-01**: Таблица «прогон руками» (трассировка переменных) после решения
- **AIDV2-02**: Подсветка того, что изменилось между ступенями лесенки
- **AIDV2-03**: Экран-справочник «Компас»: таблица «сигнал → метод»
- **AIDV2-04**: Заморозка серии (streak freeze)

### Content & Platform

- **CNV2-01**: Уровни 1–5 тренажёра и лесенка 06
- **CNV2-02**: Тёмная тема
- **CNV2-03**: Запуск реального кода на отдельном VPS (Judge0 / kotlin-compiler-server)
- **CNV2-04**: Подпись iOS, TestFlight, публикация в сторы (свои формулировки задач, поле `origin`)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Ввод кода с клавиатуры | Медленно на телефоне; суть продукта — облачка |
| Компиляция на устройстве | kotlinc тяжёлый, на iOS невозможен |
| Сервер на личных машинах с другими сервисами | JVM-компилятор отнимет у них RAM; чужой код рядом с ними |
| Бэкенд, аккаунты, синхронизация | Один пользователь, офлайн, бесплатно |
| Жизни / сердечки | Выбран мягкий режим «повтор в конце урока» |
| Таймер по «⏱ Цель» | Цели из заметок — для написания с нуля, не для тапов; показываем как инфо |
| Лиги, монеты, уведомления | Шум для одного пользователя |
| Drag-and-drop | Тап быстрее и доступнее |
| Продолжение урока с середины | Урок короткий (2–3 мин) |
| FSRS / SM-2 | Фиксированные 1/3/7 из методики заметок достаточно |
| Тексты LeetCode | Авторское право; только свои формулировки |
| LLM-проверка | Платно |
