1. From the repo root, run `xcodebuild -project iosApp/iosApp.xcodeproj -scheme iosApp -configuration Debug -sdk iphonesimulator -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath build/ios CODE_SIGNING_ALLOWED=NO build` and tee the output to `/tmp/algolingo-xcodebuild.log`. A cold build takes about 3 min, so use a 600000 ms timeout.
2. If the build fails with a sandbox or daemon error (Pitfall 5): confirm `ENABLE_USER_SCRIPT_SANDBOXING = NO`, run `./gradlew --stop`, and retry once. Do not upgrade Xcode (D-02).
3. Get the UDID: `xcrun simctl list devices available | grep 'iPhone 17 (' | head -1`, then extract the 36-character UDID. Run `xcrun simctl boot "$UDID" || true` and `xcrun simctl bootstatus "$UDID" -b`.
4. `xcrun simctl install "$UDID" build/ios/Build/Products/Debug-iphonesimulator/Algolingo.app`. If the .app name differs, `ls` the Products dir and use the real name.
5. Read the bundle id from the built app: `/usr/libexec/PlistBuddy -c 'Print CFBundleIdentifier' <app>/Info.plist`. Expect `com.tlenparty.algolingo`. Then run `xcrun simctl launch "$UDID" <that id>`.
6. `sleep 6; xcrun simctl io "$UDID" screenshot /tmp/algolingo-ios.png`. Read the PNG and confirm `Алголинго` and `Скелет: JSON прочитан из ресурсов` are visible on the same layout as Android.
  </action>
