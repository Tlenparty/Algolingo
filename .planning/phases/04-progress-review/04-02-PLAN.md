## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk → app | progress.json in filesDir / Documents can be corrupt (a crash or a hand edit) |
| UI lifecycle → storage | ViewModel/Activity lifetimes are shorter than a write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Denial of service | progressStore read | mitigate | readFrom throws CorruptionException on decode failure, and ReplaceFileCorruptionHandler { Progress() } resets the file. Real-file corrupt test on both targets |
| T-04-06 | Denial of service | ProgressRepository.progress / record | mitigate | store.data.catch emits Progress(). The record scope has a CoroutineExceptionHandler, so an IO error never crashes the app |
| T-04-07 | Tampering (lost/duplicate write) | record on Done | mitigate | The write runs in the repository's SupervisorJob scope, not viewModelScope. onFinish fires only on the non-Done to Done transition. One DataStore per process via AppGraph |
| T-04-08 | Information disclosure | progress.json in app sandbox / Android Auto Backup | accept | No PII; ids, counters and dates only |
| T-04-09 | Tampering | installDebug on all connected devices | mitigate | Install with `adb -s emulator-5554 install -r` only |
