### CR-01: Note screen stuck on "Заметка не найдена" after Activity recreation
**Files modified:** `shared/src/commonMain/kotlin/com/tlenparty/algolingo/App.kt`
**Commit:** 2b444c5
**Applied fix:** The `NoteRoute` destination now reads `loaded` and shows "…" until it is true. Reading that state subscribes the entry's scope, so the entry recomposes with the note once loading finishes. **Needs a device re-check:** open a note, then toggle `adb shell cmd uimode night yes/no`.

### WR-01: sync_notes.py wiped the bundle before reading the vault
**Files modified:** `tools/sync_notes.py`
**Commit:** 8e01273
**Applied fix:** All vault notes are read first. The script fails if there are none. It writes `kb.tmp/`, then swaps it in place of `kb/` by rename and removes `kb.old/`. Verified: a non-UTF-8 note aborts the run and the bundle stays intact.

### WR-02: Anchor scroll re-fired on return or rotation
**Files modified:** `shared/src/commonMain/kotlin/com/tlenparty/algolingo/kb/ui/NoteScreen.kt`
**Commit:** 86aaf0d
**Applied fix:** A `rememberSaveable(note.id, anchor)` flag makes the anchor jump happen only once per entry.

### WR-03: Markdown `[text](#anchor)` links rendered raw
**Files modified:** `MarkdownParser.kt`, `KbRepository.kt`, `kb/ui/NoteScreen.kt`, `MarkdownParserTest.kt`, `KbLinkTest.kt`
**Commit:** c52c2a2
**Applied fix:**
- `parseInline` now handles `[label](url)`. A `#anchor` URL becomes `Link("#anchor", anchor, label)`. An external URL becomes plain label text.
- `findAnchorIndex` also matches GitHub-style slugs (new `slug()`).
- NoteScreen handles `#` targets locally. It shows a clickable link only when the heading exists, and a tap animates the scroll to that heading.
- New tests cover parsing and slug matching. The WR-07 content test confirms that all n04 slug anchors resolve.

### WR-04: Table columns not aligned
**Files modified:** `shared/src/commonMain/kotlin/com/tlenparty/algolingo/kb/ui/BlockView.kt`
**Commit:** 20e4b8b
**Applied fix:** Each column gets one fixed width, computed from the longest cell in that column (characters x 8dp + 16, clamped to 80..240dp). The unused `Color` and `widthIn` imports were removed, which covers half of IN-04. **Needs a visual check** on a device.

### WR-05: Double tap on "Назад" popped two entries
**Files modified:** `shared/src/commonMain/kotlin/com/tlenparty/algolingo/App.kt`
**Commit:** 9f57e82
**Applied fix:** A new `NavBackStackEntry.ifResumed {}` guard wraps back, the wikilink navigation and the KB list `onOpen`. `dropUnlessResumed` was not used because it cannot wrap lambdas that take arguments.

### WR-06: Positional note ids
**Files modified:** `tools/sync_notes.py`, `shared/src/commonMain/composeResources/files/kb/*` (index.json plus 23 renamed notes)
**Commit:** db3a5cb
**Applied fix:**
- The id is now `"n" + sha1(title)[:8]`, which is stable and ASCII-only.
- The sync was re-run with the vault path passed only through `ALGOLINGO_VAULT` at runtime. No path was written to any file.
- Note contents are byte-identical (renames only). Wikilinks resolve by title, so they are unaffected.

### WR-07: KbContentTest was weak and hard-coded the count of 23
**Files modified:** `shared/src/androidHostTest/kotlin/com/tlenparty/algolingo/kb/KbContentTest.kt`
**Commit:** 5d620e6
**Applied fix:**
- The magic count is replaced by a non-empty check and an id-uniqueness check.
- Inlines are collected recursively, including callout titles and the contents of callouts and quotes.
- Every `Link` must resolve: wikilinks to a note and its heading, and `#` links to a heading in the same note.
- Six wikilink targets that are absent from the vault are listed in `knownMissing`. A newly broken link fails the test.
