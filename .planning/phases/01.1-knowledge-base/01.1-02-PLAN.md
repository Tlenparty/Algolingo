    - "> [!question]- Подсказка 1\n> текст\n> ```kotlin\n> val a = 1\n> ```" -> Callout(type="question", foldable=true, collapsed=true, title="Подсказка 1", blocks=[Paragraph, Code])
    - "> [!tip] T" -> foldable=false; "[!note]+" -> foldable=true, collapsed=false
    - two callouts separated by a blank line -> two Callout blocks
    - "> plain\n> - item" -> Quote(blocks)
    - table with alignment row: "| a | [[X|y]] |\n|---|:-:|\n| 1 | 2 |" -> Table(header=["a","[[X|y]]"], rows=[["1","2"]]) (pipe inside [[...]] or backticks not a separator)
    - "---" -> Rule; a code line "2 > 2? нет" inside a fence is untouched
    - inline: `**b**`, `*i*`, `` `c` ``, text; "[[A#h|alias]]" -> Link(target="A", anchor="h", label="alias"); "[[A]]" -> label "A"; "`[[x]]`" stays Code
    - unclosed "**" or "[[" -> literal text, no throw
  </behavior>
  <action>
Create `MarkdownParser.kt` (package com.tlenparty.algolingo.kb, pure Kotlin, no Compose imports). Declare `sealed interface Block` with data classes Heading(level:Int,text:String), Paragraph(text), ListItem(ordered:Boolean, number:Int, depth:Int, text), Code(lang,text), Table(header:List<String>, rows:List<List<String>>), Quote(blocks), Callout(type:String, foldable:Boolean, collapsed:Boolean, title:String, blocks), and object Rule. Declare `sealed interface Inline` with Text, Bold, Italic, Code (all String) and Link(target, anchor:String?, label). Functions: `fun parseBlocks(src: String): List<Block>` and `fun parseInline(s: String): List<Inline>`. Algorithm per RESEARCH "Block parser": line-based; fences first (open ``` with optional lang, close ```, inner text verbatim); a run of lines starting with `>` has one `> `/`>` prefix stripped, and the run is split at blank lines (blank line ends the run); if the first stripped line matches Regex `^\[!([A-Za-z]+)]([+-]?)\s*(.*)$` it becomes Callout (collapsed = marker is '-'; foldable = marker present), body parsed by recursive `parseBlocks`, else Quote with recursive body. Tables: a line starting with `|` followed by an alignment row (Regex `^\|?[\s:|-]+$` containing `-`); split cells outside `[[...]]` and backticks, trim. Lists: Regex `^(\s*)([-*]|(\d+)\.)\s+(.*)$`, depth = indent length / 2, number = the digits group for ordered items, 0 for unordered. Headings `#`..`###` (up to 6 tolerated). `---` alone = Rule. Consecutive other lines join with "\n" into one Paragraph (soft breaks preserved, pitfall 9). Every unknown construct falls to Paragraph; wrap nothing in try/catch but make loops index-safe so malformed input cannot throw. Inline parser: scan priority backtick code, `**bold**`, `*italic*`, `[[...]]` (split on first `|` for alias, then on first `#` for anchor); unclosed openers emit literal text.
Tests in `MarkdownParserTest.kt` (commonTest, kotlin.test) cover every behavior bullet above. Verify TDD order: write failing tests first, then implementation.
