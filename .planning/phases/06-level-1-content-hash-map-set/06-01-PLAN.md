Vertical slice 1 of level 1: a user who finished 0.4 sees and can play lesson 1.1 «Есть ли дубликат» — and the generator is made able to test every level-1 reference on both test targets.

Purpose: CNV2-01 (level 1 part only — CNV2-01 covers levels 1–5 + ladder 06; this phase delivers level 1, so CNV2-01 stays Partial). Two generator limits were confirmed by the planner by compiling with the local Kotlin/Native 2.4.21 (`~/.konan/kotlin-native-prebuilt-macos-aarch64-2.4.21/bin/kotlinc-native`):
1. `Map.getOrDefault` is JVM-only: `HashMap<Char, Int>().getOrDefault('a', 0)` gives "unresolved reference 'getOrDefault'" on Native. Note 05 uses it in 1.2, 1.3 and 1.5, and G5 forces the lesson code to equal the note reference. So ReferenceSolutionsTest (commonTest → iosSimulatorArm64Test) would not compile.
2. `with(obj) { E(1) }` does not resolve a class `E` nested in `obj`: "unresolved reference 'E'". Note 1.5 declares `data class StepEntry` / `ChampionResult` inside the snippet, and the examples must construct `StepEntry(...)`.
Neither can be fixed by reshaping holes, because the code is fixed by G5. So per the user's rule ("change generator only if unavoidable, with a test") this plan changes render_kt once, with tests, before any level-1 content is written.
Output: hardened generator + tests, content/authoring/l1.1.md, generated l1.1.json, a 5-lesson index.json and a regenerated ReferenceSolutionsTest.kt.
</objective>
