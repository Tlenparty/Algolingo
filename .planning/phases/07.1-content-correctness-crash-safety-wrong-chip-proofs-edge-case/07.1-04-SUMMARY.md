## Отклонения от плана

1. **[Rule 1 - Bug] Запрет G10 на `String(` отклонял `concatToString()`.** Подстрока `String(` есть внутри `concatToString(`, а план сам требует использовать `concatToString()`. Запрет переведён на regex с `\b`, добавлен тест. Файл: `tools/gen_content.py`, коммит a40f285.
2. **Перебор обёрнут в `case {}` по длине, а не по каждому входу.** Если вариант зацикливается на каждом входе, проверка по каждому входу стоила бы тысячи × 1M шагов. Теперь не больше 6 × 1M. Явные граничные случаи остаются отдельными `case`.
3. **Критерий `grep -c 'intArrayOf()' l0.1.md >= 2` не выполнен (там 1).** В `examples:` l0.1 пустого массива нет и не было, поэтому критерий исходил из неверной предпосылки. Добавлять пустой массив в `examples:` значит заранее выбрать контракт (пункт 1 документа находок). Пустой массив есть в `checks:`, и F1 виден.
4. Коммит Task 1 сам по себе не проходит `--check`: сгенерированные файлы и исправление G10 вошли в коммит Task 2. Дерево зелёное с a40f285.
