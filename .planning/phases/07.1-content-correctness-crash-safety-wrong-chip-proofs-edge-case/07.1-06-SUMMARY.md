## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] ANR: поиск KB на главном потоке**
- **Где нашли:** Task 3, monkey seed 2. В трассе ANR (`/data/anr` из bugreport) main стоял в `KbRepositoryKt.searchNotes` → `String.indexOf`, вызов шёл из `KbListScreen`.
- **Проблема:** `remember(query) { search(query) }` на каждое нажатие клавиши прогонял полнотекстовый поиск по всем 217 заметкам прямо в композиции.
- **Фикс:** `produceState` с ключом query, `delay(150)`, затем поиск в `withContext(Dispatchers.Default)`. Новый запрос отменяет старый.
- **Файл:** shared/src/commonMain/kotlin/com/tlenparty/algolingo/kb/ui/KbListScreen.kt
- **Коммит:** 1c36cd8
- **Регрессия:** отдельного unit-теста нет: многопоточность в Compose без устройства толком не проверить. Сценарий `scenarioKb` в `tools/smoke.sh` ищет через UI и проходит на обеих платформах, а monkey прогнан повторно на всех трёх seed.

**2. [Rule 3 — Blocking] Стенд: эмулятор падал и голодал по CPU**
- `qemu-system-aarch64` трижды падал (`.ips` 18:07, 18:36, 18:46, 18:54). Причина — hang detector на «QEMU2 main loop». Каждый раз это происходило сразу после того, как monkey открывал Gboard PermissionsActivity (голосовой ввод, то есть доступ к микрофону хоста). Помог запуск с `-no-audio`, плюс `-crash-report-mode never`, чтобы диалог отчёта не блокировал загрузку.
- AVD стартовал с **1 vCPU** и программным GPU (swangle/lavapipe). Остальные ANR на debug-сборке (раскладка текста, measure LazyList, dispose диалога) каждый раз падали в разные места фреймворка. По schedstat поток main ждал очереди в 3–4 раза дольше, чем работал (9 с работы против 39 с ожидания; 30 с против 96 с). В те же минуты ANR ловили и системные gms, IME, permissioncontroller и launcher. Чтобы проверить, собрали release-сборку (подпись debug-ключом, только в /tmp): 3×3000 событий, 0/0. После этого эмулятор перезапустили с `-cores 4 -gpu host` (только флаг запуска, AVD не менялся), и debug-сборка тоже дала 0/0 на всех трёх seed.
- Логика приложения при этом не менялась, ассерты e2e не ослаблялись.
