<objective>
Extend the generator so every wrong-chip claim is machine-checkable (GAP-1) and edge/oracle checks can run in the shared suite (GAP-2 infrastructure). Per D-01..D-03, D-05, D-07, D-10.

Deliberate deviation from D-04 (approved by orchestrator, honours the intent "one command, nothing forgotten"): wrong-chip classification (`[compile]/[wrong]/[crash]/[hang]` verdicts) runs JVM-only, in plan 03's androidHostTest, because whether a variant compiles is only known after compiling it. Reference/ok/acceptable + edge + oracle checks run on JVM AND Native in the shared ReferenceSolutionsTest. Everything stays inside `./gradlew :shared:allTests`.

Hang detection is by tick injection (no threads/timeouts): the generator inserts `tick()` after every `while (...) {` line; `tick()` throws a private HangError after 1_000_000 steps. Deterministic on JVM and Native.
Output: extended generator + python tests, tagged sidecars, regenerated ReferenceSolutionsTest.kt and wrong_variants.json.
</objective>
