## Граничные случаи и оракулы

Ниже то, что написано в `checks:` каждого сайдкара (D-07, D-08, D-09). Оракул всегда устроен иначе, чем эталон. Перебор идёт по маленьким доменам целиком, без случайных чисел. Каждый вход или каждая длина обёрнуты в `case { }`, поэтому одна ошибка не прячет остальные. Проверки идут только в тестах (`ReferenceSolutionsTest.kt`, JVM + iOS, и `wrong_variants.json`, JVM). В приложении и в JSON уроков их нет (D-10): JSON уроков не изменился ни на байт.

**l0.1 Сумма и максимум.** Оракул: stdlib `a.sum()` и `a.max()` вместо ручного прохода. Перебор: все массивы длины 1..5 из `{-3, -1, 0, 2}`. Отдельно: `[0]`; `[Int.MAX_VALUE]`; `[Int.MIN_VALUE]`; `[Int.MIN_VALUE, Int.MAX_VALUE]` (сумма `-1`); максимум первым `[5, 1, 3]` и последним `[1, 3, 5]`; контрпримеры причин `[1, 2]`, `[3, 1]`, `[1]`; пустой массив — только «не падает», контракт не задан (пункт 1).

**l0.2 Разворот строки.** Оракул: `reversedArray()`. Перебор: все строки длины 0..6 из `{a, b, c}` (пустая, один символ, чётные и нечётные длины). Отдельно: контрпример `"ab"` → `"ba"` (облачко `s[l]`).

**l0.3 Палиндром.** Оракул: `s == s.reversed()`. Перебор: все строки длины 0..5 из `{a, b, c}`. Отдельно: `"aa"`; `"abcb"` (расходится первая пара); `"abca"` (расходится внутренняя).

**l0.4 Бинарный поиск.** Оракул: `a.contains(t)`, и по найденному индексу лежит `t`. Точный индекс при дублях не единственный, поэтому проверяется свойство. Перебор: все отсортированные массивы длины 0..5 из `{0..3}`, target `-1..4`. Отдельно: `[5]` с промахом снизу и сверху; `[-7, -3, 0, 4]`: первый, последний и отсутствующий отрицательный; `[Int.MIN_VALUE, 0, Int.MAX_VALUE]`: крайние значения; контрпримеры причин `[1, 3]`/`3`, `[1, 3]`/`1`, `[1, 3, 5, 7, 9]`/`3`.

**l1.1 Есть ли дубликат.** Оракул: `toSet().size != size`. Перебор: все массивы длины 0..5 из `{-1, 0, 1, 2}`. Отдельно: `[5]`; дубль первого и последнего `[1, 2, 3, 1]`; дубль в конце `[1, 2, 3, 3]`; `[Int.MAX_VALUE, Int.MIN_VALUE, 0]`, `[Int.MAX_VALUE, Int.MAX_VALUE]`; контрпримеры `[1, 2]`, `[1, 1]`, `[1]`.

**l1.2 Первый уникальный символ.** Оракул: `s.firstOrNull { c -> s.count { it == c } == 1 }`, квадратичный подсчёт без `Map`. Контракт — `Char?`. Перебор: все строки длины 0..5 из `{a, b, c}` (пустая и «уникальных нет» входят). Отдельно: уникальный первым `"abb"` и последним `"aab"`; `"abcabc"` → `null`; контрпримеры `"aa"` → `null`, `"ab"` → `'a'`.

**l1.3 Анаграмма.** Оракул: `a.toList().sorted() == b.toList().sorted()`. Перебор: все пары строк длины 0..3 из `{a, b, c}` (разные длины, пустые, те же буквы в другом количестве). Отдельно: `""`/`"a"`, `"abc"`/`"abcc"`; контрпримеры `"ab"`/`"ba"`, `"a"`/`"a"`, `"aa"`/`"aa"`, `"ab"`/`"a"`, `"ab"`/`"aa"`.

**l1.4 Two Sum.** Оракул: перебор всех пар `i < j`. Если пара есть, ответ должен быть не `null`, `first < second` и сумма равна `target`. Если нет, ответ `null`. Перебор: все массивы длины 0..4 из `{-1, 0, 1, 2}`, target `-2..4`. Отдельно: пустой; `[3]`/`6` (`target = 2·x`, но индекс один, из ревью 06); отрицательные `[-3, 4, 1]`/`-2`; нули `[0, 4, 0]`/`0`; `[Int.MAX_VALUE, -1]`/`Int.MAX_VALUE - 1`; контрпример `[2, 7]`/`9`.

**l1.5 Победители соревнования.** Оракул: перебор юзеров. «Был во все дни» значит «есть запись в каждом дне» (а не счётчик дней), сумма через `sumOf`, сравнение по отсортированным `userIds`. Перебор: 0..3 дня, в каждом дне юзеры 1 и 2 либо отсутствуют, либо идут с шагами `0` или `100`. Отдельно: один юзер с `0` шагов → `([1], 0)`; один пустой день → `([], 0)`; контрпримеры причин `[(1, 100), (2, 50)]`, `[(1, 100)]`, `[(1, 100)]`×2, `[(2, 100)]`.
