# Выбор языка решений: Kotlin / Python

Дата: 2026-10-28 · Статус: утверждён дизайн, ждёт ревью спека

## Цель

Python — полноценный второй язык решений для широкой аудитории стора. Пользователь выбирает язык, и уроки с кодом собираются из облачков на этом языке, со своими дистракторами и граблями.

## Решения заказчика

- Зачем: стор и аудитория, полноценный второй язык, а не «для себя».
- Прогресс общий: урок засчитывается один раз на любом языке. XP, streak и повторы не делятся по языкам.
- Переключатель стоит на Home, сегмент «Kotlin | Python». По умолчанию Kotlin, выбор запоминается. Экрана онбординга нет.

## Подход: отдельный файл урока на язык

- Kotlin: `files/content/lessons/<id>.json`, путь не меняется.
- Python: `files/content/lessons/py/<id>.json`, исходник `content/authoring/py/<id>.md`.
- id урока одинаковый для обоих языков, поэтому прогресс общий без миграции.
- Схема `Lesson`, `validate()` и движок дырок не меняются. Python-урок может отличаться числом шагов, дырками, банком и граблями, ограничение одно: правила `validate()`.

Отвергнуто: варианты по языкам внутри одного файла (ломает схему без выигрыша) и автоперевод Kotlin в Python (дистракторы и их причины привязаны к семантике языка).

## Компоненты

1. **Язык в прогрессе.** `enum class CodeLang { Kotlin, Python }` с `@SerialName("kotlin"/"python")`. В `Progress` появляется поле `lang: CodeLang = CodeLang.Kotlin`. `PROGRESS_SCHEMA` не растёт: старый блоб читается с значением по умолчанию. Смена языка — `ProgressRepository.setLang(lang)` с той же записью через `commit()`.
2. **Загрузка.** Сигнатура меняется на `lessonPath(id, lang)` и `loadLesson(id, lang)`. Python-урок читается из `files/content/lessons/py/$id.json`. Путь sd-уроков от языка не зависит. Пути по-прежнему фиксированные, свободного пути из маршрута нет.
3. **Каталог.** В элементе `index.json` появляется `langs: List<String> = ["kotlin"]`. На Home урок без выбранного языка показан как «Скоро на Python» и не открывается. Повторы (review) для таких уроков при выбранном Python пропускаются. Повтор не теряется: срок остаётся и всплывёт, когда язык вернут или урок появится.
4. **UI.** На Home, над путём уроков, стоит сегмент «Kotlin | Python» на компонентах и токенах `AlgoTheme`. На вкладке System Design его нет. Урок, который уже открыт, при смене языка не перезагружается: язык читается при старте урока.
5. **Подсветка.** Сигнатура `highlight(code, colors, lang: CodeLang = Kotlin)`. Для Python свой набор ключевых слов (`def`, `return`, `in`, `not`, `and`, `or`, `None`, `True`, `False`, `for`, `while`, `if`, `elif`, `else`, `lambda`, `class`, `import`, `from`, `pass`, `break`, `continue`, `is`, `yield`, `with`, `as`) и комментарий `#`. Числа и строки разбираются общими регулярками. Лигатуры отключены, как и для Kotlin. `CodeBlock` и `TokenChip` получают `lang` и пробрасывают его дальше. `design` не зависит от `shared`, поэтому `CodeLang` лежит в `design`.
6. **Генератор.** В sidecar появляется ключ `lang: python`, а `checks:` пишется в fence ```` ```python ````. Для Python-уроков `gen_content.py` рендерит модуль, в котором эталон и каждый вариант из `ok`/`acceptable` проходят `examples` и `checks`, а каждый `[wrong]`-чип хотя бы в одной дырке, где он может стоять, проваливает их. Запуск: `python3 -I` из временного каталога. Разбор дырок, банка, `why` и тегов общий с Kotlin. Пишется в `lessons/py/`, обновляет `langs` в `index.json`.
7. **Документы.** В `PROJECT.md` строку «Другие языки решений (Java, Python) — пока только Kotlin» переносим из Out of Scope в план (Python). В `ROADMAP.md` добавляются фазы 9 и 10.

## Ошибки

- Python-файла нет, хотя в `langs` он указан: тот же экран ошибки урока, что и для битого Kotlin-файла.
- Неизвестное значение `lang` в блобе прогресса: откат на Kotlin, а не падение. `coerceInputValues` или ручная проверка в декодере.

## Тесты

- `commonTest`: каждый `lessons/py/*.json` декодируется и проходит `validate()`. `lessonPath` для обоих языков и для sd. Старый блоб прогресса без `lang` даёт Kotlin. `lang` переживает round-trip. Фильтр каталога и повторов по `langs`.
- `test_gen_content.py`: Python-харнесс ловит неверный эталон и `[wrong]`-чип, который не роняет проверки.
- Устройства (Android + iOS-симулятор): переключить на Python, пройти пилотный урок, перезапустить приложение. Язык сохранён, урок засчитан и на Kotlin-пути.

## Не входит

База знаний (Kotlin-код в заметках), вкладка System Design, Java, онбординг выбора языка, раздельный прогресс по языкам.
